# 翼览无余（YiLanWuYu）

翼览无余是一套面向航空科普教育的交互展示平台。

项目包含航空器三维展示、驾驶舱体验、爆炸图拆解、虚拟课堂、知识问答等多个模块，
支持 Web 与 MR（PICO）等多平台展示。

---

## 项目结构

YiLanWuYu-Web
├── Web-frontend    # 前端
└── Web-backend     # 后端

---

## 技术栈

### Frontend

- Vue 3
- Vite
- Vue Router
- Three.js

### Backend

- Python
- FastAPI
- SQLite

---

## 功能

- C919 展示
- 运20展示
- 歼20展示
- 直20展示
- 三维模型浏览
- 爆炸图交互
- 驾驶舱体验
- 航空知识课程
- AI 智能问答

---
