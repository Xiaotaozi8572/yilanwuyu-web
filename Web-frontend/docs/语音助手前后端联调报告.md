## 三、联调协议要点（voice-ws-v1）

| 方向 | 消息 | 用途 |
| --- | --- | --- |
| 客户端→后端 | `session.start` | 携带 `session_id/turn_id/audio_stream_id`，握手建立语音轮次 |
| 客户端→后端 | `audio.frame`(文本) + 二进制帧 | 20ms/320B @16kHz PCM 音频块，附带 `energy` 能量 |
| 客户端→后端 | `audio.end` / `session.cancel` | 语音结束 / 打断 |
| 客户端→后端 | `scene_state` | 场景绑定（`camera_view`、`artifact_mode`） |
| 后端→客户端 | `voice.state` (`session.started`/`scene.updated`/…) | 会话与场景状态 |
| 后端→客户端 | `asr.final` | 识别结果（transcript + confidence） |
| 后端→客户端 | `answer.display` / `clarification.required` | 答案（含 `main_answer` + `evidence`）或澄清追问 |
| 后端→客户端 | 二进制 TTS 块 / `voice.error`(`VOICE_TTS_ERROR`) | 语音合成输出或降级提示 |
| 后端→客户端 | 关闭码 4408 | 会话超时 |

## 六、已知限制

1. **TTS 外放降级**：未部署生产媒体服务器时，后端返回 `voice.error VOICE_TTS_ERROR`、无 TTS 二进制块；前端以"文字答案"兜底展示，语音播放为空白。接入生产媒体服务后即可恢复。
2. **连接方式**：本地演示采用**直连** `ws://127.0.0.1:8765`（协议允许浏览器直连 WS）。部署时可改用 `VITE_VOICE_WS_URL` 指向网关/反向代理地址。
3. **原 HTTP 端点降级**：`VITE_VOICE_ASSISTANT_ENDPOINT` 旧地址仍有占位降级逻辑保留，未配置时不会出现 `pending-integration`。

## 附：增量迭代——右侧聊天面板（文本输入 + 语音转文字 + 流式输出）

> 在原始"语音问答"基础上新增：点击 AI 语音老师后，右侧打开聊天面板，支持**打字提问**与**语音转文字填框**，答案采用**前端打字机流式渲染**。C919/J20/Y20/Z20 四页已统一接入。

### 9.1 新协议：`query.text`（后端 websocket_server.py）

原有 WS 仅接受 5 类消息；现新增第 6 类，使**纯打字文本直达既有可信问答管线**（normalizer→检索→生成→自检→`answer.display`），无需 VAD/ASR 端点。

```json
{ "type": "query.text", "session_id": "…", "turn_id": "…",
  "audio_stream_id": "…", "text": "C919 的发动机型号是什么" }
```

- 实现：`_query_text()` 构造一个 `ASRResult(confidence=1.0, is_final=True, provider="client_text")`，复用 `orchestrator.handle_asr_result(endpoint_required=False)`，其后事件（`answer.display`、`clarification.required`、TTS 尝试）与原语音路径完全一致。
- 校验：缺少/空文本或过长（>2000 字符）→ `VOICE_PROTOCOL_INVALID`（field=`text`，close 4400）；未建会话直接发送 → 4400。

### 9.2 前端服务层调整（voiceAssistant.js）

- `openVoiceAssistantSession`：改为**只建会话不再自动开麦**（原实现会在 `session.started`/`scene.updated` 时自动 `startMic`）。
- 新增 `beginVoiceCapture()` / `endVoiceCapture()`：**按住说话**采集，`asr.partial` 实时把文字写入输入框（语音转文字），`asr.final` 定稿后自动停麦；松开手动结束。
- `askVoiceAssistant(question, …)`：改为真正通过 `client.sendTextPrompt(text)` 发送文本到后端。
- `voiceWsClient.js` 新增 `sendTextPrompt(text)`。
- 事件向聊天面板统一走 `voice-assistant:update`（kind：`transcript / answer / clarification / error / status / ready`）。

### 9.3 新增组件 `src/components/CoachChatPanel.vue`

右侧聊天面板（复用 `glass-panel` 毛玻璃风格）：
- 消息列表（用户/老师气泡，自动滚动到底）+ 底部输入框（回车发送）+ 发送按钮 + **按住说话**麦克风（🎤）。
- **打字机流式输出**：完整答案到达后按 30ms/字渐进追加 + 光标动画（`typewriter()`）。
- 面板 `onUnmounted` 时清理定时器、停麦、`closeVoiceAssistant()`。

### 9.4 页面接入

4 个 `CoreInteractionPage.vue` 把原 `coach-panel` 静态浮层替换为 `<CoachChatPanel scene=… aircraft=… @close=…>`，`toggleCoach` 简化为开关。
