# 翼览无余 · 部署指南

> 前端：Vue 3 + Vite 8 + Three.js　|　后端：Python 3.11+（yilan-ai-tutor，RAG 问答 / 语音交互）

## 一、前端部署

### 环境要求
- Node.js ≥ 20.19（推荐 22 LTS）

### 方式 A：直接部署构建产物（最快）
包内已附带构建好的 `挑战杯前端/dist/`，任意静态服务器指向该目录即可：

- 入口：`dist/index.html`；构建资源：`dist/assets/`；各机型素材：`dist/{c919,j20,y20,z20}-assets/`
- 本项目为 SPA 路由，需将未命中的请求 fallback 到 `index.html`

nginx 参考配置：

```nginx
server {
    listen 80;
    server_name _;
    root /var/www/c919;      # 指向 dist 目录
    index index.html;
    charset utf-8;           # 素材含中文路径，必须 UTF-8
    location / { try_files $uri $uri/ /index.html; }
    location ~* \.(js|css|png|jpg|mp4|glb|gltf)$ { expires 7d; }
}
```

无 nginx 时可临时预览：`npx serve dist`。

### 方式 B：从源码构建

```bash
cd 挑战杯前端
npm install
npm run dev        # 开发调试 http://localhost:5173
npm run build      # 产出 dist/
npm run preview    # 本地预览构建产物 http://localhost:4173
```

## 二、后端部署

### 环境要求
- Python ≥ 3.11

### 安装依赖

```bash
cd 挑战杯后端
python -m venv .venv
# Windows:      .venv\Scripts\activate
# Linux/macOS:  source .venv/bin/activate

pip install -r requirements.txt      # 顶层依赖（版本与 pyproject.toml 一致）
pip install -e .                     # 注册 yilan 命令行入口
```

> 项目同时附带 `uv.lock`，已安装 [uv](https://docs.astral.sh/uv/) 时可直接 `uv sync` 一键精确还原环境。
> `sentence-transformers` / `faster-whisper` 首次安装体积较大，网络受限时可加国内镜像：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### 配置

- 复制 `.env.example` 为 `.env`，按需填入模型 / 服务凭据
- 业务配置位于 `configs/`（providers / voice / rag / memory 等 YAML）

### 启动

```bash
# 主应用 CLI（查看可用子命令）
yilan --help

# 语音交互服务（WebSocket，默认 ws://127.0.0.1:8765）
python scripts/run_voice.py
python scripts/run_voice.py --host <局域网IP>   # 放开局域网访问（注意防火墙放行）
```

- 语音服务自带健康检查：`GET http://<host>:8765/health`
- 前端对接后端 API 的地址在前端 `.env.production` / `.env.development` 中配置

## 三、常见问题

| 现象 | 处理 |
|---|---|
| 刷新页面 404 | 静态服务器未配置 SPA fallback（`try_files ... /index.html`） |
| 中文素材路径 404 | 确保服务器对 UTF-8 URL 正确解码（nginx 默认支持，勿自行转义路径） |
| 大依赖安装慢/失败 | 使用国内镜像源，或改用 `uv sync` |
| 端口冲突 | 前端 dev 5173 / preview 4173 / 语音服务 8765，均可通过参数修改 |
