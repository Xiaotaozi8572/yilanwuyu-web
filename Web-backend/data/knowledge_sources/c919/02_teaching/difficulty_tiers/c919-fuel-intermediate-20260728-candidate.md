## 一、Parker-AVIC 燃油系统
C919 燃油系统由派克汉尼汾（Parker Hannifin）与中航工业合资公司提供。

**系统组成**：
- **油箱**：左/右机翼油箱 + 中央油箱
- **燃油泵**：每个油箱 2 台电动增压泵（冗余）
- **阀门**：交输阀、断流阀、加油阀、抽油阀
- **管路**：供油管、回油管、加油管
- **油量测量系统**：电容式传感器+油量计算机
- **惰性气体系统（IGS）**：中空纤维膜分离器
- **加油面板**：压力加油控制

## 二、油箱结构与容量
**三个油箱**：
- **左机翼油箱**：约 7,000 升
- **右机翼油箱**：约 7,000 升
- **中央油箱**：约 5,000 升
- **总容量**：约 19,000 升（约 15,300 kg 航空煤油，密度约 0.8 kg/L）

**油箱结构**：
- 机翼油箱：机翼内部蒙皮+翼梁+翼肋构成的密封空间
- 中央油箱：机身中部机翼根部
- 防漏设计：所有接头/检查口密封

**通气系统**：
- 每个油箱有通气管，通到机翼外的通气口
- 保证油箱内压力与外界平衡，防止油箱变形
- 通气口有浮子阀防止燃油外溢

## 三、供油逻辑
**正常供油顺序**：
1. 起飞阶段：使用中央油箱燃油（重心近）
2. 巡航阶段：中央油箱耗尽后切换到机翼油箱
3. 进近/着陆：使用机翼油箱燃油（重心稳定）

**为什么先耗中央油箱**：
- 中央油箱位于机身中部，燃油消耗对重心影响小
- 先消耗中央油箱可以让机翼油箱燃油继续卸载机翼弯矩
- 避免中央油箱长期存油（减少惰性气体系统负担）

**燃油泵冗余**：
- 每个油箱 2 台电动增压泵
- 主泵+备用泵
- 任一故障，另一台接替
- 双泵同时故障：交输供油（从对侧油箱供油）

## 四、交输供油（Crossfeed）
**用途**：当一侧油泵故障或一侧油箱燃油不平衡时，通过对侧油箱供油给两侧发动机。

**操作**：
- 飞行员打开交输阀（Crossfeed Valve）
- 故障侧关闭燃油泵（避免空转）
- 对侧油泵供油给两侧发动机
- 通过燃油管路交叉供油

**典型场景**：
- 左机翼油泵双故障 → 开交输阀 → 右机翼油泵供油给左右发动机
- 横滚不平衡 → 通过交输调整耗油顺序

## 五、加油/抽油
**压力加油**：
- 加油车通过压力加油接头（机翼下方）连接
- 加油压力约 50 psi（3.5 bar）
- 加油速度可达 1,000+ 升/分钟
- 加油面板可设置目标油量
- 自动分配到各油箱（按预设比例）

**加油控制逻辑**：
1. 飞行员/机务在加油面板设置总油量
2. 加油计算机计算各油箱加油量
3. 自动开启各油箱加油阀
4. 达到目标油量自动关闭加油阀
5. 关闭总加油阀，断开加油车

**抽油**：
- 维护时通过抽油阀反向抽油
- 把燃油从油箱抽到抽油车
- 用于油箱内部检查、修理

**重力加油（如配备）**：
- 部分机型配备重力加油口（机翼上方）
- 速度慢（< 200 升/分钟）
- 通常作为压力加油的备份

## 六、油量测量
**电容式油量传感器**：
- 探杆（长度贯穿油箱高度）
- 两层金属管，中间绝缘介质
- 燃油浸入传感器 → 改变电容值（燃油介电常数约 2.1，空气为 1）
- 电容值与浸入高度成正比

**多点测量**：
- 一个油箱多个传感器（典型 6-12 根）
- 分布在不同位置
- 应对飞机俯仰/横滚姿态变化

**油量计算机（FQPU）**：
- 接收各传感器信号
- 计算油面高度
- 根据油箱形状（三维油量表）计算体积
- 根据燃油密度计算重量
- 显示在 ECAM 上

**精度**：
- 满油时精度约 ±1-2%
- 低油量时精度降低
- 需定期校准

## 七、把概念串起来
- 想知道燃油系统供应商 → 看 **Parker-AVIC**
- 想知道油箱结构 → 看 **三油箱 + 通气系统**
- 想知道油怎么流 → 看 **供油逻辑 + 交输供油**
- 想知道怎么加油 → 看 **压力加油 + 抽油**
- 想知道怎么测油量 → 看 **电容式传感器 + FQPU**

## 进阶版小结
C919 燃油系统由 Parker-AVIC 合资提供，三个油箱（左右机翼+中央）总容量约 19,000 升；先耗中央油箱再耗机翼油箱保持重心；双泵冗余+交输供油保证任一故障仍能供油；压力加油 1,000+ 升/分钟，自动分配；电容式油量传感器多点测量，FQPU 计算总油量。
