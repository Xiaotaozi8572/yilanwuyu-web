## 一、飞机为什么需要液压
C919 重 70 多吨，飞行员用胳膊怎么搬动那么大的舵面？答案是用液压——液体传力。

飞机上凡是需要"大力气"的地方，几乎都靠液压：
- 推动舵面（让飞机俯仰/滚转/偏航）
- 收放起落架
- 刹车
- 反推装置

## 二、液压是什么：水压类比
**帕斯卡定律**：密闭液体中的压力可以向各个方向等值传递。

简单说：你在一头推液体，液体在另一头就能推别的东西。压力 = 力 ÷ 面积（P=F/A）。

- 小活塞推液体 → 液体推大活塞 → 大活塞面积大，受力就大
- 这就是液压千斤顶的原理——用小力气推动重物

**演示**：拿两个注射器用管子连起来，推小注射器，大注射器会被推出来——大注射器受力更大。

C919 液压压力是 3000 psi，约等于 200 个大气压——比汽车轮胎气压（约 2-3 个大气压）高 100 倍！

## 三、液压系统怎么组成
液压系统像家里的水管系统：
- **泵**：像水泵，产生压力
- **油箱**：像水塔，储存液压油
- **管路**：像水管，传输压力
- **作动器**：像水龙头，把压力变回机械力
- **阀门**：像水龙头开关，控制流向

但液压油不是普通机油，是专用阻燃液压油（如 Skydrol），高温下不燃、低温下不凝固。

## 四、C919 液压用在哪里
1. **飞控舵面**：副翼、升降舵、方向舵、扰流板——飞行员推侧杆，电信号传到作动器，作动器推动舵面
2. **起落架**：起落架收放、刹车、前轮转弯
3. **反推**：发动机反推装置展开/收起
4. **缝翼/襟翼**：增升装置的展开/收起

## 五、怎么保证液压不断油：三套系统
液压失效是大麻烦——舵面动不了飞机就失控。C919 装了 3 套独立液压系统（A/B/C），每套独立泵源、独立管路、独立油箱。

**泵源**：
- **EDP（发动机驱动泵）**：每台主发动机带一台
- **EMP（电动泵）**：电动备份
- **RAT（冲压空气涡轮）**：紧急情况下从机身放出，靠气流驱动发电+液压

**工作逻辑**：
- 正常时 3 套并行工作
- 任一套故障，其余接替
- 三套都故障，RAT 应急供压给关键舵面

像"三条腿凳子，断一条还能站"。

## 六、一个生活类比总结
- 液压 = 水管系统传力
- 帕斯卡定律 = 你推一头，另一头被推
- 3000 psi = 200 个大气压
- 三套系统 = 三条腿凳子
- RAT = 应急手摇发电机

## 入门版小结
C919 液压系统用 3000 psi 高压液体传力，驱动舵面/起落架/反推/增升装置。三套独立液压系统+EDP/EMP/RAT 多种泵源保证余度。液压油是专用阻燃合成油，不是普通机油。
