# C919 电气系统 · 入门版

> 来源说明：本文基于 01_science 已收集的 C919 电气资料派生，用于教学组织，不作为科学事实证据源。数据截至 2026-07-28。
> 难度档：入门（面向无航空背景的普通公众，用家庭电路类比电气系统，不涉及术语）

## 这一档要回答的问题
1. 飞机上的电从哪来？
2. 飞机的电和家里的电一样吗？
3. C919 怎么保证不会断电？

## 一、飞机的电从哪来
家里插头一插就有电，那是发电厂送的。飞机飞在 1 万米高空，电从哪来？

C919 的电主要来自：
- **发动机发电机**：两台主发动机各带一台发电机，发动机转动时顺便发电
- **APU 发电机**：尾部辅助动力装置（APU）也带一台发电机
- **地面电源**：地面停靠时由地面电源车（GPU）供电

## 二、飞机的电和家里的电不一样
家里是 220V/50Hz 交流电，飞机的电完全不同：
- **电压**：115V（不是 220V）
- **频率**：400Hz（不是 50Hz）
- **类型**：三相交流电

**为什么 400Hz**：高频可以减小变压器和电机的体积重量——飞机对重量极敏感。同样功率的发电机，400Hz 比 50Hz 小很多。

**为什么 115V**：安全与绝缘权衡，不是越高压越好。

C919 还有 28V 直流电（给计算机、应急设备）和 270V 高压直流（部分系统）。

## 三、C919 怎么保证不断电
飞机断电是大麻烦——飞控、航电、照明全部失效。C919 装了多重余度：

1. **多发电机并联**：两台 IDG（发动机发电机）+ APU 发电机，任一故障其余接替
2. **蓄电池**：镍镉蓄电池组，应急时可供电约 30-60 分钟
3. **RAT（冲压空气涡轮）**：紧急情况从机身放出，靠气流驱动一台小型发电机+液压泵

像家里的"市电 + 柴油发电机 + UPS + 电池"多层备份。

## 四、电怎么送到每个设备
飞机里有"汇流条"——电力的主干道，把发电机/电源的电分配到各子系统：
- **主交流汇流条**：输送 115V/400Hz 交流电
- **直流汇流条**：输送 28V 直流电
- **应急汇流条**：紧急情况给关键设备供电
- **蓄电池汇流条**：永远不断电的关键设备

每个回路有断路器（CB），过流时自动跳闸保护——像家里的空气开关。

## 五、C919 电气系统的特点
- **IDG（整体驱动发电机）**：每台主发动机带一台，单台容量约 90 kVA
- **270VDC 高压直流**：部分系统采用，减小线缆重量
- **ELMC（电气负载管理中心）**：计算机自动管理负载通断
- **变压整流器（TRU）**：把交流电转换为直流电
- **自动负载卸载**：紧急情况下自动卸载非关键负载（如厨房、娱乐），保证飞控/航电供电

C919 电气系统由 Hamilton Sundstrand（现 RTX）与中航工业合资提供。

## 六、应急供电示例
典型场景：双发停车（如萨利机长哈德逊河迫降）
1. 双发停车 → 主发电机停转
2. APU 启动 → APU 发电机接替
3. APU 也故障 → RAT 放出
4. 蓄电池短暂供电
5. 飞控/航电/基本仪表仍能工作
6. 飞行员操控迫降

## 七、一个生活类比总结
- 发动机发电机 = 发电厂
- APU 发电机 = 备用柴油发电机
- 蓄电池 = UPS 不间断电源
- RAT = 应急手摇发电机
- 汇流条 = 家里的电箱
- 断路器 = 空气开关
- 400Hz = 高频减小体积

## 入门版小结
C919 电气系统由 Hamilton Sundstrand-AVIC 合资提供，主电源为 2 台 IDG（90 kVA）+ APU 发电机，115V/400Hz 三相交流 + 28V/270VDC 直流；多发电机+蓄电池+RAT 多重余度保证不断电；ELMC 自动管理负载，紧急时卸载非关键负载保证飞控/航电。
