# C919 电气系统 · 进阶版

> 来源说明：本文基于 01_science 已收集的 C919 电气资料派生，用于教学组织，不作为科学事实证据源。数据截至 2026-07-28。
> 难度档：进阶（面向已了解电气基本概念的受众，引入 Hamilton Sundstrand-AVIC、发电机、IDG、ELMC 等概念）

## 这一档要回答的问题
1. C919 发电机由谁提供、有什么特点？
2. IDG 怎么保持恒频输出？
3. ELMC 电气负载管理中心怎么工作？

## 一、Hamilton Sundstrand-AVIC 电气系统
C919 电气系统由汉胜（Hamilton Sundstrand，现 RTX/雷神技术）与中航工业合资公司提供。

**主要设备**：
- **IDG（整体驱动发电机）**：2 台（左右发动机各一）
- **APU 发电机**：1 台
- **变压整流器（TRU）**：4 台
- **蓄电池**：镍镉蓄电池组
- **ELMC（电气负载管理中心）**：多台
- **RAT（冲压空气涡轮）**：1 台
- **配电中心**：交流/直流配电板

## 二、IDG（Integrated Drive Generator）
**IDG = 恒速传动装置（CSD）+ 发电机**

**为什么需要恒速**：
- 发动机转速变化（慢车到起飞转速差约 2 倍）
- 交流电频率取决于发电机转速
- 要保持 400Hz 恒频，必须让发电机转速恒定

**CSD（Constant Speed Drive）工作原理**：
- 液压机械式恒速传动
- 输入轴转速变化 → 内部液压泵/马达调节 → 输出轴转速恒定
- 输出转速恒定在 12,000 RPM（典型）
- 驱动发电机输出 400Hz 恒频

**发电机部分**：
- 三级无刷交流发电机
- 转子（励磁机+主发电机+旋转整流器）
- 定子（主发电机绕组）
- 输出 115V/400Hz 三相交流

**容量**：
- C919 IDG 单台容量约 90 kVA
- A320 IDG 约 90 kVA，B737 IDG 约 90 kVA（同代同级）

**IDG 滑油冷却**：
- IDG 内部有滑油循环润滑+冷却
- 通过 IDG 滑油散热器冷却
- 滑油温度超温告警

**IDG 脱开**：
- IDG 严重故障（如卡死）时，飞行员可按电门脱开 IDG
- 脱开后 IDG 不再由发动机驱动
- 脱开后不可在空中复位

## 三、APU 发电机
**APU（Honeywell HGT750[C]）**：
- APU 本身是小型燃气涡轮
- APU 带一台发电机（容量约 90 kVA）
- 输出与 IDG 相同的 115V/400Hz 三相交流
- 地面/空中都能供电

**APU 发电机用途**：
- 地面：发动机不工作时主供电
- 空中：发动机故障时接替
- 起飞/着陆：作为备份

## 四、变压整流器（TRU）
**TRU = 变压器 + 整流器**

**功能**：
- 输入：115V/400Hz 三相交流
- 输出：28V 直流
- 容量：约 100-200A

**原理**：
1. 变压器降压：115V → 28V 交流
2. 整流器：6 脉冲或 12 脉冲整流
3. 滤波：电容+电感滤波
4. 输出：28V 直流

**用途**：
- 给飞控计算机、航电、应急设备供电
- 给蓄电池充电

**C919 配置**：4 台 TRU，分属不同汇流条。

## 五、ELMC 电气负载管理中心
**ELMC（Electrical Load Management Center）**：
- 由计算机控制负载通断
- 接收 BITE 自检测信息
- 根据电源状态自动管理负载

**ELMC 功能**：
1. **正常负载管理**：按预设逻辑控制负载通断
2. **负载卸载（Load Shedding）**：
   - 电源不足时自动卸载非关键负载
   - 优先级：飞控/航电 > 照明 > 厨房 > 娱乐
3. **故障隔离**：检测到过流/短路，自动跳闸
4. **重构**：电源故障后，自动切换到备用电源

**典型卸载逻辑**：
- 单台 IDG 故障 → 卸载厨房、部分照明
- 双 IDG 故障 → APU 接替，仍卸载部分负载
- APU 也故障 → 仅保留飞控/航电/基本仪表，蓄电池供电

## 六、蓄电池
**镍镉蓄电池（Ni-Cd）**：
- 容量：约 20-40 Ah
- 电压：24V 直流（标称）
- 优点：高倍率放电、耐高温、寿命长
- 缺点：记忆效应、需定期容量检查

**用途**：
- 应急供电（30-60 分钟）
- 启动 APU
- 飞控/航电的不间断电源

**充电**：
- 由 TRU 通过蓄电池充电器充电
- 充电电流受控，防止过充

## 七、汇流条架构
**C919 主要汇流条**：
- **左交流汇流条**：左 IDG 供电
- **右交流汇流条**：右 IDG 供电
- **APU 交流汇流条**：APU 发电机供电
- **地面电源汇流条**：地面电源车供电
- **左直流汇流条**：左 TRU 供电
- **右直流汇流条**：右 TRU 供电
- **应急直流汇流条**：蓄电池供电
- **蓄电池汇流条**：永远不断电

**转换逻辑**：
- 正常：左右 IDG 各供左右交流汇流条
- 任一 IDG 故障：APU 接替，或交叉供电
- 全故障：蓄电池+RAT 供应急汇流条

## 八、把概念串起来
- 想知道发电机怎么恒频 → 看 **IDG + CSD**
- 想知道交流怎么变直流 → 看 **TRU**
- 想知道负载怎么管理 → 看 **ELMC**
- 想知道应急电源 → 看 **蓄电池 + RAT**

## 进阶版小结
C919 电气由 Hamilton Sundstrand-AVIC 合资提供，2 台 IDG（90 kVA，CSD 恒速）+ APU 发电机；4 台 TRU 把 115V/400Hz 转 28VDC；ELMC 自动管理负载，电源不足时按优先级卸载；镍镉蓄电池应急 30-60 分钟；多汇流条架构实现故障切换与重构。
