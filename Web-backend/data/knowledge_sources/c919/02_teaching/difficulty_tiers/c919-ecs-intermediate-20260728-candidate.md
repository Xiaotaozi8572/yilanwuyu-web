# C919 环控系统 · 进阶版

> 来源说明：本文基于 01_science 已收集的 C919 环控资料派生，用于教学组织，不作为科学事实证据源。数据截至 2026-07-28。
> 难度档：进阶（面向已了解环控基本概念的受众，引入 Liebherr、引气系统、座舱增压等概念）

## 这一档要回答的问题
1. C919 环控由谁提供、有什么特点？
2. 引气系统怎么从发动机"借"空气？
3. 座舱增压的具体控制逻辑是什么？

## 一、Liebherr 环控系统
C919 环控系统（ECS）由利勃海尔（Liebherr）提供，主要包括：
- **引气系统（Pneumatic System）**：从发动机/APU 引气
- **空调组件（Air Conditioning Pack）**：2 台，处理引气
- **座舱增压系统（Pressurization System）**：控制客舱压力
- **温度控制系统（Temperature Control System）**：多区调温
- **空气分配系统（Air Distribution）**：送风到客舱/驾驶舱

## 二、引气系统
**引气来源**：
- **发动机引气**：从高压压气机（HPC）中段或后段引出
- **APU 引气**：APU 提供的压缩空气
- **地面气源车**：地面停靠时由地面气源车供气

**引气处理**：
1. **压力调节**（PRV，Pressure Regulating Valve）：调到约 40-50 psi
2. **预冷器**（Precooler）：用外界冷空气冷却引气到约 200℃
3. **流量控制**（FCV，Flow Control Valve）：控制进入 Pack 的流量
4. **过压保护**：OPV（Overpressure Valve）防止超压

**引气用途**：
- 空调组件（Pack）供气
- 发动机进气道防冰
- 机翼防冰
- 水箱增压
- 液压油箱增压

## 三、空调组件（Pack）
**Pack 组成**：
- **主热交换器**（Primary Heat Exchanger）：用外界空气冷却引气
- **次热交换器**（Secondary Heat Exchanger）：进一步冷却
- **空气循环机（ACM，Air Cycle Machine）**：压缩机+涡轮+风扇同轴
- **冷凝器/水分离器**：除湿
- **再加热器**：调节温度

**空气循环制冷工作流程**：
1. 引气进入主热交换器，被外界冷空气初步冷却
2. 进入 ACM 压缩机，被压缩升温
3. 进入次热交换器，再冷却
4. 进入 ACM 涡轮，膨胀降温（降温到 0℃ 左右）
5. 冷凝器除湿，水分离器分离水分
6. 与部分热引气混合调温
7. 送入客舱

**Pack 特点**：
- 不用氟利昂（环保）
- 用"空气膨胀制冷"原理
- 效率高、重量轻

## 四、座舱增压系统
**压力控制**：
- **外流阀（Outflow Valve）**：通常位于机身尾部下方
- 由两个电机驱动（正常+应急）
- 开大 → 客舱放气多 → 压力下降（客舱压力高度上升）
- 关小 → 客舱放气少 → 压力上升（客舱压力高度下降）

**控制逻辑**：
- **起飞前**：客舱压力预增压（防止起飞瞬间压力波动）
- **爬升**：客舱压力按计划下降，变化率受控（≤ 300m/min）
- **巡航**：保持目标客舱压力高度（C919 约 1,830m）
- **下降**：客舱压力按计划上升，变化率受控（≤ 150m/min）
- **着陆**：客舱压力等于机场压力

**C919 客舱压力高度**：
- 巡航高度 11,000m 时客舱压力高度约 1,830m
- 等效压差约 0.06-0.07 MPa
- 低于传统 2,400m，更舒适

**安全阀**：
- **正压释放阀**：防止客舱压差超限（约 0.08-0.09 MPa）
- **负压释放阀**：防止客舱负压

**应急下降**：
- 客舱失压（压力高度 > 4,300m）→ 氧气面罩自动落下
- 飞行员紧急下降到 3,000m 以下

## 五、温度控制
**分区**：
- 驾驶舱
- 前客舱
- 后客舱
- 货舱（部分机型可调）

**控制原理**：
- 每区有温度传感器
- 区温度控制阀调节冷热空气混合比
- 维持目标温度（通常 22-24℃）

## 六、空气分配
**送风方式**：
- 顶部送风（天花板上方的风道）
- 侧壁送风（行李架下方）
- 地板附近回风

**新风比例**：
- 每分钟换气约 20-30 次
- 部分 recirculation（再循环）+ 部分新风
- HEPA 过滤器滤除 99.97% 颗粒

## 七、把概念串起来
- 想知道空气从哪来 → 看 **引气系统**
- 想知道空气怎么处理 → 看 **空调组件（Pack）**
- 想知道压力怎么控制 → 看 **外流阀 + 增压系统**
- 想知道温度怎么调 → 看 **温度控制 + 分区**

## 进阶版小结
C919 环控由 Liebherr 提供，引气系统从发动机/APU 引气（PRV+预冷器+FCV）；2 台空调组件用空气循环制冷（主/次热交换器+ACM+水分离器）；座舱增压由外流阀控制，客舱压力高度 1,830m（低于传统 2,400m），配正/负压安全阀；温度分区控制，HEPA 过滤 99.97% 颗粒。
