## 一、惰性气体系统（IGS）
**背景**：TWA 800 航班（1996）空难原因是中央油箱爆炸——燃油蒸汽与空气混合遇火源引爆。FAA/EASA 随后要求新机型油箱惰性化。

**IGS 工作原理**：
1. **引气**：从发动机或 APU 引出高温高压空气
2. **预处理**：通过热交换器降温、过滤
3. **中空纤维膜分离**：
   - 膜组件由数千根中空纤维管组成
   - 纤维膜材料对不同气体有选择性渗透
   - 氧气（O₂）渗透速率快，水蒸气（H₂O）渗透更快
   - 氮气（N₂）渗透速率慢
4. **分离结果**：
   - 渗透侧（外侧）：富氧空气（OEA），排放到机外
   - 非渗透侧（内侧）：富氮空气（NEA），氮气含量 > 95%
5. **充入油箱**：NEA 通过管路进入油箱上方空间

**氮气惰性化原理**：
- 油箱上方空间原本是空气（O₂ 约 21%）
- 充入 NEA（N₂ > 95%）后，O₂ 浓度被稀释
- 当 O₂ 浓度 < 12%（按飞行高度调整）时，燃油蒸汽无法点燃
- 这是"-limit oxygen concentration"原理

**O₂ 浓度限值**：
- 海平面：O₂ < 12%
- 巡航高度（11,000m）：O₂ < 9-10%（高空气压低，O₂ 限值随压力变化）
- 通过 O₂ 传感器实时监测

**适航要求**：
- CCAR-25.981 燃油点燃防护
- 油箱上方空间 O₂ 浓度全程低于限值

## 二、油量测量精度
**测量误差来源**：
1. **传感器误差**：电容传感器制造公差、温度漂移
2. **姿态误差**：飞机俯仰/横滚时油面倾斜，单点测量不准
3. **密度误差**：航空煤油密度随温度变化（约 0.8 kg/L，温差 10℃ 变化约 1%）
4. **油箱形状误差**：油箱形状复杂，体积-高度关系非线性

**多点测量补偿**：
- 一个油箱 6-12 根传感器
- 不同位置采样
- FQPU 通过加权平均计算平均油面高度
- 应对姿态变化

**密度补偿**：
- 油箱内布置密度传感器（振动管式）
- 测量燃油实时密度
- 按密度将体积换算为重量

**温度补偿**：
- 油箱内温度传感器
- 修正电容传感器温度漂移
- 修正燃油密度温度变化

**三维油量表（Tank Quantity Table）**：
- 油箱形状通过测绘建立"油面高度-体积"三维表
- FQPU 查表得到体积
- 配合密度得到重量

**精度目标**：
- 满油：±1-2%
- 半油：±2-3%
- 低油量：±3-5%

## 三、油泵余度与故障切换
**双泵冗余**：
- 每个油箱 2 台电动增压泵（主+备）
- 主泵正常工作
- 主泵故障/压力低 → 备用泵自动启动
- 双泵故障 → 交输供油

**泵类型**：
- **离心泵**：常用，流量大、压力稳定
- **喷油泵（Immersion Pump）**：浸入燃油中，电机+泵一体
- 无油干转保护：检测到油面低于泵入口 → 关闭泵防止空转损坏

**故障检测**：
- 压力开关监测泵输出压力
- 电流传感器监测泵电流
- 低压力/高电流 → 触发故障告警

**交输供油切换**：
1. 故障侧泵关闭
2. 飞行员打开交输阀
3. 对侧油泵供油给两侧发动机
4. ECAM 显示交输状态

## 四、燃油温度管理
**航空煤油特性**：
- Jet A-1 冰点 -47℃
- C919 使用 Jet A-1 或国产 RP-3 航空煤油
- 高空巡航时外界温度可达 -56℃

**温度风险**：
- 燃油温度过低 → 接近冰点 → 蜡结晶 → 堵塞滤网/管路
- 燃油温度过高 → 蒸汽压升高 → 汽阻风险

**温度管理**：
- **油箱温度传感器**：每个油箱布置温度传感器
- **燃油冷却器**：部分机型用燃油/空气热交换器冷却发动机滑油（同时给燃油加热）
- **低温告警**：燃油温度接近冰点（如 -37℃）触发告警
- **处置**：下降到较暖空域/加速（气动加热）

**C919 燃油温度**：
- 巡航中燃油温度通常 -20℃ 到 0℃
- 不会接近冰点（除非长时间极地航线）

## 五、燃油系统适航要求
**CCAR-25 燃油系统条款**：
- **25.951** 燃油系统总则
- **25.953** 独立燃油系统（多油箱独立性）
- **25.955** 燃油流量（保证最大流量满足发动机需求）
- **25.961** 燃油系统热气候（高温不汽阻）
- **25.963** 燃油箱（结构强度、防漏）
- **25.965** 燃油箱试验（压力试验）
- **25.967** 燃油箱安装
- **25.969** 燃油箱不可燃性
- **25.981** 燃油点燃防护（IGS 要求）
- **25.993** 燃油系统导管
- **25.995** 燃油阀
- **25.997** 燃油关断阀
- **25.999** 燃油系统排液
- **25.1001** 燃油 jettison（应急放油，C919 通常无）

## 六、C919 燃油的工程权衡
- **三油箱 vs. 两油箱**：三油箱（含中央）增加灵活性但增加复杂性
- **双泵 vs. 单泵**：双泵冗余更安全但增重
- **IGS vs. 无 IGS**：IGS 防爆但增重、增加维护（FAA/EASA 强制，CAAC 跟进）
- **压力加油 vs. 重力加油**：压力加油快但需加油车
- **国产化**：Parker-AVIC 合资，外方掌握核心泵/阀/IGS 技术

## 深入版小结
C919 燃油系统配 IGS 惰性气体系统（中空纤维膜分离 N₂ > 95%，O₂ < 12% 惰性化）；油量测量多点电容传感器+密度补偿+温度补偿+三维油量表，精度 ±1-2%；双泵冗余+交输供油保证任一故障仍供油；按 CCAR-25.951-.1001 验证，含 25.981 燃油点燃防护（IGS）；燃油温度管理保证 Jet A-1 不接近 -47℃ 冰点。
