## 这一档要回答的问题
1. C919 主起落架由谁提供、有什么特点？
2. 前轮转向系统怎么工作？
3. 收放系统的逻辑是什么？

## 一、主起落架：Liebherr LAMC
C919 主起落架由利勃海尔（Liebherr）与中航工业合资公司提供，型号 LAMC 系列。

**主起落架结构**：
- **缓冲支柱（Oleo Strut）**：吸收着陆冲击和滑行颠簸
  - 工作原理：油气式缓冲器，气体（氮气）压缩吸能、油液阻尼耗能
- **轮轴（Axle）**：安装机轮
- **扭力臂（Torque Links）**：防止支柱旋转
- **侧撑杆（Side Strut）**：固定支柱位置
- **收放作动器**：驱动收放

**主起落架收起位置**：收入机身/机翼根部的起落架舱，舱门关闭后气动平滑。

**缓冲支柱工作原理**：
1. 着陆冲击 → 活塞向上压入缸体
2. 缸内氮气被压缩（吸能）
3. 油液通过节流孔产生阻尼（耗能）
4. 反弹时油液缓慢回流（防止反弹过快）

## 二、前起落架与转向
**前起落架结构**：
- 缓冲支柱
- 双轮（2 个机轮）
- 转向作动器
- 收放作动器

**前轮转向系统（Honeywell 提供）**：
- **转向作动器**：液压驱动前轮转向
- **控制输入**：
  - 低速（< 20 kt）：手轮（Tiller）控制，转向角度可达 ±70°
  - 中速（20-130 kt）：方向舵脚蹬控制，转向角度 ±7°
  - 高速（> 130 kt）：方向舵气动效应主导，前轮转向锁定或小幅
- **自动中心**：起飞后前轮自动对中，便于收起

**差动刹车辅助**：
- 低速大角度转向时，左右主轮差动刹车辅助
- 提高地面机动性

## 三、收放系统
**收放逻辑**：
1. **正常收起**：飞行员拉起落架手柄到 UP → 液压作动器收起起落架 → 上位锁锁住 → 舱门关闭
2. **正常放下**：飞行员拉手柄到 DOWN → 舱门打开 → 开下位锁 → 起落架放下 → 下位锁锁住 → 舱门关闭
3. **应急放下**：液压失效时 → 转动应急手柄 → 机械开锁 → 起落架靠重力自由落下 → 下位锁锁住

**舱门顺序**：
- 收起：开舱门 → 收起落架 → 关舱门
- 放下：开舱门 → 放起落架 → 关舱门
- 顺序阀保证各步骤按序执行

**位置指示**：
- 每个起落架有"上位锁/下位锁"位置传感器
- 驾驶舱 ECAM 显示起落架位置（UP/DOWN/UNSAFE）
- 三个绿灯 + 一个手柄 = 机械备份指示

## 四、机轮与刹车
**机轮（Michelin Air X）**：
- **轮胎**：航空专用，多层帘布、特种橡胶、充氮气
- **充气压力**：约 14 bar（200 psi），约 14 个大气压
- **爆胎防护**：充氮气防燃防爆，多层结构防飞溅
- **寿命**：按起落次数限制，定期翻新/更换

**刹车（Carbenix 碳/碳盘式）**：
- **结构**：多片碳/碳复合材料刹车盘叠在一起，液压夹紧产生摩擦
- **优点**：耐高温（> 1000℃）、重量轻（比钢刹车轻约 40%）、寿命长
- **冷却**：刹车后需冷却（约 15-30 分钟）才能再次起飞
- **温度监控**：刹车温度传感器，超温告警

**反推（发动机反推）**：
- 着陆时发动机气流反向喷出
- C919 整体式反推短舱（窄体客机首创）
- 反推集成在短舱内，减重降阻

## 五、刹车系统控制
**BSCU（Brake System Control Unit，刹车控制单元）**：
- 接收飞行员脚蹬输入
- 控制刹车液压压力
- 防滑控制（Anti-skid）：防止机轮锁死打滑
- 差动刹车：辅助转向
- 自动刹车（Auto-brake）：可选 1/2/3/MAX 档位

**防滑原理**：
- 机轮速度传感器监测转速
- 检测到机轮即将锁死（减速率超阈值）→ 释放刹车压力
- 机轮恢复转动 → 重新施加刹车
- 每秒数次循环，保持最大摩擦力

## 六、把概念串起来
- 想知道主起落架结构 → 看 **Liebherr LAMC + 缓冲支柱**
- 想知道前轮怎么转 → 看 **Honeywell 转向系统 + 手轮/脚蹬**
- 想知道起落架怎么收放 → 看 **收放系统 + 应急放下**
- 想知道怎么刹车 → 看 **Carbenix 碳盘 + BSCU + 防滑**

## 进阶版小结
C919 主起落架由 Liebherr-AVIC 提供（LAMC 系列），油气缓冲支柱+侧撑杆+收放作动器；前轮转向由 Honeywell 提供，低速手轮±70°、中速脚蹬±7°、高速锁定；收放系统正常液压+应急重力放下，舱门顺序阀控制；刹车用 Carbenix 碳盘 + BSCU 防滑控制 + 自动刹车，配米其林 Air X 轮胎。
