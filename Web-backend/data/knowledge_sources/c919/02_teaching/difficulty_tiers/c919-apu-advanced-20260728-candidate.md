## 一、APU 空中启动
**地面启动**：
- 蓄电池供电启动电机
- 启动电机带动 APU 高压转子转动
- 达到一定转速后喷油点火
- APU 自持

**空中启动（无风车辅助）**：
- 与地面类似，蓄电池或 IDG 供电启动电机
- 但高空空气稀薄，启动条件更苛刻
- FADEC 调整燃油流量适应高空

**空中风车启动（Windmill Start）**：
- 在一定空速下，气流吹动 APU 涡轮（如配备）
- 达到一定转速后喷油点火
- 需要足够空速（典型 250-300 kt 以上）
- 不依赖启动电机

**双发停车应急场景**：
1. 双发停车 → 主发电机停转 → 蓄电池供电
2. 飞行员启动 APU
3. APU 启动需在启动包线内（高度+空速）
4. APU 启动成功 → 供电给飞控/航电，引气给发动机重启
5. 飞行员尝试发动机空中重启

**关键参数**：
- APU 启动时间：典型 30-60 秒
- 启动成功率：在包线内 > 99%

## 二、高空启动包线
**启动包线限制因素**：

1. **空气密度**：
   - 高空空气稀薄，可用氧气少
   - 燃烧室点火困难
   - 需要更强点火系统

2. **温度**：
   - 高空低温（-56℃）
   - 燃油黏度增大，雾化差
   - 启动电机扭矩需求增大

3. **转速**：
   - 高空 APU 起转阻力大
   - 启动电机需更大功率

4. **燃油压力**：
   - 高空燃油可能汽化
   - 需增压泵保证燃油压力

**典型包线**：
- 高度：0-12,500m（约 41,000ft）
- 速度：0-300 kt
- 在包线内启动保证 > 99% 成功率
- 包线外启动成功率显著下降，可能需多次尝试

**包线图**：
- 横轴：空速
- 纵轴：高度
- 曲线划分：可启动区/不可启动区
- C919 HGT750[C] 包线覆盖典型巡航高度

## 三、APU 引气控制
**引气来源**：
- 从 APU 压气机中段引出压缩空气
- 引气压力约 40-50 psi
- 引气温度约 200℃

**引气控制阀**：
- **APU 引气阀（APU Bleed Valve）**：控制 APU 引气是否进入飞机引气系统
- **负载控制阀（LCV，Load Control Valve）**：根据需求调节引气流量

**控制逻辑**：
1. APU 启动稳定后，APU 引气阀可打开
2. 引气通过单向阀进入飞机引气总管
3. LCV 根据需求（空调/启动主发）调节流量
4. FADEC 监测引气压力/温度
5. 超压/超温自动关断保护

**与发动机引气协调**：
- 同一时间只能由一个气源供气（APU 或发动机）
- 通过引气阀切换
- 避免不同压力源冲突

## 四、APU 适航要求
**CCAR-25 APU 相关条款**：
- **25.901** 安装（动力装置总则）
- **25.903** 发动机（含 APU 安装）
- **25.961** 燃油系统热气候
- **25.1091** 进气系统
- **25.1101** 汽化器空气导管（引气）
- **25.1121** 排气系统
- **25.1141** 操纵机构总则
- **25.1189** 切断措施

**APU 专项 CRI**：
- APU 高空启动能力
- APU 应急供电/供气
- APU 火警/灭火系统

**APU 火警/灭火**：
- APU 舱内布置火警探测器（火焰/过热）
- 驾驶舱 APU 火警告警
- APU 灭火瓶（哈龙替代品）
- 飞行员可手动释放灭火剂
- APU 自动关机（火警时）

## 五、APU 燃油系统
**燃油来源**：
- 从主油箱（通常左机翼油箱）通过 APU 燃油泵供油
- APU 燃油泵通常为电动泵
- 油箱低位时 APU 可能否工作（需燃油压力）

**燃油控制**：
- FADEC 控制燃油流量
- 启动时低流量，加速时增流量
- 稳态时按负载调节

**燃油消耗**：
- APU 典型油耗 100-200 kg/小时
- 地面长时间运行显著耗油

## 六、APU 噪音与排放
**噪音**：
- APU 是飞机地面噪音主要来源之一
- 进气口/排气口噪音
- 通过消音器、隔音棉降噪

**排放**：
- APU 燃烧产生 CO₂、NOx
- 机场对 APU 使用有时间限制（环保）
- 部分机场要求优先用地面电源车，减少 APU 使用

## 七、C919 APU 的工程权衡
- **APU 容量**：90 kVA + 引气，与 A320/B737 同代
- **高空启动能力**：12,500m 覆盖典型巡航高度，满足应急需求
- **APU vs. RAT**：APU 提供较长时间应急供电（小时级），RAT 仅最低限度（30-60 分钟）
- **国产化**：Honeywell 提供，外方掌握核心机技术，国产化仍在爬坡
- **未来**：C919 改型可能考虑更先进 APU（如更高效率、更低排放）

## 深入版小结
C919 APU（HGT750[C]）空中启动包括电机启动和风车启动，高空启动包线受空气密度/温度/转速/燃油压力限制（典型 0-12,500m、0-300 kt）；引气通过 APU 引气阀+LCV 控制，FADEC 监测保护；按 CCAR-25.901-.1189 验证，配火警探测+灭火系统；APU 燃油从主油箱经 APU 燃油泵供油，FADEC 控制流量。
