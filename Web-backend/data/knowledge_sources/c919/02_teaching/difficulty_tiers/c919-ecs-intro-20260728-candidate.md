# C919 环控系统 · 入门版

> 来源说明：本文基于 01_science 已收集的 C919 环控资料派生，用于教学组织，不作为科学事实证据源。数据截至 2026-07-28。
> 难度档：入门（面向无航空背景的普通公众，用空调类比环控，不涉及术语）

## 这一档要回答的问题
1. 飞机客舱的空气从哪来？
2. 高空那么冷、那么缺氧，客舱为什么舒服？
3. C919 的"空调"和家里的空调一样吗？

## 一、飞机的"空调"：环控系统
飞机在高空飞行，外面气温可达 -56℃、空气稀薄（含氧量约为地面 1/4）。但客舱里温暖、有氧气、能呼吸——靠的是环控系统（ECS，Environmental Control System）。

C919 环控系统由利勃海尔（Liebherr）提供。

## 二、空气从哪来：引气系统
客舱空气来自发动机或 APU 的"引气"——从发动机压气机引出一部分高温高压空气。

**引气流程**：
1. 发动机压气机引气（高温高压，约 200℃）
2. 压力调节阀调压
3. 预冷器降温（用外界冷空气冷却）
4. 进入空调组件（Pack）

## 三、空调组件：降温除湿
空调组件（Pack）把引气处理成适合客舱的空气：
- **降温**：通过热交换器+空气循环制冷机降温
- **除湿**：水汽凝结分离
- **过滤**：HEPA 过滤器滤除细菌/病毒

处理后的空气温度约 0-10℃，再与部分热引气混合调到舒适温度（约 22-24℃）。

## 四、座舱增压：让客舱像在低海拔
高空空气稀薄，如果不增压，乘客会缺氧。C919 通过增压让客舱气压保持在高海拔较低的水平。

**C919 客舱压力高度**：约 1,830 米
- 相当于身处海拔 1,830 米的地方（如昆明）
- 比传统客舱的 2,400 米（8,000 英尺）更低
- 气压更高、氧气更多，长途飞行更不疲劳

**压力怎么控制**：
- 空气进入客舱（空调组件供气）
- 客舱压力由"外流阀"控制——开大放气多、压力低，关小放气少、压力高
- 自动调节保持目标压力高度

## 五、C919 环控的特点
- **客舱压力高度 1,830m**：低于传统 2,400m，更舒适
- **HEPA 过滤**：滤除 99.97% 细菌/病毒
- **LED 情景照明**：模拟日出/日落/星空
- **空气循环制冷**：高效节能
- **温度分区**： cockpit/前客舱/后客舱可独立调温

## 六、应急情况
**客舱失压**：
- 客舱压力高度超过 4,300m 时氧气面罩自动落下
- 化学氧气发生器供氧 12-15 分钟
- 飞行员紧急下降到 3,000m 以下

**空调故障**：
- 双 Pack 故障：仍有一定供气能力（部分引气直接进入客舱）
- 单 Pack 故障：另一 Pack 接替

## 七、一个生活类比总结
- 环控系统 = 飞机的"空调+新风+加压"
- 引气 = 从发动机"借"空气
- 空调组件 = 家用空调的室外机+室内机
- 增压 = 让客舱像在 1,830 米海拔
- HEPA 过滤器 = 口罩+空气净化器

## 入门版小结
C919 环控系统由 Liebherr 提供，从发动机/APU 引气，经空调组件（空气循环制冷+HEPA 过滤）处理后送入客舱；客舱压力高度 1,830m（低于传统 2,400m，更舒适）；外流阀调节压力，HEPA 滤除 99.97% 细菌/病毒；LED 情景照明模拟日出/日落。
