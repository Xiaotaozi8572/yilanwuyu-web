# C919 气动原理与机翼设计 · 入门版

> 来源说明：本文基于 01_science/03_principles 中 C919 气动原理资料派生，用于教学组织，不作为科学事实证据源。数据截至 2026-07-28。
> 难度档：入门（面向无航空背景的普通公众，不涉及公式）

## 这一档要回答的问题
1. 飞机为什么能飞起来？
2. 飞机在天上"顶风"飞行，是什么在拖慢它？
3. C919 的机翼为什么"长得不一样"？

## 一、升力：把飞机托起来的力
飞机能飞，最关键的就是机翼。

机翼的截面不是平板，而是上表面弯、下表面平的形状（叫"翼型"）。当飞机向前跑，空气从机翼上下两面流过：
- 上表面弯度大，空气被"挤"得跑得更快，压力变小；
- 下表面平，空气跑得慢，压力变大。

下面压力大、上面压力小，机翼就被"托"起来了——这个向上的力就是**升力**。

除了压力差，机翼还会把迎面来的空气往下"推"。根据"作用力与反作用力"的道理，空气反过来给机翼一个向上的力，这也是升力的一部分。

只要飞机飞得够快、机翼角度合适，升力就能大到托起 70 多吨的 C919。

## 二、阻力：拖慢飞机的力
空气不是"空"的，飞机在空气里飞，空气会反过来拽住飞机，这个拽住的力就是**阻力**。

阻力主要分两类：
- **废阻力**：空气撞在机头、机身、机翼上产生的"挡路"的力。就像你骑自行车迎风冲，风把你往后推。
- **诱导阻力**：这是机翼产生升力时"附赠"的代价。机翼下面压力高、上面压力低，到了翼尖（机翼最外端），下面的高压空气会往上翻，形成一个个旋转的涡流。这些涡流会"偷走"一部分能量，变成阻力。

发动机的推力，就是为了克服这些阻力，让飞机能持续向前飞。

## 三、C919 的机翼为什么"长得不一样"

### 超临界机翼：上表面更平
传统机翼上表面弯得厉害，气流跑得快，但在高速飞行时容易在机翼上方"撞墙"——形成一道激波，让阻力突然变大。

C919 用的是**超临界机翼**，它的上表面更平坦、下表面弯度更大（像把传统翼型"翻转"过来调一调）。这样空气能更平顺地流过，不容易形成激波，飞起来更省劲。

效果：气动效率提升约 20%，阻力降低约 8%。省下来的就是燃油和钱。

### 翼尖小翼：给机翼"装个小挡板"
机翼最外端会形成翻卷的涡流（就是上面说的诱导阻力来源）。C919 在翼尖装了向上翘的**翼尖小翼**，像小挡板一样挡住气流乱翻，把诱导阻力降低约 4-5%。

别小看这几个百分点，对一架每天飞几个航班的客机来说，一年省下的油非常可观。

## 四、一个生活类比总结
- 升力 = 电梯把人顶上去的力；
- 阻力 = 逆风骑车时风往后拽你的力；
- 超临界机翼 = 把"拱桥"改成"平缓坡道"，让气流走得顺；
- 翼尖小翼 = 在路口装个挡板，不让风乱卷。

## 入门版小结
C919 能飞，靠机翼上下表面的压力差产生升力；飞得省油，靠超临界机翼和翼尖小翼降低阻力。这两个设计是 C919 气动设计最直观的"看得见"的亮点。
