# C919 适航取证 · 深入版

> 来源说明：本文基于 01_science 已收集的 C919 适航资料派生，用于教学组织，不作为科学事实证据源。数据截至 2026-07-28。
> 难度档：深入（面向具备适航工程基础的受众，涉及 CRI、符合性方法 M0-M9、TIA、审定计划等工程概念）

## 这一档要回答的问题
1. TIA（型号检查授权）的颁发条件与作用是什么？
2. 符合性方法 M0-M9 在具体条款中怎么应用？
3. 审定计划（CP）怎么编制、怎么管理？
4. CRI 的制定流程是什么？

## 一、TIA（Type Inspection Authorization，型号检查授权）
TIA 是 CAAC 在符合性验证阶段颁发的授权，授权正式审定试飞和航空器检查。

**TIA 颁发条件**：
- 申请人已完成足够的设计符合性验证（M0-M5、M7-M9 大部分完成）
- 审定计划（CP）已批准
- 飞机设计构型基本冻结
- 安全性分析（M3）证明试飞风险可控

**TIA 颁发后**：
- CAAC 试飞员/工程检查员参与审定试飞（M6）和航空器检查（M7）
- TIA 之前的试飞是申请人研发试飞，数据不能直接用作符合性证据
- TIA 之后的审定试飞数据才是正式符合性证据

**C919 TIA**：约 2018-2020 年间颁发（具体时间未公开），之后进入密集审定试飞阶段。

## 二、符合性方法 M0-M9 详细应用
**M0（符合性声明）**：列出条款与适用规章的对应关系。
- 适用：简单条款、引用其他条款
- 如 25.1 适用范围

**M1（说明性文件）**：用图样、描述说明符合性。
- 适用：构型描述、系统原理
- 如 25.771 驾驶舱布局

**M2（分析/计算）**：理论分析、计算。
- 适用：性能、结构强度、CFD、有限元
- 如 25.305 强度变形（有限元分析）、25.233 方向稳定性（CFD）

**M3（安全性分析）**：FHA/FTA/FMEA/PSSA/SSA。
- 适用：系统安全、失效影响
- 如 25.1309 设备系统安装（FHA + FTA + FMEA）

**M4（试验室试验）**：结构静力/疲劳试验、设备试验。
- 适用：结构验证、设备合格鉴定
- 如 25.305 强度变形（静力试验到极限载荷）、25.571 损伤容限（疲劳试验）

**M5（地面试验）**：机上地面试验。
- 适用：系统地面功能、电磁兼容、刹车
- 如 25.1309 设备地面功能、25.735 刹车

**M6（试飞）**：飞行试验。
- 适用：飞行性能、操纵性、系统飞行功能
- 如 25.103 失速速度（失速试飞）、25.143 操纵性

**M7（航空器检查）**：实物检查。
- 适用：构型符合性、可达性、维修性
- 如 25.811 应急撤离（实物检查出口标识）

**M8（模拟器试验）**：工程模拟器。
- 适用：操纵品质、人为因素、故障处置
- 如 25.143 操纵性（工程模拟器）

**M9（设备合格鉴定）**：环境/软件鉴定。
- 适用：设备 RTCA DO-160 环境鉴定、DO-178C 软件鉴定
- 如 25.1309 设备环境鉴定

**典型条款 MOC 组合**：
- 25.103 失速速度：M2（分析）+ M6（试飞）
- 25.143 操纵性：M2 + M6 + M8
- 25.305 强度变形：M2（有限元）+ M4（静力试验）
- 25.1309 设备系统安装：M3（安全性分析）+ M4（设备试验）+ M9（环境鉴定）
- 25.571 损伤容限：M2（裂纹扩展分析）+ M4（疲劳试验）

## 三、审定计划（CP，Certification Plan）
审定计划是申请人编制、CAAC 批准的符合性验证总规划。

**CP 内容**：
- 审定基础（CCAR-25 版本 + CRI + 豁免 + 专用条件）
- 条款符合性矩阵（条款 → MOC → 责任人 → 状态）
- 试飞大纲（M6 详细规划）
- 试验室/地面试验大纲（M4/M5）
- 模拟器试验大纲（M8）
- 构型控制计划

**CP 管理**：
- 申请人编制 → CAAC 审查 → 批准
- 实施过程中更新（如新增 CRI、调整 MOC）
- 每次更新需 CAAC 重新批准
- CP 是 TIA 颁发的前提

## 四、CRI 制定流程
**CRI 触发**：CCAR-25 部未覆盖的新技术/特殊设计。

**CRI 制定流程**：
1. **识别**：审查组识别需要 CRI 的项目
2. **起草**：审查组起草 CRI 要求
3. **协调**：与申请人协调，确认技术可行性
4. **批准**：CAAC 批准 CRI
5. **纳入审定基础**：CRI 成为审定基础一部分

**C919 典型 CRI**：
- 电传飞控 CRI：控制律、余度、包线保护、模式切换
- IMA CRI：分区隔离、共享资源、健康监控、DAL 分配
- 复合材料 CRI：损伤容限、修理、雷击防护、制造工艺
- 整体式反推短舱 CRI：反推集成、风扇叶片包容
- LEAP-1C 发动机 CRI：高涵道比、TAPS 燃烧室

## 五、持续适航（Continuing Airworthiness）
取证后进入持续适航阶段：
- **AD（Airworthiness Directive，适航指令）**：CAAC 强制执行的检查/改装
- **SB（Service Bulletin，服务通告）**：COMAC 建议执行的检查/改装
- **MIS（Maintenance Instruction）**：维修指示
- **持续监控**：航司报告故障、COMAC 分析、必要时发 SB/AD
- **改装**：按 AD/SB 执行改装，更新 AC

**C919 持续适航**：新机型 SB/AD 频次较高，航司需快速响应。

## 六、FAA/EASA 认可
**认可机制**：
- CAAC 与 FAA/EASA 有双边协议（Bilateral Agreement）
- C919 获 CAAC TC 后，可申请 FAA/EASA 认可
- 认可审查：FAA/EASA 审查 CAAC 的审定过程和符合性证据
- 通常有差异项需补充验证（如美方对某些条款的特定要求）

**现状**：C919 暂未申请 FAA/EASA 认可，无确切时间表。已可在与 CAAC 有双边协议的 30 多个国家运行。

## 深入版小结
C919 适航审定按 CP（审定计划）执行，TIA 颁发后进入正式审定试飞；M0-M9 符合性方法按条款组合应用，如失速用 M2+M6、结构用 M2+M4、系统用 M3+M4+M9；CRI 针对电传/IMA/复材等新技术制定专项审定要求；取证后持续适航按 AD/SB 执行；FAA/EASA 认可需双边谈判。
