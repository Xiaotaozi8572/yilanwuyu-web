# C919 航电系统 · 入门版

> 来源说明：本文基于 01_science 已收集的 C919 航电资料派生，用于教学组织，不作为科学事实证据源。数据截至 2026-07-28。
> 难度档：入门（面向无航空背景的普通公众，用电脑/手机类比航电，不涉及术语）

## 这一档要回答的问题
1. 飞机上的电脑是干什么的？
2. 飞行员怎么看飞机的状态？
3. C919 的"大脑"和家里的电脑有什么不一样？

## 一、航电是什么：飞机的"电脑+手机"
飞机上不光有发动机和翅膀，还有一大堆电脑和屏幕——这就是"航电系统"（航空电子系统）。

可以把它理解成飞机的"电脑+手机"：
- **电脑**：负责计算和处理数据，像电脑主机
- **手机**：负责通信、导航、显示，像智能手机
- **屏幕**：把信息显示给飞行员看，像电脑显示器

C919 的航电系统由 GE 航空与中航工业合资公司提供，是飞机的"大脑"。

## 二、航电干什么用：三大功能
1. **通信**：飞行员和地面空管说话、收发数据，像打电话
2. **导航**：知道飞机在哪里、要去哪里，像手机地图导航
3. **显示**：把飞机状态、航路、警告显示给飞行员，像电脑屏幕

C919 驾驶舱有 5 块 15.4 英寸液晶显示屏，飞行员通过屏幕看所有信息。

## 三、飞行员怎么看：显示器
C919 的驾驶舱屏幕分几种：
- **主飞行显示（PFD）**：显示速度、高度、姿态、航向——飞行员最关心的核心信息
- **导航显示（ND）**：显示航路、机场、地形——像手机地图
- **电子集中飞机监控（ECAM）**：显示系统状态、警告——像电脑的"任务管理器"

每块屏幕可以切换显示不同内容，飞行员能灵活查看。

## 四、C919 航电的亮点：一体化
传统飞机的电脑是"一个设备一个电脑"，每个设备都有自己的处理器——像家里每件电器都有自己的遥控器。

C919 用的是"综合模块化航电"（IMA）——把多个设备的计算功能集中到几台共享计算机上，像一台电脑同时运行多个软件。好处是：
- 重量轻（少了很多重复的电脑）
- 升级方便（软件升级即可）
- 故障隔离（一台电脑坏了，其他不受影响）

## 五、一个生活类比总结
- 航电 = 飞机的"电脑+手机"
- 显示器 = 电脑屏幕
- 通信 = 手机打电话
- 导航 = 手机地图
- IMA = 一台电脑同时运行多个软件

## 入门版小结
C919 的航电系统是飞机的"大脑"，负责通信、导航、显示，由 GE-AVIC 合资提供。它用"综合模块化"设计，把多个设备的计算集中到共享计算机，重量轻、升级方便、故障隔离。
