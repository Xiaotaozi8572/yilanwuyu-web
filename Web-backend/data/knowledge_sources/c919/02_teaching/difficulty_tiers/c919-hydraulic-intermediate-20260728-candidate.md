# C919 液压系统 · 进阶版

> 来源说明：本文基于 01_science 已收集的 C919 液压资料派生，用于教学组织，不作为科学事实证据源。数据截至 2026-07-28。
> 难度档：进阶（面向已了解液压基本概念的受众，引入作动器、伺服阀、3000 psi 权衡等概念）

## 这一档要回答的问题
1. C919 为什么选 3000 psi 而不是 5000 psi？
2. 作动器怎么把液压变成精确的舵面运动？
3. 伺服阀是什么，怎么工作？

## 一、3000 psi 的选择权衡
液压系统压力等级：
- **3000 psi（约 20.7 MPa）**：传统民机主流（A320/B737 也用 3000 psi）
- **5000 psi（约 34.5 MPa）**：新一代部分机型（A380/B787 部分系统）

**C919 选 3000 psi 的原因**：
1. **成熟度**：3000 psi 技术成熟，供应商体系完善（Parker-AVIC 合资）
2. **重量权衡**：5000 psi 可减小管路/作动器体积减重，但密封/管路耐压要求高，重量优势有限
3. **维护性**：3000 psi 维护经验积累多，外场维护更便利
4. **风险**：5000 psi 新技术增加适航审定风险

C919 作为新机型，选用成熟的 3000 psi 是工程权衡——用成熟技术降低研制风险。

## 二、作动器原理
**液压作动器（Actuator）** 把液压能转换为机械运动，分两类：

**线性作动器（液压缸）**：
- 活塞在液压缸内直线运动
- 液压油进入一侧推动活塞，另一侧回油
- 用于舵面推杆、起落架收放

**旋转作动器（液压马达）**：
- 液压驱动旋转运动
- 用于襟翼/缝翼驱动、反推展开

**力放大**：
- 活塞面积 A × 液压压力 P = 输出力 F
- 3000 psi × 10 cm² 活塞面积 ≈ 19,000 N（约 2 吨力）
- 飞行员侧杆指令只需几牛顿，经电信号放大后驱动几吨力的作动器

## 三、伺服阀（Servo Valve）
伺服阀是液压系统的"精准开关"——按电信号精确控制液压油流量和方向。

**电液伺服阀（EHV）工作原理**：
1. 飞控计算机发出电信号（如 ±10 mA）
2. 信号驱动力矩马达，偏转挡板
3. 挡板偏转改变喷嘴挡板流量，产生压差
4. 压差推动滑阀（spool）移动
5. 滑阀移动控制液压油流向作动器
6. 反馈弹簧平衡滑阀位置，实现精确控制

**特点**：
- 响应快（毫秒级）
- 精度高（微米级位置控制）
- 但对油液清洁度敏感（需精细过滤）

## 四、C919 液压系统架构
**三套独立系统**（Parker-AVIC 合资）：
- **A 系统**：左发动机 EDP + EMP，独立油箱和管路
- **B 系统**：右发动机 EDP + EMP，独立油箱和管路
- **C 系统**：EMP + RAT 应急，独立油箱和管路

**供压逻辑**：
- 正常时 A/B 系统为主，C 系统待机
- 任一主系统故障，C 系统接替
- 双主系统故障，C 系统 + RAT 应急供压给关键舵面

**典型供压对象**：
- A 系统：左副翼、左升降舵、左扰流板、左起落架刹车
- B 系统：右副翼、右升降舵、右扰流板、右起落架刹车
- C 系统：方向舵、应急作动器、RAT 备份

## 五、蓄压器（Accumulator）
蓄压器是液压系统的"电池"，储存液压能量：
- **结构**：壳体+隔膜，一侧气体（氮气），一侧液压油
- **工作原理**：泵把液压油压入蓄压器，压缩气体；需要时气体膨胀把油推回系统
- **作用**：
  1. 缓冲压力脉动（泵脉动、阀门快关）
  2. 瞬间大流量补充（如刹车瞬间）
  3. 泵失效时短暂供压（几秒到几十秒）

类比：像水塔，平时泵把水打上去，需要时水靠重力流出来。

## 六、液压油
C919 用合成阻燃液压油（如 Skydrol LD-4 等）：
- **阻燃**：高温下不燃（闪点高、自燃温度高）
- **低凝点**：高空低温（-50℃ 以下）不凝固
- **化学稳定**：不腐蚀管路、不分解
- **染色**：通常染红色/紫色，方便识别泄漏
- **维护**：需定期检测酸值、含水量、清洁度

## 七、把概念串起来
- 想知道液压压力等级权衡 → 看 **3000 psi 选择**
- 想知道电信号怎么变成机械力 → 看 **作动器 + 伺服阀**
- 想知道液压怎么分配 → 看 **三套独立系统 A/B/C**
- 想知道液压怎么"存电" → 看 **蓄压器**

## 进阶版小结
C919 液压系统选 3000 psi 成熟技术（Parker-AVIC 合资），三套独立系统 A/B/C 分担不同舵面；电液伺服阀按电信号精确控制液压油流量；线性/旋转作动器把液压能转换为机械运动；蓄压器缓冲脉动+应急供压；阻燃合成液压油保证高温不燃、低温不凝。
