## 一、碳纤维复合材料的铺层设计
碳纤维复合材料不是“一整块”，而是把许多层碳纤维预浸料按设计方向叠合、在热压罐中固化而成。每一层的纤维方向决定了该方向的强度：

- **0° 铺层**（沿载荷方向）：承受主要拉伸/压缩载荷；
- **±45° 铺层**：承受剪切载荷；
- **90° 铺层**：承受横向载荷、控制泊松比。

铺层顺序和比例根据各部位的应力场设计：高拉伸区多放 0°，受剪区多放 ±45°。这种“按载荷定向布置纤维”是复合材料比各向同性金属更高效的根本原因——材料只在需要的方向上“用力”。

工程代价：复合材料是各向异性的，设计必须考虑层间剪切、湿热老化、冲击后压缩强度（CAI）等金属不存在的失效模式。

## 二、疲劳寿命评估
飞机在每次起降中经历增压/卸压、机动载荷循环，结构会累积疲劳。疲劳设计的关键概念：
- **S-N 曲线**：应力水平 S 与到失效的循环数 N 的关系。铝合金有明显的疲劳极限，复合材料疲劳行为更平缓但分散性大。
- **疲劳寿命**：在给定载荷谱下结构能安全承受的循环次数。民机结构按设计寿命（如 C919 的起降次数目标）设计，并留有裕度。
- **分散系数**：考虑材料和载荷的统计分散性，用试验寿命除以分散系数得到许用寿命。

C919 的疲劳验证通过全尺寸疲劳试验完成，模拟多次起降循环，验证结构在设计寿命内不发生疲劳破坏。

## 三、损伤容限设计
损伤容限（Damage Tolerance）是民机结构适航的核心要求（CCAR-25.571）：
- 假设结构不可避免存在初始缺陷（如制造缺陷、冲击损伤）；
- 要求在规定的检修周期内，裂纹或损伤能被检测到且结构仍能承受极限载荷；
- 关键参数：**临界裂纹长度**、**裂纹扩展速率**、**检修周期**。

设计策略：
- **缓慢裂纹扩展**：裂纹在检修周期内扩展缓慢，下次检修前不达到临界值；
- **破损安全**：单个传力路径破坏后，剩余结构仍能承载。

复合材料还需考虑**低速冲击损伤（LID）**——如工具掉落、冰雹，内部可能脱层而表面几乎不可见（BVID，目视勉强不可见损伤），需通过冲击后压缩强度设计和无损检测保证安全。

## 四、中央翼盒材料选择的工程权衡
中央翼盒是连接左右机翼、穿过机身下方的关键承力结构，承受机翼传来的弯矩和扭矩。C919 中央翼盒原计划采用碳纤维复合材料以减重，最终改回铝合金，权衡如下：

| 因素 | 复合材料方案 | 铝合金方案 |
|------|------------|-----------|
| 重量 | 减重约 15-20% | 基准 |
| 强度 | 比强度高 | 足够 |
| 认证风险 | 高（民机主承力盒段应用经验少） | 低（成熟） |
| 损伤检测 | 难（脱层不可见） | 易（裂纹可视+无损检测成熟） |
| 制造工艺 | 复杂、成本高 | 成熟 |
| 维修性 | 差 | 好 |

结论：在 C919 作为首个型号、需积累适航经验的阶段，用材料/重量收益换取认证风险和可靠性是合理的工程选择。这是民机研制“先求稳、再优化”的典型路径。

## 深入版小结
C919 的材料与结构设计是碳纤维定向铺层、疲劳寿命验证、损伤容限适航要求的综合工程：复合材料按载荷定向铺层实现高效承载，全尺寸疲劳试验验证设计寿命，损伤容限设计保证带缺陷安全运行。中央翼盒从复合材料改回铝合金，是用重量收益换认证风险与可维修性的工程权衡。
