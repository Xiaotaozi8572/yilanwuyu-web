## 这一档要回答的问题
1. 什么是控制律，C919 有哪几种？
2. 包线保护具体保护什么？
3. 舵面作动器怎么把电信号变成机械力？

## 一、控制律（Control Law）
控制律是飞控计算机处理飞行员指令的"规则"。C919 飞控由霍尼韦尔-AVIC 合资提供，采用分层控制律：

**正常控制律（Normal Law）**：
- 全功能，含包线保护
- 飞行员指令经控制律处理，自动配平
- 提供俯仰/滚转/偏航三通道的精确控制
- 是常规飞行模式

**降级控制律（Alternate Law）**：
- 部分包线保护丧失
- 触发条件：传感器故障、计算机降级、某些异常
- 飞行员需更谨慎，留意包线边界
- 仍保留基本操纵能力

**直接控制律（Direct Law）**：
- 包线保护全部丧失
- 侧杆指令直接映射到舵面（按固定比例）
- 飞行员需手动配平，完全自主管理
- 触发条件：多重故障、备份模式

**分层降级逻辑**：Normal → Alternate → Direct，逐级降级，保证任一故障下仍有最低操纵能力。

## 二、包线保护（Envelope Protection）
正常控制律下，C919 提供多重包线保护：

1. **迎角保护（α-protection）**：
   - 把可用迎角限制在失速迎角以下
   - 飞行员拉杆到底也不会失速
   - 通过迎角传感器实时监测

2. **过载限制（Load Factor Protection）**：
   - 限制法向过载约 +2.5g / -1g（CCAR-25.337）
   - 防止结构过载损坏
   - 机动飞行时自动限制拉杆量

3. **速度限制（Speed Protection）**：
   - 超过 Vmo/Mmo 触发超速保护
   - 自动抬头减速
   - 低于 Vls 触发低速保护

4. **坡度限制（Bank Angle Protection）**：
   - 正常控制律下坡度限制约 67°
   - 超过限制自动滚转回正
   - 防止过度倾斜

5. **地形避让（TAWS）**：
   - 与 GPWS 配合
   - 防止可控飞行撞地（CFIT）

**重要说明**：包线保护是"最后兜底"，不替代飞行员判断；在 Direct Law 下保护全部丧失。

## 三、舵面作动器
电信号怎么变成舵面的机械运动？靠作动器。

**C919 主要舵面**：
- **升降舵**（平尾后缘）：控制俯仰
- **副翼**（机翼外段后缘）：控制滚转
- **方向舵**（垂尾后缘）：控制偏航
- **扰流板**（机翼上表面）：减速/滚转辅助/破坏升力
- **水平安定面**（整个平尾）：俯仰配平
- **襟翼/缝翼**（机翼后缘/前缘）：增升装置

**作动器类型**：
- **液压作动器**：主流，由液压系统驱动，力气大
- **电液作动器（EHA）**：电动+液压备份，部分舵面使用
- **电气作动器（EMA）**：纯电动，用于次要舵面

C919 主舵面以液压作动器为主，关键舵面配备 EHA 作为备份，保证液压全失效时仍有最低操纵。

## 四、侧杆与双输入
- C919 左右座各一个侧杆
- 侧杆无机械力反馈，手感来自弹簧+阻尼器
- **双输入逻辑**：左右座同时操纵时，系统取指令叠加
- 双输入超过一定时间触发告警，提醒机组协调

## 五、自动配平
正常控制律下，C919 自动配平：
- 速度变化时自动调整水平安定面，保持俯仰配平
- 飞行员无需手动配平
- 降级到 Direct Law 时需手动配平

## 六、把概念串起来
- 想知道飞控怎么"决策" → 看 **控制律（Normal/Alternate/Direct）**
- 想知道飞控怎么"保护" → 看 **包线保护（迎角/过载/速度/坡度）**
- 想知道电信号怎么"变成力" → 看 **舵面作动器**
- 想知道飞行员怎么"输入" → 看 **侧杆 + 双输入逻辑**

## 进阶版小结
C919 飞控采用分层控制律（Normal→Alternate→Direct），正常控制律含迎角/过载/速度/坡度/地形多重包线保护；舵面以液压作动器为主，关键舵面配 EHA 备份；侧杆无机械反馈，双输入逻辑+自动配平。
