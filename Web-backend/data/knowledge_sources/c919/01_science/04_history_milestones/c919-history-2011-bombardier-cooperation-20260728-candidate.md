## 正文

### Bombardier 合作背景

2011-2012 年期间，C919 项目进入关键设计阶段，COMAC 与加拿大庞巴迪公司（Bombardier Inc.）展开了深入合作。庞巴迪当时正在研制 C Series 系列窄体客机（CS100、CS300），与 C919 在 100-150 座级存在部分重叠，但双方在多个方面存在合作空间。

### 合作时间线

| 日期 | 事件 | 说明 |
| --- | --- | --- |
| 2011-03 | COMAC 与 Bombardier 签署合作框架协议 | 初步合作意向 |
| 2012-03 | 双方进一步深化合作 | 涉及具体领域 |
| 2012-2014 | 供应商合作开展 | 供应链、航电、驾驶舱等 |
| 2015 后 | 合作逐步淡化 | C Series 项目转让空客 |

### 合作领域

COMAC 与 Bombardier 的合作涵盖以下领域：

#### 1. 供应链合作

- 共同评估和选择供应商
- 共享供应商资源
- 在某些部件上联合采购，争取规模效益
- 供应商认证标准互通

#### 2. 航电系统

- 航电架构交流
- ARINC 664 网络设计经验分享
- IMA 平台选型咨询
- 显示系统设计交流

#### 3. 驾驶舱设计

- 人机界面（HMI）设计理念交流
- 侧杆设计经验分享
- 显示布局优化
- 操作流程标准化

#### 4. 适航认证

- 适航经验交流
- 设计准则互通
- 测试方法分享
- 国际认证策略讨论

### 合作的潜在战略价值

C919 项目与 Bombardier 的合作具有重要的战略价值：

#### 1. 互补性

- C919（158-192 座）与 C Series（100-150 座）形成互补
- 共同对抗空客、波音的双寡头垄断
- 在不同细分市场覆盖客户需求

#### 2. 技术交流

- Bombardier 在支线客机和公务机领域经验丰富
- COMAC 可借鉴其在适航、制造、客户支持方面的经验
- 双方共同探索新材料、新工艺应用

#### 3. 市场协同

- 共同开拓新兴市场
- 在客户支持网络方面合作
- 在备件供应上互为补充

### 合作未深入的领域

虽然 COMAC 与 Bombardier 在多个领域开展合作，但合作未深入到以下方面：

1. **核心设计**：C919 总体设计由 COMAC 自主完成
2. **关键系统**：飞控、发动机等关键系统选型独立
3. **共平台**：未实现 C919 与 C Series 的共平台生产
4. **股权合作**：未涉及股权投资

### 合作的挑战

COMAC 与 Bombardier 合作面临以下挑战：

#### 1. 市场定位重叠

C919-100 STD（158-168 座）与 C Series CS300（130-160 座）在座位数上存在部分重叠，竞争关系难以完全消除。

#### 2. 文化差异

- 中方：国企背景，决策流程严格
- 加方：民营企业，决策灵活但资源有限
- 工作方式差异需要磨合

#### 3. 知识产权保护

- 双方对核心技术的保护意识强
- 技术交流深度受限
- 共享程度低于预期

#### 4. 政治因素

- 中加关系的不确定性
- 美国对技术转移的关注
- 国际航空产业竞争

### 合作的实际成果

COMAC 与 Bombardier 合作的具体成果：

#### 1. 供应商层面

- 部分供应商同时服务 C919 和 C Series 项目
- 例如：Parker Hannifin 同时为两机型提供液压系统
- Honeywell 同时为两机型提供部分航电设备

#### 2. 设计经验

- COMAC 借鉴了 Bombardier 的 IMA 架构经验
- C919 驾驶舱人机界面设计参考了 C Series 理念
- 适航认证经验得到交流

#### 3. 试飞支持

- Bombardier 在试飞规划和数据分析方面提供咨询
- C919 试飞 4,200 小时，部分经验借鉴自 C Series

### 合作的终止

C919 与 Bombardier 的合作在 2015 年后逐步淡化，主要原因：

#### 1. C Series 项目转让

2017 年，空客以 1 美元价格收购了 Bombardier C Series 项目 50.01% 股权，C Series 改名为 Airbus A220。Bombardier 不再是独立的窄体客机制造商。

#### 2. 项目阶段差异

- C919 项目从 2017 年开始进入试飞阶段
- C Series 项目（A220）被空客整合后策略调整
- 双方合作基础发生变化

#### 3. 国际政治

- 中加关系在 2018 年后紧张
- 孟晚舟事件影响双边合作
- 航空领域合作受到波及

### 合作的历史评价

回顾 2011-2012 年 COMAC 与 Bombardier 的合作：

#### 积极方面

1. **拓宽视野**：COMAC 接触了国际先进的窄体客机设计经验
2. **加快学习**：缩短了 C919 项目学习曲线
3. **供应商整合**：促进供应商体系国际化
4. **适航经验**：丰富了适航审定经验

#### 局限性

1. **合作深度有限**：未达到共平台、共生产层面
2. **持续期短**：仅 4-5 年即逐步淡化
3. **依赖外部**：C919 不能完全依赖此类合作
4. **后续不确定性**：Bombardier 退出窄体客机市场使合作失去基础

### 后续影响

虽然 COMAC 与 Bombardier 的直接合作逐步淡化，但合作期间积累的经验对 C919 项目产生持续影响：

1. **设计理念**：C919 驾驶舱设计部分受 C Series 启发
2. **供应商体系**：共同供应商的经验帮助 COMAC 提升管理水平
3. **适航能力**：丰富了 COMAC 的适航审定经验
4. **国际视野**：为 COMAC 后续国际合作奠定基础

### A220 项目（原 C Series）现状

虽然 Bombardier 退出了 C Series 项目，但该项目在空客运营下继续发展：

- 2017 年：空客收购 C Series 50.01% 股权
- 2018 年：C Series 改名为 A220
- 2020 年：Bombardier 完全退出
- 2026 年：A220 累计交付约 300 架，运营良好

A220 的成功证明了 100-150 座级窄体客机的市场价值，也为 C919-600（130-150 座缩短型，2026 年 1 月 8 日出厂）提供了市场参考。
