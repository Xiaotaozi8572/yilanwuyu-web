# C919 与 A320neo 发动机对比：LEAP-1C vs LEAP-1A vs PW1100G

## 正文

### 三型发动机总览

窄体客机市场三型主流发动机对比：

| 发动机 | 应用机型 | 制造商 | 类型 |
| --- | --- | --- | --- |
| LEAP-1C | C919 | CFM International（GE-Safran） | 大涵道比涡扇 |
| LEAP-1A | A320neo | CFM International（GE-Safran） | 大涵道比涡扇 |
| PW1100G | A320neo | Pratt & Whitney | 齿轮传动涡扇（GTF） |

C919 配备 LEAP-1C 的两个推力等级：

| 发动机型号 | 应用变体 | MTO 推力 | MCT 推力 |
| --- | --- | --- | --- |
| LEAP-1C28 | C919-100 STD | 129.98 kN (29,220 lbf) | 127.93 kN (28,760 lbf) |
| LEAP-1C30 | C919-100 ER | 137.14 kN (30,830 lbf) | 133.22 kN (29,950 lbf) |

### LEAP-1C 与 LEAP-1A 的关系

LEAP-1C 与 LEAP-1A 同属 CFM International 的 LEAP 系列，两者共享型号合格证。两者的共同点：

| 特征 | LEAP-1C | LEAP-1A |
| --- | --- | --- |
| 制造商 | CFM International（GE-Safran） | CFM International（GE-Safran） |
| 风扇叶片 | 18 片碳纤维复合材料 | 18 片碳纤维复合材料 |
| 涵道比 | 约 11:1 | 约 11:1 |
| 总压比 | 40+ | 40+ |
| 燃烧室 | TAPS 双环预混旋流 | TAPS 双环预混旋流 |
| 型号合格证 | 共享 | 共享 |

LEAP-1C 与 LEAP-1A 的主要差异：

| 差异点 | LEAP-1C | LEAP-1A |
| --- | --- | --- |
| 应用机型 | C919 | A320neo |
| 推力等级 | 129.98 kN / 137.14 kN | 通常 124-151 kN |
| 短舱集成 | Nexcelle PANACHE，O-Duct 反推 | 各短舱供应商 |
| 安装接口 | 适配 C919 挂架 | 适配 A320neo 挂架 |

LEAP-1C 与 LEAP-1A 共享型号合格证意味着两者在核心机、压气机、燃烧室、涡轮等核心部件上高度通用，差异主要体现在风扇直径、推力标定、短舱集成等机型适配方面。这一共享降低了 LEAP-1C 的研制风险——LEAP-1A 已在 A320neo 上大量服役，技术成熟度高。

### LEAP-1C vs PW1100G 的技术路线对比

A320neo 提供两种发动机选择：LEAP-1A 和 PW1100G。两者代表窄体客机发动机的两条技术路线：

| 特征 | LEAP-1C/1A（CFM） | PW1100G（P&W） |
| --- | --- | --- |
| 技术路线 | 传统大涵道比涡扇 | 齿轮传动涡扇（GTF） |
| 风扇驱动方式 | 风扇直接由低压涡轮驱动 | 风扇通过减速齿轮箱驱动 |
| 风扇转速 | 与低压涡轮同转速 | 风扇低转速，涡轮高转速 |
| 涵道比 | 约 11:1 | 约 12:1 |
| 减速齿轮箱 | 无 | 有（风扇/涡轮转速解耦） |

PW1100G 的齿轮传动设计使风扇和低压涡轮各自工作在最优转速——风扇低速运转提高推进效率、降低噪声，低压涡轮高速运转提高效率。这一设计的理论优势是更高的推进效率，但增加了齿轮箱这一复杂部件，带来额外的可靠性挑战。

LEAP 系列（含 LEAP-1C）采用传统直接驱动架构，通过提高涵道比（11:1 vs CFM56 的 5.5:1）、采用复合材料风扇叶片、TAPS 燃烧室等技术提升效率。相比 PW1100G，LEAP 架构更成熟、零件数更少、齿轮箱相关可靠性风险更低。

### 推力等级对比

| 发动机 | MTO 推力 | MCT 推力 |
| --- | --- | --- |
| LEAP-1C28（C919 STD） | 129.98 kN (29,220 lbf) | 127.93 kN (28,760 lbf) |
| LEAP-1C30（C919 ER） | 137.14 kN (30,830 lbf) | 133.22 kN (29,950 lbf) |
| LEAP-1A（A320neo） | 约 124-151 kN | 约 120-147 kN |
| PW1100G（A320neo） | 约 121-147 kN | 约 117-143 kN |

C919 的 LEAP-1C28/1C30 推力区间（129.98-137.14 kN）处于 A320neo 两型发动机推力范围的中段。C919-100 ER 通过 LEAP-1C30（137.14 kN）和更高 MTOW 实现延程（航程 5,555 km）。

### 燃油效率对比

LEAP 系列（含 LEAP-1C）相比上一代 CFM56 燃油效率提升约 15%，PW1100G 相比 CFM56 提升约 16%。两型发动机的燃油效率接近，差异在 1-2 个百分点内。

C919 采用 LEAP-1C 的燃油经济性收益：

- 巡航马赫 0.785（835 km/h），实用升限 12,200 m
- 标准型航程 4,075 km，延程型 5,555 km
- 超临界机翼设计（气动效率 +20%，阻力 -8%）与 LEAP-1C 协同降油耗

### 供应链风险对比

| 发动机 | 供应链风险 |
| --- | --- |
| LEAP-1C（C919） | 美国成分高，2025 年曾暂停对华销售 |
| LEAP-1A（A320neo） | CFM 全球供应链，不受对华管制直接影响 |
| PW1100G（A320neo） | P&W 全球供应链，不受对华管制直接影响 |

LEAP-1C 的供应链风险是 C919 特有的——由于 C919 是中国机型，LEAP-1C 对华销售受美国出口管制政策影响。2025 年 5 月美国暂停 LEAP-1C 销售，2025 年 7 月解除，这一事件直接推动了 CJ-1000A 国产发动机的研制加速。

A320neo 的 LEAP-1A 和 PW1100G 不受对华销售管制的直接影响（虽然部分 PW1100G 早期也曾有可靠性问题），因为 A320neo 是欧洲机型，发动机作为整机销售给空客。

### 国产替代前景

C919 的 LEAP-1C 有国产替代路径——CJ-1000A：

| 日期 | 事件 |
| --- | --- |
| 2009 年 | CJ-1000A 开始研制 |
| 2017-12 | 总装完成 |
| 2018-05 | 首次运转（6,600 rpm） |
| 2023-03 | 在运-20 上试飞 |
| 2027-2028（预计） | 认证 |
| 2030（预计） | 量产 |

CJ-1000A 量产后将替代 LEAP-1C，使 C919 发动机成本从 22% 进口转为国产。A320neo 的 LEAP-1A 和 PW1100G 无国产替代路径——空客作为欧洲制造商不面临发动机断供风险，也无国产替代需求。

### 短舱与反推对比

C919 的 LEAP-1C 短舱由 Nexcelle（Safran-ST Engineering MRAS 合资）提供，型号 PANACHE，采用 O-Duct 整体式反推设计。O-Duct 将反推装置集成在短舱整体结构中，相比传统四分式短舱减少零件数量和重量。

A320neo 的 LEAP-1A 和 PW1100G 短舱由各自短舱供应商提供（CFM 与短舱供应商协作，P&W 与短舱供应商协作），通常采用传统四分式设计。C919 的 O-Duct 整体式设计是相对独特的，是 C919 在短舱集成上的一个特色。
