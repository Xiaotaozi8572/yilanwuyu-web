# C919 燃油系统详节：Parker-AVIC 与惰性气体系统

## 正文

### 燃油系统总体概述

C919 燃油系统由 Parker-AVIC 合资公司提供，主要功能包括：

1. 储存燃油
2. 向发动机和 APU 供油
3. 燃油管理（输油、转油）
4. 燃油测量与指示
5. 燃油惰化（防止燃油蒸汽燃烧）
6. 应急放油（如需要）

Parker-AVIC 由美国 Parker Hannifin 与中国航空工业集团（AVIC）合资成立，专门为 C919 项目研制燃油和液压系统。Parker Hannifin 是全球流体控制领域的领导者，在 A320、B737 等机型上提供燃油系统元件。

### 油箱布局

C919 采用典型的"三油箱"布局，包括左机翼油箱、右机翼油箱和中央油箱：

| 油箱 | 位置 | 容量 | 说明 |
| --- | --- | --- | --- |
| 左机翼油箱 | 左外翼 | 约 4,000 L | 整体油箱 |
| 右机翼油箱 | 右外翼 | 约 4,000 L | 整体油箱 |
| 中央油箱 | 中央翼盒 | 约 8,500 L | 主储油 |
| 总容量 | — | 约 16,500 L | 约 13.3 吨 |

C919 标准型（C919-100 STD）航程 4,075 km，延程型（C919-100 ER）航程 5,555 km，主要差异在于燃油容量和最大起飞重量。延程型通过增加中央油箱容量和提升结构强度实现更远航程。

### 燃油规格

C919 使用 Jet A-1 航空煤油，主要参数：

| 参数 | 数值 | 规格 |
| --- | --- | --- |
| 密度 | 0.81 g/cm³ | 15℃ 时 |
| 闪点 | >38℃ | 闭杯 |
| 冰点 | <-47℃ | Jet A-1 规格 |
| 能量密度 | 43.15 MJ/kg | 体积能量密度 |
| 硫含量 | <0.30% | 质量分数 |
| 芳烃含量 | <25% | 体积分数 |

C919 也可使用国产 RP-3 航空煤油（GB 6537 标准），与 Jet A-1 性能基本相当。

### 供油系统

C919 供油系统采用"重力+泵送"组合方式：

1. **主供油泵**：每个油箱配备 2 个直流电动增压泵
2. **备用泵**：关键油箱配备备用泵
3. **交输供油**：左右系统可通过交输阀切换
4. **APU 供油**：由专用管路从中央油箱供油

供油流程：

- 起飞阶段：先使用中央油箱燃油（先减轻中央翼盒载荷）
- 巡航阶段：使用机翼油箱燃油
- 着陆前：保留机翼油箱部分燃油，便于着陆时机翼结构承力

### 燃油管理系统

C919 燃油管理系统（Fuel Management System, FMS）由 AVIAGE Systems（GE-AVIC 合资）提供的飞行管理系统（TrueCourse）集成管理，主要功能：

1. **燃油测量**：通过油箱内的电容式传感器实时测量油量
2. **重心计算**：根据油量分布计算飞机重心
3. **输油控制**：自动控制输油泵，保持重心在许可范围内
4. **不平衡保护**：左右油箱油量差超过阈值时报警
5. **耗油预测**：根据飞行计划预测到达油量

#### 燃油测量原理

C919 采用电容式燃油测量技术：

- 油箱内布置多个电容式探头（典型 8-12 个）
- 探头高度从油箱底部到顶部
- 燃油介电常数（约 2.0）与空气（1.0）不同
- 测量电容值计算燃油高度
- 多探头数据融合计算总油量

电容式测量相比浮子式测量精度更高（误差 <1% vs 2-3%），且无活动部件，可靠性高。

### 燃油惰化系统

C919 配备燃油惰化系统（Fuel Inerting System, FIS），这是 FAA 在 2008 年后强制要求安装的安全系统。燃油惰化系统的作用是将油箱上部空间（ullage）中的氧气浓度降至 12% 以下，防止燃油蒸汽被点燃。

#### 工作原理

C919 燃油惰化系统采用空气分离技术（Air Separation Technology）：

1. **引气**：从发动机压气机引出高压空气
2. **过滤**：去除水分和颗粒物
3. **分离**：通过中空纤维膜分离器（MEMBRANE）分离氧气和氮气
4. **NEA 输出**：富氮空气（NEA，Nitrogen-Enriched Air）含氮量 >95%
5. **注入油箱**：将 NEA 注入油箱上部空间
6. **氧气浓度监测**：传感器实时监测油箱氧气浓度

#### 性能参数

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 引气流量 | 约 50 kg/h | 单台 |
| NEA 浓度 | >95% N2 | 富氮空气 |
| 油箱氧浓度 | <12% | 安全水平 |
| 响应时间 | <30 秒 | 系统启动到稳定 |
| 膜组件寿命 | >30,000 小时 | 中空纤维膜 |
| 功耗 | 约 1-2 kW | 引气消耗 |

#### 适航要求

C919 燃油惰化系统满足 FAR 25.981 适航要求：

- 任何油箱上部空间氧气浓度不超过 12%
- 系统故障时必须有明确指示
- 必须在地面、起飞、巡航、着陆各种状态下工作

### 中央油箱设计

C919 中央油箱位于中央翼盒内部，是最大的单个油箱。中央油箱设计特点：

1. **整体油箱**：直接利用翼盒结构作为油箱壁
2. **隔板**：内部设置隔板减小燃油晃动
3. **加强肋**：通过翼肋加强，承受燃油液压
4. **检查口盖**：底部设置多个检查口盖，便于内部检查
5. **失效安全设计**：油箱壁为多路传力结构，单一裂纹不会导致整体失效

中央油箱容量约 8,500 L，在延程型 C919-100 ER 中是延长航程的关键。

### 应急放油系统

C919 配备应急放油系统（Fuel Jettison System），主要功能是在紧急情况下快速放油，降低飞机重量至最大着陆重量以下。

应急放油系统参数：

- **放油速率**：约 500-800 L/min
- **放油口**：每侧机翼后缘 1 个放油喷嘴
- **控制**：由飞行员在驾驶舱手动启动
- **应急关断**：在低油量时自动停止

### 燃油系统试验

C919 燃油系统在适航取证过程中完成了以下试验：

1. **油箱密封性试验**：油箱加压至 1.5 倍工作压力，检查泄漏
2. **燃油系统功能试验**：地面模拟各种供油场景
3. **燃油惰化试验**：验证油箱氧浓度降低效果
4. **应急放油试验**：飞行中验证放油功能
5. **燃油测量精度试验**：地面标定和飞行验证
6. **振动和温度试验**：在 -55℃ 至 +135℃ 全包线内验证

### 燃油经济性

C919 燃油经济性主要取决于 LEAP-1C 发动机的油耗和飞机气动效率：

- LEAP-1C 涵道比 11:1，比 CFM56-5B（涵道比 5.4:1）燃油消耗降低约 15%
- 超临界机翼降低巡航阻力约 8%
- 翼尖小翼降低诱导阻力约 3-5%
- 复合材料和铝锂合金减轻结构重量

综合效果使 C919 单座燃油消耗相比 A320ceo 降低约 12-15%，与 A320neo 接近。

### LEAP-1C 与燃油系统匹配

C919 选用的 LEAP-1C 发动机对燃油系统提出以下要求：

| 参数 | LEAP-1C28（STD） | LEAP-1C30（ER） |
| --- | --- | --- |
| 最大起飞推力 | 129.98 kN | 137.14 kN |
| 最大连续推力 | 127.93 kN | 133.22 kN |
| 巡航耗油率 | 约 0.53 kg/daN·h | 约 0.53 kg/daN·h |
| 起飞燃油流量 | 约 3,800 kg/h | 约 4,000 kg/h |
| 巡航燃油流量 | 约 1,200 kg/h | 约 1,250 kg/h |

C919 燃油系统需保证在最大燃油流量下稳定供油，且在油箱低油量时仍能维持发动机工作。
