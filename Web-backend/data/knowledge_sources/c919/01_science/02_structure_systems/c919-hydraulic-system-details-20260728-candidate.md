## 正文

### 液压系统总体概述

C919 液压系统是飞机次级操纵系统的核心动力源，为起落架收放、刹车、前轮转向、增升装置驱动、反推装置、舱门操纵等关键功能提供动力。液压系统由 Parker-AVIC 合资公司提供。

Parker-AVIC 是美国 Parker Hannifin（派克汉尼汾）与 AVIC 的合资公司，专门为 C919 项目研制液压和燃油系统。Parker Hannifin 是全球最大的液压元件制造商之一，在 A320、B737 等机型上提供液压元件。

### 液压系统参数

C919 液压系统主要参数：

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 系统压力 | 3,000 psi（约 20.7 MPa） | 标准民机压力 |
| 系统数量 | 3 套独立系统 | 三余度设计 |
| 液压油 | Mobil Jet Oil II 或 Skydrol LD-4 | 阻燃磷酸酯 |
| 单系统流量 | 约 30-40 L/min | 主发动机驱动泵 |
| 总油液容量 | 约 200 L | 三系统合计 |
| 工作温度 | -55℃ 至 +135℃ | 全飞行包线 |
| 过滤精度 | 3 μm 绝对过滤 | 保证元件寿命 |

C919 选择 3,000 psi 系统压力而非 5,000 psi（如 A380、B787 使用的高压系统），主要考虑：

1. **成熟度高**：3,000 psi 是民机液压系统的标准压力，元件经过数十年验证
2. **维护便利**：现有维护基础设施完全兼容
3. **成本可控**：元件成本相对低
4. **泄漏风险低**：相对高压系统密封更可靠

### 三套独立液压系统

C919 配备三套相互独立的液压系统，分别称为 A 系统、B 系统和备用系统（Standby）：

| 系统 | 驱动源 | 主要用户 |
| --- | --- | --- |
| A 系统（左） | 左发动机 EDP + 电动泵 | 副翼、升降舵、方向舵、左刹车、起落架收放 |
| B 系统（右） | 右发动机 EDP + 电动泵 | 副翼、升降舵、方向舵、右刹车、前轮转向、增升装置 |
| 备用系统 | 电动泵 | 关键舵面备份、刹车备份 |

三套系统设计为任意两套失效时仍能保持飞机安全操纵：

- A+B 同时失效：备用系统提供关键舵面操纵
- A+备用同时失效：B 系统独立工作
- B+备用同时失效：A 系统独立工作

### 液压源

每套主液压系统的液压源由两部分组成：

1. **EDP（Engine-Driven Pump）发动机驱动泵**：由发动机附件齿轮箱驱动，提供主液压动力
2. **EMP（Electric Motor Pump）电动泵**：由飞机电力系统驱动，作为备份和地面动力

每套系统的 EDP 和 EMP 可独立工作，互为冗余。

| 参数 | 数值 |
| --- | --- |
| 类型 | 柱塞式变量泵 |
| 排量 | 约 30 cc/r |
| 转速 | 约 3,750 rpm |
| 最大流量 | 约 50 L/min |
| 工作压力 | 3,000 psi |

#### EMP 性能参数

| 参数 | 数值 |
| --- | --- |
| 类型 | 柱塞式变量泵 |

| 功率 | 约 5-7 kW |

### 液压油

C919 选用阻燃磷酸酯液压油，主要型号为 Skydrol LD-4 或 Mobil Jet Oil II。磷酸酯液压油特性：

| 性能 | 数值 | 说明 |
| --- | --- | --- |
| 密度 | 1.0 g/cm³ | 高于矿物油 |
| 闪点 | >160℃ | 高燃点 |
| 自燃温度 | >500℃ | 阻燃特性 |
| 工作温度 | -55℃ 至 +135℃ | 全包线 |
| 运动粘度（40℃） | 约 10 cSt | 适中 |

磷酸酯液压油虽然成本较高（约 30 美元/升），但其阻燃特性对飞行安全至关重要，是民机液压系统的标准选择。

### 余度设计

C919 液压系统的余度设计体现在多个层次：

#### 1. 系统级余度

三套独立液压系统，任意两套失效仍能安全飞行。

#### 2. 元件级余度

- EDP + EMP 双泵配置
- 双向过滤器（自动切换）
- 双向蓄压器（保证应急动力）

#### 3. 用户级余度

- 关键舵面（副翼、升降舵、方向舵）的作动器均由多套系统供压
- Power Control Unit（PCU）内部双腔设计

#### 4. 故障检测与隔离

- 每套系统配备压力传感器、温度传感器、液位传感器
- 飞控计算机实时监控液压系统状态
- 自动隔离故障分支，防止全系统失效

### 蓄压器

C919 液压系统配备多个蓄压器（accumulator），主要功能：

1. **应急动力**：在液压泵失效时提供短期液压动力
2. **脉动衰减**：吸收压力脉动，保证系统压力稳定
3. **瞬时大流量**：在用户瞬时需求大于泵流量时补充

蓄压器类型为活塞式或隔膜式，预充氮气压力约 1,500 psi。

### 液压系统监控

C919 液压系统通过航电系统进行实时监控，主要监控参数：

| 参数 | 监测点 | 报警阈值 |
| --- | --- | --- |
| 系统压力 | 每套系统出口 | <2,500 psi 或 >3,300 psi |
| 油液温度 | 每套系统回油 | >110℃ |
| 油液液位 | 每套系统油箱 | <50% 容量 |
| 过滤器压差 | 每套系统过滤器 | >0.7 MPa |
| 泵出口压力 | 每个 EDP/EMP | 异常波动 |

监控数据通过 ARINC 664 以太网传输至驾驶舱显示系统，飞行员可通过 ECAM（电子集中飞机监控）页面查看液压系统状态。

### 液压系统试验

C919 液压系统在适航取证过程中完成了以下试验：

1. **地面试验**：液压系统全功能地面试验
2. **飞行试验**：在各种飞行包线内验证液压系统性能
3. **失效试验**：模拟各种失效模式（双系统失效、单系统失效等）
4. **温度试验**：在 -55℃ 至 +135℃ 全温度范围内验证
5. **振动试验**：模拟发动机振动环境下的可靠性
6. **EMI 试验**：电磁兼容性试验

累计试验时间约 4,200 小时（与试飞时间一致），验证了液压系统的可靠性。

### 液压系统与电传飞控的协同

C919 采用电传飞控（FBW）系统，飞控计算机输出电信号，通过液压作动器转换为机械动作。协同流程：

1. 飞行员操纵杆输入 → 飞控计算机
2. 飞控计算机计算所需舵面偏转
3. 电信号传输至液压作动器伺服阀
4. 伺服阀控制液压流量至作动器
5. 作动器推动舵面偏转

电传系统为三余度，液压系统为三余度，二者结合形成高可靠性的飞控-液压复合系统。
