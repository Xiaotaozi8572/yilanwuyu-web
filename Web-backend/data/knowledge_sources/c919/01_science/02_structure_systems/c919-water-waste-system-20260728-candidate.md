# C919 水废水系统：淡水箱、真空马桶、引气增压

## 正文

### 水废水系统的功能

C919 的水废水系统负责为客舱和机组提供饮用水、洗手水，并收集和处理废水。该系统是客舱服务系统的一部分，虽不直接影响飞行安全，但直接影响乘客体验和航班正常运行。C919 的客舱系统供应商包括 Liebherr（空气管理系统）和嘉泰（AVIC 舱内系统，座椅 JT220B/JT220E），水废水系统作为客舱子系统之一配置。

### 系统组成

C919 的水废水系统由以下主要部件构成：

| 子系统 | 功能 | 关键部件 |
| --- | --- | --- |
| 饮用水系统 | 储存并向客舱/厨房供水 | 淡水箱、增压系统、管路 |
| 厕所冲洗系统 | 冲洗马桶并输送污物 | 真空马桶、污物箱 |
| 废水排放系统 | 收集洗手池废水并排出机外 | 废水管路、排放阀、加热器 |
| 水量指示系统 | 显示水箱水量 | 水量传感器、驾驶舱指示 |

### 淡水箱与供水

C919 的饮用水储存在机身下部的水箱中，水箱容量根据座位数和航程需求配置（窄体客机通常 200-300 升）。水箱采用不锈钢或复合材料制造，内部需符合食品级卫生要求。水从水箱通过管路输送至客舱厨房（galley）和厕所洗手池。

水箱增压是供水的核心机制。C919 采用发动机引气为水箱增压——引气经过减压后进入水箱气室，将水压送至各用水点。引气增压的优点是无需独立水泵，结构简单；缺点是引气中可能含有油污等污染物，因此水箱内需设置气水分离器和过滤装置。在地面发动机未运行时，可使用 APU 引气或地面气源为水箱增压。

### 真空马桶系统

C919 的厕所采用真空马桶系统。真空马桶的工作原理：

- 冲洗时机组或乘客按下冲洗按钮
- 冲洗阀短暂开启（约 2-3 秒），少量冲洗水（约 0.5 升）流入马桶
- 真空泵或机内外压差产生的抽吸力将污物通过管路吸入污物箱
- 冲洗阀关闭，系统复位

真空马桶相比传统重力冲水马桶的优势：用水量极少（每次 0.5 升 vs 传统马桶 4-6 升），管路直径小，安装灵活，不受飞机姿态影响。C919 在巡航高度（如 12,200 m）飞行时，机外气压远低于客舱气压，可直接利用压差驱动污物输送，无需真空泵；在地面低高度时则启用真空泵辅助。

### 污物箱

C919 每个厕所配置一个污物箱（或多个厕所共用一个集中污物箱）。污物箱安装在机身下部厕所对应位置，容量按航线运行需求配置。污物箱内加入少量化学消毒液（"蓝液"），抑制细菌繁殖和异味。污物箱配备满量传感器，当污物量达到 80% 时在驾驶舱或服务面板指示，提示地面服务人员排放。

### 废水排放

厕所洗手池和厨房的下水属于"灰水"（grey water），通过废水管路收集后排出机外。C919 的废水排放口通常位于机身下部，配备防冰加热器——废水在低温高空排出时若结冰可能堵塞排放口，加热器防止结冰堵塞。废水排放阀由客舱服务系统控制，在地面通常关闭以防泄漏。

### 水系统防冻

C919 的水废水管路在低温环境（如高空巡航时机身蒙皮温度可达 -40°C 以下）存在结冰风险。防冻措施包括：

- 管路布置在水箱和厕所附近的保温区域内
- 关键管路段落配备电加热带
- 水箱本身布置在增压舱内的保温区，不直接接触蒙皮
- 在寒冷天气地面停靠时，需执行水系统排空程序，防止过夜结冰损坏管路

### 地面服务

C919 在地面过站时由地面服务车进行水废水服务：

- 饮用水车通过加水口向水箱补充饮用水
- 污水车通过排放口抽取污物箱内容物
- 服务口通常位于机身下部舱门内，设有标识

地面服务的标准流程：先排放污物，再补充清水，避免交叉污染。服务完成后服务人员检查排放口和加水口盖板关闭锁定。

### 水量指示

C919 的水箱配备水量传感器（通常为电容式或浮子式），将水量信号传输至驾驶舱或客舱服务面板显示。机组和乘务员可根据水量预判航程供水是否充足，必要时调整客舱服务（如减少厨房用水、优先保证厕所洗手水）。
