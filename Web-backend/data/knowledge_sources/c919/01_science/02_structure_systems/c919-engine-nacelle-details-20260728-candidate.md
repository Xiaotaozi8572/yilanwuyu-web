## 正文

### 短舱总体概述

C919 发动机短舱（nacelle）是包裹发动机的流线型结构，主要功能包括：

1. 提供进气整流，保证发动机进气质量
2. 保护发动机免受外部环境损害
3. 提供反推装置安装结构
4. 实现发动机噪声抑制
5. 提供灭火和通风系统接口

C919 短舱由 Nexcelle 公司提供，型号为 PANACHE（中文名"奔耐驰"）。Nexcelle 是 CFM 国际公司的母公司 GE 与赛峰集团（Safran）合资成立的短舱公司，专门为 LEAP 系列发动机提供短舱。

### Nexcelle 公司背景

Nexcelle 成立于 2008 年，由 GE 航空集团（持股 50%）和赛峰短舱公司（持股 50%）合资组建。该公司专注于下一代发动机短舱的研制，主要产品包括：

- LEAP-1A 短舱（用于 A320neo）
- LEAP-1B 短舱（用于 B737 MAX）
- LEAP-1C 短舱（用于 C919，型号 PANACHE）
- Passport 短舱（用于 Global 7000/8000 公务机）

Nexcelle 通过统一短舱供应商的方式，使 LEAP 系列发动机的短舱设计具备一致性，并优化发动机与短舱的匹配。

### PANACHE 短舱技术特征

C919 选用的 PANACHE 短舱具有以下技术特征：

1. **一体化设计**：进气道、风扇外罩、反推装置、排气锥一体化集成
2. **复合材料广泛应用**：复合材料占比超过 50%，显著减重
3. **声学处理**：进气道和风扇外罩内壁采用声学衬层
4. **O-Duct 整体式反推**：单一环形门反推装置
5. **电驱反推**：采用电力驱动而非传统的液压或气动驱动

PANACHE 短舱与 LEAP-1C 发动机的匹配参数：

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 短舱长度 | 约 5.0 m | 进气口到排气口 |
| 短舱最大直径 | 约 2.3 m | 风扇外罩 |
| 进气道直径 | 约 1.85 m | 风扇入口 |
| 风扇叶片数 | 18 片 | LEAP-1C 标定 |
| 复合材料占比 | >50% | 主要承力结构 |
| 重量 | 约 800 kg | 单侧短舱 |

### 进气道设计

进气道（intake/cowl）是短舱前部组件，主要功能是向发动机提供均匀、稳定的气流。C919 进气道特征：

- **型面**：经过优化的气动型面，NACA 1 系列衍生
- **唇口半径**：约 12 cm，平衡低速性能和高速效率
- **扩散段**：内部轻微扩散，减小气流速度梯度
- **防冰**：采用热气防冰系统，引气来自发动机高压压气机
- **声学衬层**：内壁穿孔板+蜂窝芯+背板的三层结构

声学衬层工作原理：

- 穿孔板允许声波进入
- 蜂窝芯空腔共振吸收特定频率声波
- 主要吸收风扇噪声（频率 1-5 kHz）
- 噪声降低约 5-10 dB

### 风扇外罩

风扇外罩（fan cowl）是短舱中部组件，包裹发动机风扇段。C919 风扇外罩特征：

- **结构**：复合材料蜂窝夹芯结构
- **材料**：碳纤维环氧蒙皮 + Nomex 蜂窝芯
- **开口**：维护口盖（用于风扇叶片检查和更换）
- **声学衬层**：内壁同样有声学处理
- **气动外形**：保持层流，减小阻力

风扇外罩通过快卸锁（quick-release latch）固定在进气道和反推装置之间，便于维护人员打开发动机。

### O-Duct 反推装置

C919 选用的 O-Duct 反推装置是 PANACHE 短舱的标志性技术。O-Duct 是一种整体式环形反推装置，与传统 D 形反推门相比具有显著优势。

#### 传统 D 形反推 vs O-Duct

| 特征 | D 形反推门 | O-Duct |
| --- | --- | --- |
| 形状 | 两个半圆形门 | 一个完整环形门 |
| 滑动方式 | 两侧导轨 | 360° 全周导轨 |
| 反推气流 | 上半部 + 下半部 | 整个环形均布 |
| 气流对称性 | 较差 | 优秀 |
| 重量 | 较重 | 减重约 20% |
| 维护 | 需要校准两侧门 | 单一组件 |
| 故障模式 | 两侧可能不同步 | 同步性更好 |

#### O-Duct 工作原理

1. 飞行员选择反推（着陆后）
2. 电力作动器驱动 O-Duct 整体向后滑动
3. 阻流门（blocker doors）展开，挡住风扇气流出口
4. 风扇气流被强制向外侧偏转，产生反推力
5. 反推力使飞机减速

#### O-Duct 性能参数

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 滑动距离 | 约 30 cm | 沿轴向 |
| 反推效率 | 约 35-40% | 最大反推力与最大正推力比 |
| 驱动方式 | 电力 | 4 个电机同步驱动 |
| 同步精度 | <5 mm | 4 个电机位置差 |
| 工作时间 | 约 10 秒 | 从指令到完全展开 |

### 电驱反推的优势

C919 是较早采用电驱反推（Electric Thrust Reverser, ETR）的窄体客机。电驱相比传统液压驱动的优势：

1. **重量减轻**：无需复杂的液压管路，减重约 30-50 kg
2. **响应快速**：电力传输延迟低于液压
3. **维护简单**：电机免维护，无液压油泄漏风险
4. **可靠性高**：电驱系统故障率低
5. **可控性好**：精确定位，便于同步控制

电驱反推由 Hamilton Sundstrand-AVIC 提供的电力系统供电。

### 排气锥

排气锥（exhaust cone）位于短舱后部，主要功能是平滑排气流，减小基底阻力。C919 排气锥特征：

- **形状**：流线型锥形
- **材料**：钛合金（耐高温）
- **结构**：双层壁冷却结构
- **长度**：约 0.8 m

排气锥与发动机喷管配合，将核心机排气加速排出，提高排气效率。

### 反推装置适航要求

C919 反推装置满足 CCAR 25 部适航要求：

- **CCAR 25.933**：反推装置必须能在任何工作条件下安全运行
- **CCAR 25.1305**：必须有清晰的指示系统显示反推状态
- **CCAR 25.901**：反推系统必须防止意外展开

C919 反推装置在 4,200 小时试飞中进行了大量验证，包括：

- 干跑道和湿滑跑道反推试验
- 反推不对称展开试验
- 反推故障情况下飞行试验
- 反推快速收回试验

### 短舱降噪设计

C919 短舱是飞机降噪设计的重要组成部分，主要降噪措施：

1. **进气道声学衬层**：吸收风扇前传噪声 5-10 dB
2. **风扇外罩声学衬层**：吸收风扇后传噪声 3-5 dB
3. ** Chevron 锯齿形喷管**：风扇排气与自由流混合降噪（部分配置）
4. **O-Duct 反推气动力学优化**：减小反推噪声

C919 整机噪声水平满足 ICAO 第四章（Chapter 4）噪声标准，且满足更严格的 ICAO 第十四章（Chapter 14）要求，噪声余量约 5-8 EPNdB。

### 短舱安装接口

C919 短舱通过发动机挂架（pylon）安装在机翼下表面。挂架主要功能：

1. 传递发动机推力到机翼
2. 提供发动机与机翼之间的气动过渡
3. 容纳燃油管路、电气线路、液压管路
4. 隔离发动机振动传递到机翼

挂架结构主要为钛合金，能够承受发动机最大推力 137.14 kN（LEAP-1C30 ER）的载荷。
