## 正文

### 尾翼总体布局

C919 采用常规尾翼布局（conventional tail），由垂直尾翼（vertical stabilizer/fin）和水平尾翼（horizontal stabilizer/tailplane）组成。这种布局在窄体客机中应用最为广泛，空客 A320 系列和波音 737 系列均采用此布局。常规布局相比 T 形尾翼、H 形尾翼等具有结构简单、重量轻、操纵特性良好等优点。

C919 尾翼主要参数：

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 垂尾高度 | 约 5.5 m | 从机身顶部 |
| 垂尾后掠角 | 约 35° | 提高尾臂效率 |
| 垂尾面积 | 约 22 m² | 含方向舵 |
| 方向舵面积 | 约 5 m² | 单块式 |
| 平尾翼展 | 约 12.5 m | 含升降舵 |
| 平尾面积 | 约 30 m² | 含升降舵 |
| 升降舵面积 | 约 6 m² | 左右各 1 块 |
| 平尾安装角 | 可调 | 配平功能 |

### 垂直尾翼结构

垂直尾翼（vertical stabilizer）主要作用是提供航向稳定性，并安装方向舵用于航向操纵。C919 垂尾结构特点：

- **翼型**：对称翼型，NACA 0012 系列衍生
- **后掠角**：约 35°，提高尾臂效率并降低阻力
- **翼根弦长**：约 4.5 m
- **翼尖弦长**：约 1.8 m
- **梯形比**：约 0.4
- **结构形式**：双梁式盒形结构

垂尾结构主要部件：

| 部件 | 材料 | 说明 |
| --- | --- | --- |
| 前梁 | 复合材料 | 主要承力件 |
| 后梁 | 复合材料 | 主要承力件 |
| 蒙皮 | 复合材料 | 整体壁板 |
| 翼肋 | 复合材料 | 6-8 个 |
| 根部接头 | 钛合金 | 与机身连接 |

C919 垂尾是机体中复合材料使用比例最高的部件之一，主要结构（蒙皮、梁、肋）均采用碳纤维复合材料，相比铝合金结构减重约 20-25%。

### 方向舵

方向舵（rudder）是安装在垂尾后缘的可动翼面，用于提供航向操纵力矩。C919 方向舵主要特征：

- **结构**：复合材料蜂窝夹芯结构
- **面积**：约 5 m²
- **偏转角度**：±25°
- **驱动方式**：电传飞控系统驱动液压作动器
- **供应商**：Hongfei（Honeywell-AVIC 合资）提供飞控系统

方向舵主要功能：

1. **航向操纵**：起飞、着陆阶段进行侧风修正
2. **协调转弯**：与副翼配合实现协调转弯
3. **侧滑控制**：在不平衡推力情况下保持航向
4. **偏航阻尼**：自动抑制荷兰滚振荡

### 水平尾翼结构

水平尾翼（horizontal stabilizer）主要作用是提供纵向稳定性和俯仰操纵力矩。C919 平尾为全动式（可调安装角），由前端的安定面和后缘的升降舵组成。

平尾主要参数：

| 参数 | 数值 |
| --- | --- |
| 翼展 | 约 12.5 m |
| 翼根弦长 | 约 2.5 m |
| 翼尖弦长 | 约 1.2 m |
| 后掠角 | 约 30° |
| 安定面面积 | 约 24 m² |
| 升降舵面积 | 约 6 m² |
| 安装角调节范围 | -3° 至 +1° |

平尾结构与垂尾类似，采用双梁盒形结构，主要部件为复合材料。安定面安装角可通过水平安定面配平系统（HTSM）在飞行中调节，实现纵向配平。

### 升降舵

升降舵（elevator）是安装在平尾后缘的可动翼面，用于俯仰操纵。C919 升降舵特征：

- **结构**：复合材料蜂窝夹芯结构
- **数量**：左右各 1 块
- **面积**：约 6 m²
- **偏转角度**：上偏 +25°，下偏 -15°
- **驱动**：电传飞控系统驱动液压作动器

升降舵与安定面共同实现纵向操纵：

- 升降舵用于快速俯仰操纵（如起飞抬轮、着陆拉平）
- 安定面安装角调节用于配平，减轻飞行员操纵力

### 尾翼材料与制造

C919 尾翼结构大量使用复合材料，主要材料：

| 材料 | 类型 | 应用 |
| --- | --- | --- |
| 碳纤维环氧复合材料 | T800/977-2 | 蒙皮、梁、肋 |
| 蜂窝夹芯 | Nomex 芳纶纸 | 升降舵、方向舵 |
| 钛合金 | Ti-6Al-4V | 接头、紧固件 |
| 铝合金 | 7075-T6 | 部分次要结构 |

C919 尾翼由 AVIC 下属的沈阳飞机工业集团（SAC）制造，采用的主要工艺：

- **自动铺带（ATL）**：用于蒙皮和大型壁板
- **树脂转移成形（RTM）**：用于复杂形状部件
- **热压罐固化**：保证复合材料致密度
- **数控加工**：保证接头和紧固件精度

### 尾翼气动设计

C919 尾翼气动设计要点：

1. **后掠角选择**：垂尾后掠 35°、平尾后掠 30°，平衡尾臂效率和结构重量
2. **翼型选择**：对称翼型，避免不必要的升力
3. **尾臂长度**：从重心到尾翼焦点距离约 14-15 m，保证稳定性
4. **端板效应**：垂尾与平尾的连接处设计，减小诱导阻力

### 尾翼与飞控的协同

C919 尾翼与电传飞控系统（FBW）协同工作，实现以下功能：

| 功能 | 实现方式 |
| --- | --- |
| 航向操纵 | 方向舵偏转 |
| 俯仰操纵 | 升降舵偏转 |
| 偏航阻尼 | 方向舵自动小幅偏转 |
| 配平 | 安定面安装角调节 |
| 包线保护 | 飞控计算机限制偏转角 |

飞控系统通过三余度设计提高可靠性，关键作动器均采用双余度液压供应。

### 尾翼适航要求

C919 尾翼设计满足 CCAR-25 适航要求，主要条款：

- **CCAR 25.415**：尾翼突风载荷
- **CCAR 25.427**：非对称载荷
- **CCAR 25.429**：尾翼机动载荷
- **CCAR 25.445**：辅助气动力面
- **CCAR 25.651**：方向舵和升降舵强度

尾翼在试飞中完成 4,200 小时累计飞行验证，涵盖颤振、突风、机动等多种工况。
