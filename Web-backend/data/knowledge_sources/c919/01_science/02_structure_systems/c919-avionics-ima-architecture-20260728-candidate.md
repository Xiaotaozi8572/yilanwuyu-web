## 正文

### IMA 架构概述

C919 航电系统采用综合模块化航电（Integrated Modular Avionics, IMA）架构，这是当前最先进的航电系统架构。IMA 架构通过共享的计算平台、统一的网络通信和标准化的接口，将传统的分布式航电系统整合为集中式计算资源。

C919 的 IMA 系统由 AVIAGE Systems（GE 与 AVIC 合资公司）提供。AVIAGE Systems 成立于 2012 年，由 GE 航空集团（持股 50%）和中国航空工业集团（AVIC，持股 50%）合资组建，专门为 C919 项目提供航电系统。

### IMA 与传统航电对比

传统航电系统（Federated Avionics）采用每个功能独立的计算机：

- 每个功能（如导航、通信、飞控）有专用 LRU（Line Replaceable Unit）
- 计算资源无法共享
- 重量大、功耗高
- 升级和维护困难

IMA 架构的优势：

| 特征 | 传统航电 | IMA 架构 |
| --- | --- | --- |
| 计算资源 | 各自独立 | 共享计算平台 |
| 软件架构 | 嵌入式专用 | ARINC 653 分区 |
| 网络 | ARINC 429 串行 | ARINC 664 以太网 |
| 重量 | 较重 | 减重约 30% |
| 升级性 | 困难 | 软件升级 |
| 故障隔离 | 物理隔离 | 时间和空间分区 |

### AVIAGE Systems 提供的核心组件

C919 IMA 架构中，AVIAGE Systems 提供以下核心组件：

1. **核心处理平台（Core Processing Input Output Module, CPIOM）**：通用计算模块
2. **显示系统（Display System）**：驾驶舱主显示器
3. **飞行管理系统（Flight Management System, FMS）**：TrueCourse FMS
4. **综合显示系统（Integrated Display System, IDS）**：6 块主显示器

### CPIOM 模块

C919 IMA 架构中，核心处理模块（CPIOM）是计算资源的主要载体。CPIOM 特征：

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 处理器 | PowerPC 架构 | 高可靠性嵌入式处理器 |
| 内存 | 256 MB | 应用软件存储 |
| 接口 | ARINC 664 + ARINC 429 + 离散量 | 多种接口 |
| 操作系统 | ARINC 653 兼容实时操作系统 | 分区管理 |
| 故障检测 | 内置 BITE | 自动检测 |
| 数量 | 8-10 个 CPIOM | 全机分布 |

ARINC 653 标准的关键特性是分区（Partitioning）：

- **时间分区**：每个应用分配固定时间片，互不干扰
- **空间分区**：每个应用有独立内存空间，防止越界访问
- **健康监控**：操作系统监控应用健康状态
- **故障隔离**：一个应用故障不影响其他应用

### ARINC 664 网络架构

C919 IMA 架构的通信网络基于 ARINC 664 Part 7 标准（即 AFDX, Avionics Full-Duplex Switched Ethernet）。ARINC 664 网络特征：

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 带宽 | 100 Mbps | 全双工以太网 |
| 拓扑 | 双冗余星型 | A 网和 B 网 |
| 延迟 | <150 μs | 端到端 |
| 误码率 | <10⁻⁹ | 高可靠 |
| 协议 | UDP/IP 简化 | 减小开销 |
| 虚链路 | 多个 VL | 隔离不同流量 |

ARINC 664 的关键概念是虚链路（Virtual Link, VL）：

- 每个虚链路有固定的带宽分配
- 不同应用的流量通过虚链路隔离
- 网络交换机根据虚链路标识路由数据
- 保证关键应用的网络带宽

### C919 航电网络结构

C919 航电网络采用分层星型拓扑：

```
[驾驶舱显示器] ←→ [网络交换机 A/B] ←→ [CPIOM 模块群]
                          ↑
                       [各种传感器]
                          ↑
                  [发动机、飞控、液压、燃油等]
```

主要网络节点：

- **网络交换机**：6-8 台（双冗余）
- **CPIOM**：8-10 个
- **显示器**：6 块主显示器
- **远程接口单元（RIU）**：多个，用于传统传感器接口

### 驾驶舱显示系统

C919 驾驶舱显示系统由 AVIAGE Systems 提供，主要组成：

| 显示器 | 数量 | 尺寸 | 显示内容 |
| --- | --- | --- | --- |
| 主飞行显示器（PFD） | 2 | 15 英寸 | 左右座各 1，姿态、航向、空速 |
| 导航显示器（ND） | 2 | 15 英寸 | 左右座各 1，航路、气象雷达 |
| 发动机指示/机组告警系统（EICAS） | 1 | 15 英寸 | 中央，发动机参数 |
| 多功能显示器（MFD） | 1 | 15 英寸 | 系统页面、检查单 |
| 备用显示器（ISI） | 1 | 5 英寸 | 独立电池供电，应急 |

显示系统通过 ARINC 664 接收数据，通过图形发生器生成显示画面。

### 平视显示器（HUD）

C919 配备平视显示器（Head-Up Display, HUD），由 AVIC 光电（中航工业光电技术研究所）提供。HUD 特征：

- **安装位置**：左右座各 1 个
- **视场**：水平 30°，垂直 25°
- **显示内容**：主要飞行参数、引导信息
- **优点**：飞行员无需低头看仪表
- **应用场景**：起飞、进近、着陆

### 增强视景系统（EVS）

C919 配备增强视景系统（Enhanced Vision System, EVS），由 Elbit Kollsman 公司提供。EVS 通过红外相机捕捉机场环境，在 HUD 上显示，主要用途：

1. **低能见度着陆**：在雾、雨等低能见度条件下辅助着陆
2. **夜间飞行**：增强夜间视觉
3. **机场识别**：提前发现跑道和滑行道

EVS 通过 ARINC 664 与 HUD 集成，将红外图像叠加在 HUD 显示画面上。

### 飞行管理系统（TrueCourse）

C919 飞行管理系统（FMS）采用 AVIAGE Systems 提供的 TrueCourse 系统，主要功能：

1. **航路规划**：飞行计划制定和修改
2. **性能计算**：根据飞机状态计算最优飞行剖面
3. **导航**：综合 GPS、VOR、DME、IRS 等导航源
4. **引导**：自动驾驶仪和飞行指引仪的横向/纵向引导
5. **数据库管理**：导航数据库（NavDB）和性能数据库

TrueCourse 系统参数：

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 数据库容量 | >500 MB | 包含全球机场和航路 |
| 航路点容量 | >10,000 | 全球航路点 |
| 导航精度 | <0.1 nm | RNP 0.1 |
| 计算速度 | 100 ms | 性能计算周期 |

### 飞控计算机（FCC）

C919 飞控计算机（Flight Control Computer, FCC）由 Hongfei（Honeywell-AVIC 合资）提供，是电传飞控系统的核心：

- **数量**：3 套（三余度）
- **架构**：三重独立通道
- **接口**：ARINC 664 + 离散量
- **功能**：控制律计算、舵面指令生成、包线保护

FCC 通过 ARINC 664 与 IMA 网络连接，接收飞行员输入和传感器数据，计算所需舵面偏转，输出指令至液压作动器。

### 大气数据与惯导系统

C919 大气数据与惯导系统由 Honeywell 提供，型号为 LASERREF IV：

- **大气数据计算机（ADC）**：3 套
- **激光惯导（IRS）**：3 套
- **组合方式**：ADC + IRS + GPS 组合导航
- **更新率**：50 Hz
- **精度**：惯导 1 nm/h，GPS 10 m

LASERREF IV 通过 ARINC 664 输出数据至 IMA 网络，供飞控、导航、显示等系统使用。

### 气象雷达

C919 气象雷达由 ALRAC（Collins-AVIC 合资）提供，主要功能：

1. **气象探测**：探测前方 320 km 范围内的气象
2. **湍流探测**：识别湍流区域
3. **风切变探测**：进近阶段探测微下击暴流
4. **地形探测**：辅助地形回避

气象雷达通过 ARINC 664 输出气象图像至 ND 显示器，飞行员可看到彩色气象图。

C919 通信导航系统由 RCCAC（Collins-CETCA 合资）提供，主要包括：

| 系统 | 类型 | 频段 | 用途 |

### IMA 架构的适航要求

C919 IMA 架构满足以下适航要求：

- **CCAR 25.1309**：系统和设备的可靠性
- **CCAR 25.1316**：电气和电子系统的闪电保护
- **CCAR 25.1317**：高强辐射场（HIRF）保护
- **DO-178C**：机载软件适航
- **DO-254**：机载硬件适航
- **DO-297**：IMA 系统适航

IMA 架构的适航验证需要证明：

1. 分区有效，应用互不干扰
2. 网络冗余，单点失效不影响安全
3. 软件独立验证
4. 硬件失效容错

### IMA 架构的优势体现

C919 IMA 架构带来的具体优势：

1. **重量减轻**：相比传统航电减重约 200-300 kg
2. **功耗降低**：相比传统航电降低约 30%
3. **可靠性提升**：通过冗余设计提升可靠性
4. **维护便利**：模块化设计便于更换
5. **升级便利**：软件升级即可添加新功能
6. **故障诊断**：内置 BITE 自动诊断
