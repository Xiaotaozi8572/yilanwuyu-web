# C919 经济影响评估：产业链带动、就业、技术溢出

## 来源
- 主要来源：Wikipedia "Comac C919"（en.wikipedia.org/wiki/Comac_C919）
- 访问日期：2026-07-29

## 正文

### 项目投入规模

C919 项目的投入规模反映了其对经济的影响基础：

| 投入维度 | 数值 |
| --- | --- |
| 立项预算（2008） | CN¥580 亿 / US$95 亿 |
| 实际投入估算 | >CN¥1,250 亿 / >US$200 亿 |
| 目录价格 | CN¥6.53 亿 / US$1.01 亿 |
| 已交付数量 | 37 架（截至 2026-05） |
| 已制造数量 | 44 架（含 8 架原型机） |

实际投入远超立项预算（约 2.2 倍），这一投入分散在 2008-2026 年的 18 年研制周期中，带动了航空产业链的整体发展。

### 产业链带动

C919 项目带动的产业链覆盖航空工业的多个层级：

#### 上游：材料与元器件

| 产业 | C919 需求 | 国产化进展 |
| --- | --- | --- |
| 铝合金 | 机身主材 | 国产化（AVIC） |
| 铝锂合金 | 8.8% 结构占比 | 部分国产 |
| 碳纤维复合材料 | 12% 结构占比 | 部分国产（中央翼盒改铝合金） |
| 航电芯片 | 航电系统核心 | 部分进口 |
| 紧固件 | 全机连接 | 国产化 |

C919 对先进材料的需求拉动了国内铝锂合金、碳纤维复合材料等材料工业的发展。中央翼盒原计划用碳纤维复合材料后改铝合金，反映了国产复合材料在主承力结构应用上的成熟度差距，但 C919 的需求仍推动了相关材料研发。

#### 中游：系统与部段制造

| 产业 | C919 供应商 | 国别 |
| --- | --- | --- |
| 机体制造 | AVIC（西飞、成飞、沈飞、洪都） | 中国 |
| 发动机 | CFM LEAP-1C | 美法合资 |
| 航电 | AVIAGE Systems 等 | 美中合资 |
| 飞控 | Hongfei Flight Control | 美中合资 |
| 起落架 | Liebherr LAMC | 德中合资 |
| 短舱 | Nexcelle | 法/美/新加坡 |
| APU | Honeywell | 美国 |
| 座椅 | 嘉泰 | 中国 |

C919 的中游供应链通过合资公司模式带动了国内系统研制能力的提升。AVIAGE Systems（昂际航电）、Hongfei Flight Control（鸿飞飞控）、Liebherr LAMC 等合资公司不仅服务 C919，其积累的系统集成能力可外溢至其他航空项目。

#### 下游：总装、运营、维护

| 产业 | 角色 |
| --- | --- |
| 总装 | COMAC 上海浦东总装基地 |
| 航空公司运营 | 东航、国航、南航 |
| 航线维护 | 各航空公司机务部门 |
| 大修（MRO） | COMAC 客服公司及航空公司 MRO |
| 航材供应 | 供应商授权经销商 + 国产替代 |

截至 2026 年 5 月已交付 37 架，带动了航线维护和大修产业的发展。C919 机队规模扩大将催生专门的 MRO 服务需求。

### 就业带动

C919 项目的就业带动体现在三个层面：

- 直接就业：COMAC 及合资公司的研制、生产、客服人员
- 间接就业：供应商及其下游的零部件、材料供应商员工
- 诱发就业：航空运营、维护、培训等相关服务业就业

具体的就业人数属于动态数据，公开数据有限。C919 作为大型航空项目，直接和间接就业规模通常以万计，涵盖工程师、技术工人、飞行员、机务人员、客服人员等多种岗位。

### 技术溢出

C919 项目的技术溢出体现在多个方面：

#### 航空工业能力

- 机体设计能力：C919 的超临界机翼设计（气动效率 +20%，阻力 -8%）、机身截面设计（12.915 m² 横截面积）积累的设计经验
- 系统集成能力：通过合资公司参与的航电、飞控、起落架系统集成经验
- 适航审定能力：4,200 小时取证试飞、CCAR-25 部审定流程的完整实践
- 复合材料应用：12% 复合材料占比的应用经验

#### 国产化率提升路径

C919 国产化率约 60%（按成本），成本构成：

| 类别 | 成本占比 |
| --- | --- |
| 结构 | 36% |
| 发动机 | 22% |
| 航电 | 17% |
| 机电 | 13% |
| 其余 | 12% |

CJ-1000A 国产发动机（2009 年开始研制，2017 年 12 月总装完成，2018 年 5 月首次运转 6,600 rpm，2023 年 3 月在运-20 上试飞，预计 2027-2028 认证、2030 年量产）的研制直接受益于 C919 项目对发动机技术的需求拉动。

#### 衍生型号发展

C919 系列的衍生型号发展也是技术溢出的体现：

| 变体 | 座位 | 状态 |
| --- | --- | --- |
| C919-100 STD | 158-168 | 已服役 |
| C919-100 ER | 158-168 | 已取证 |
| C919-600 | 140-160 | 2026-01-08 出厂 |
| C919-800 | 约 218 | 预计 2030 服役 |

C919-600 缩短型（拆除 6 个机身框）和 C919-800 加长型（增加约 50 座）的研制，复用了 C919-100 的设计经验和供应链，是技术能力在产品线上的横向溢出。

### 经济影响的量化挑战

C919 经济影响的精确量化面临挑战：

- 投入与产出分散在长周期内（2008-2026+）
- 部分技术溢出难以货币化（如适航审定能力的获得）
- 国产化率提升的渐进性（CJ-1000A 2030 年才量产）
- 国际市场不确定（EASA 认证 2028-2031，FAA 未申请）

因此，C919 的经济影响评估更多侧重于定性分析和结构性数据，而非精确的投入产出比。

### 与国际同类项目的对比

C919 的经济影响可与空客 A320、波音 737 项目对比：

| 项目 | 立项 | 产业链特点 |
| --- | --- | --- |
| 波音 737 | 1964 | 美国本土产业链成熟 |
| 空客 A320 | 1981 | 欧洲多国合作产业链 |
| C919 | 2008 | 中国本土+国际合资产业链 |

C919 的产业链特点是"合资主导"——通过合资公司引入国际供应商，逐步建立本土能力。这一模式与空客早期的多国合作有相似之处，但 C919 的合资更强调技术转移的中方参与度。

### 长期经济影响展望

C919 的长期经济影响取决于：

- 产能爬坡：从当前 37 架交付到目标年产 50-100 架的稳定生产
- 国产化率提升：CJ-1000A 量产后国产化率从 60% 提升至接近 80%
- 国际市场拓展：EASA 认证后开拓欧盟及认可 EASA 的市场
- 衍生型号成功：C919-600/-800 等变体的市场表现
- 技术迭代：C919 经验向未来宽体客机（如 C929）的技术溢出
