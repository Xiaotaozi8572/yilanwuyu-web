# C919 国产化率分析：60% 成本构成、各系统国产化进展

## 来源
- 主要来源：Wikipedia "Comac C919"（en.wikipedia.org/wiki/Comac_C919）
- 访问日期：2026-07-29

## 正文

### 国产化率总览

C919 的国产化率约为 60%（按成本计算）。国产化率的定义和计算方式直接影响数值——按成本计算与按零件数量、按重量计算的结果差异较大。C919 的 60% 国产化率是按成本计算的行业估算，非 COMAC 官方公布数据。

### 成本构成分解

C919 按成本类别的国产化构成：

| 类别 | 成本占比 | 国产化情况 |
| --- | --- | --- |
| 结构 | 36% | 主要国产（AVIC） |
| 发动机 | 22% | 进口（CFM LEAP-1C） |
| 航电 | 17% | 合资为主（AVIAGE Systems 等） |
| 机电 | 13% | 合资与进口混合 |
| 其余 | 12% | 部分国产 |

国产化率 60% 意味着 40% 的成本来自国际供应商。结构（36%）主要由 AVIC 国产化，是国产化率的最大贡献项。发动机（22%）作为单一最大进口项，是国产化率提升的核心瓶颈。

### 各系统国产化进展

#### 机体结构（成本占比 36%，国产化高）

机体结构由 AVIC（中国航空工业集团）下属单位制造，国产化程度最高：

| 部段 | 制造单位 |
| --- | --- |
| 机头 | 成飞 |
| 前机身 | 洪都航空 |
| 中机身（含中央翼盒） | 西飞 |
| 后机身 | 沈飞 |
| 机翼 | 西飞 |
| 尾翼 | 相关 AVIC 单位 |

机身主要为铝合金，铝锂合金占结构 8.8%，复合材料占 12%。中央翼盒原计划用碳纤维复合材料，后改为铝合金。机体结构的国产化是 C919 区别于"组装飞机"的关键——机体设计、制造、试验由中方主导，是航空工业核心能力的体现。

#### 发动机（成本占比 22%，国产化低）

C919 当前配备 CFM International（GE-Safran 合资）的 LEAP-1C 发动机，完全进口。两个推力等级：

| 发动机型号 | 应用变体 | MTO 推力 | MCT 推力 |
| --- | --- | --- | --- |
| LEAP-1C28 | C919-100 STD | 129.98 kN (29,220 lbf) | 127.93 kN (28,760 lbf) |
| LEAP-1C30 | C919-100 ER | 137.14 kN (30,830 lbf) | 133.22 kN (29,950 lbf) |

LEAP-1C 与空客 A320neo 使用的 LEAP-1A 共享型号合格证。2025 年 5 月美国曾暂停 LEAP-1C 对华销售，2025 年 7 月解除暂停，凸显发动机供应的地缘政治风险。

国产替代发动机 CJ-1000A 的研制进展：

| 日期 | 事件 |
| --- | --- |
| 2009 年 | CJ-1000A 开始研制 |
| 2017-12 | 总装完成 |
| 2018-05 | 首次运转（6,600 rpm） |
| 2023-03 | 在运-20 上试飞 |
| 2027-2028（预计） | 认证 |
| 2030（预计） | 量产 |

CJ-1000A 量产后将逐步替代 LEAP-1C，使发动机从 22% 的进口成本转为国产。考虑到发动机是最大单项进口成本，CJ-1000A 的量产对 C919 国产化率提升影响最大。

#### 航电系统（成本占比 17%，合资为主）

C919 航电系统主要通过合资公司引入技术：

| 子系统 | 供应商 | 合资构成 |
| --- | --- | --- |
| 显示单元 | AVIAGE Systems | GE-AVIC 美中合资 |
| 飞行管理系统（TrueCourse） | AVIAGE Systems | GE-AVIC 美中合资 |
| 气象雷达 | ALRAC | Collins-AVIC 雷华 美中合资 |
| 通信导航 | RCCAC | Collins-CETCA 美中合资 |
| 大气数据系统 | Honeywell | 美国（进口） |
| 惯性参考系统（LASEREF IV） | Honeywell | 美国（进口） |
| 平视显示器 | AVIC 光电 | 中国 |
| 增强视景系统（Kollsman EVS-SP） | Elbit Systems of America | 以色列/美国 |
| 机上娱乐（TopSeries） | Thales-CETCA | 法中合资 |

合资模式下，中方通过合资公司参与系统集成，逐步掌握核心技术。AVIAGE Systems（昂际航电）作为 GE 与 AVIC 的合资公司，承担 C919 的显示单元和飞行管理系统，是航电国产化的重要载体。

#### 机电系统（成本占比 13%，合资与进口混合）

| 子系统 | 供应商 | 国别/性质 |
| --- | --- | --- |
| 主起落架 | Liebherr LAMC Aviation | 德中合资 |
| 前轮 | Honeywell | 美国 |
| APU（HGT750[C]） | Honeywell | 美国 |
| 空气管理系统 | Liebherr | 德国 |
| 增升系统 | Moog-AVIC 庆安 | 美中合资 |
| 电力系统 | RTX Hamilton Sundstrand-AVIC EM | 美中合资 |
| 轮胎 | Michelin Air X（主选）/ 桂林蓝宇（选装） | 法国/中国 |

机电系统中，主起落架（Liebherr LAMC）、增升系统（Moog-AVIC）、电力系统（RTX-AVIC）通过合资引入，APU、前轮、空气管理系统仍为进口。轮胎有国产选装（桂林蓝宇）。

#### 客舱与其他（成本占比 12%，部分国产）

| 子系统 | 供应商 | 国别 |
| --- | --- | --- |
| 座椅（JT220B/JT220E） | 嘉泰（AVIC 舱内系统） | 中国 |
| 短舱（PANACHE） | Nexcelle | 法/美/新加坡 |
| 反推装置（O-Duct） | Nexcelle | 法/美/新加坡 |

座椅由嘉泰（AVIC 舱内系统）国产化，是客舱系统中已实现国产的部分。短舱和反推装置由 Nexcelle（Safran-ST Engineering MRAS 合资）提供。

### 国产化率提升路径

C919 国产化率从当前 60% 提升的路径：

| 路径 | 影响 | 时间表 |
| --- | --- | --- |
| CJ-1000A 替代 LEAP-1C | +22%（发动机全国产） | 2030 年量产 |
| 合资公司中方技术份额提升 | 航电/机电逐步国产 | 持续推进 |
| 复合材料国产化 | 结构材料国产 | 持续推进 |
| 航电核心芯片国产化 | 航电国产 | 长期 |

发动机国产化是最大单项影响——CJ-1000A 量产后，C919 国产化率有望从 60% 提升至接近 80%。

### 国产化率与成本/价格的关联

国产化率提升对 C919 经济性的影响：

- 成本降低：国产部件成本通常低于进口，提升国产化率直接降低制造成本
- 汇率风险降低：进口比例下降，减少汇率波动对成本的影响
- 供应稳定性提升：减少国际供应链中断风险（如 LEAP-1C 暂停事件）
- 售后支持自主：国产部件的维修、备件供应更自主

但国产化率提升也面临挑战：

- 技术成熟度：国产替代部件需达到与进口部件同等的可靠性和寿命
- 适航重新验证：关键部件更换需重新进行适航验证
- 初期成本：国产化研发投入大，初期成本可能高于进口
