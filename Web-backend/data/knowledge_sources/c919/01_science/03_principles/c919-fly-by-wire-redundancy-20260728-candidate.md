## 正文

### 电传操纵概述

电传操纵（Fly-By-Wire, FBW）是用电子信号代替机械连杆传递飞行员操纵指令的技术。C919 采用全权限电传飞控系统，由 Hongfei（Honeywell-AVIC 合资）提供。

C919 FBW 系统特征：

- 三余度架构
- 全权限数字式控制
- 主动包线保护
- 多模式控制律

### FBW vs 机械操纵

| 特征 | 机械操纵 | FBW |
| --- | --- | --- |
| 信号传递 | 钢索/连杆 | 电信号 |
| 控制律 | 固定增益 | 可编程 |
| 重量 | 较重 | 减重约 200 kg |
| 维护 | 复杂 | 简单 |
| 自动化 | 困难 | 容易 |
| 包线保护 | 难实现 | 容易实现 |
| 故障检测 | 难 | 内置 BITE |

C919 采用 FBW 是民机主流选择，A320（1987 年首飞）是首款采用 FBW 的窄体客机，B737 在 MAX 之前一直使用机械操纵，MAX 才开始引入部分 FBW 功能。

### C919 FBW 架构

C919 FBW 系统由以下主要部件组成：

#### 1. 飞行员输入装置

- 主操纵杆（侧杆或盘式）：左右座各 1 个
- 方向舵脚蹬：左右座各 1 套
- 油门杆：左右座各 1 个
- 配平开关

C919 采用侧杆设计（与 A320 类似），主操纵杆位于驾驶舱左右两侧。

#### 2. 飞控计算机（FCC）

C919 配备 3 套飞控计算机（FCC），形成三余度：

- FCC1（主）
- FCC2（备份）
- FCC3（应急）

每套 FCC 独立计算控制指令，通过投票机制确定最终输出。

#### 3. 作动器

- 副翼作动器：每侧 1 个，PCU 双余度
- 升降舵作动器：每侧 1 个，PCU 双余度
- 方向舵作动器：1 个，PCU 三余度
- 襟翼/缝翼驱动：螺旋千斤顶
- 扰流板作动器：每侧 4-5 个

#### 4. 传感器

- 迎角传感器：3 个
- 侧滑角传感器：3 个
- 加速度计：3 套
- 陀螺仪：3 套（IRS）
- 大气数据：3 套（ADC）

### 三余度架构

C919 采用三余度架构，确保任意两套系统失效仍能安全飞行：

#### 余度层次

| 层次 | 余度数 | 失效容忍 |
| --- | --- | --- |
| FCC（飞控计算机） | 3 | 2 失效可工作 |
| 液压系统 | 3 | 2 失效可工作 |
| 电源 | 3（含应急） | 2 失效可工作 |
| 传感器 | 3 | 2 失效可工作 |
| 作动器 PCU | 2-3 | 1-2 失效可工作 |

#### 投票机制

FCC 三余度投票：

1. 三套 FCC 独立计算控制指令
2. 通过 ARINC 664 网络交换数据
3. 比较三套输出
4. 多数表决（2/3 投票）确定最终输出
5. 单套偏离时被标记为故障

#### 故障树分析

C919 FBW 故障树典型分析：

```
顶层事件：丧失飞行控制
├─ 三套 FCC 全部失效
│   ├─ FCC1 故障 (10⁻⁴/飞行小时)
│   ├─ FCC2 故障 (10⁻⁴)
│   └─ FCC3 故障 (10⁻⁴)
│   联合失效率：10⁻¹²/飞行小时
├─ 三套液压系统全部失效
│   └─ 联合失效率：<10⁻¹²
└─ 三套电源全部失效
    └─ 联合失效率：<10⁻¹²
```

C919 FBW 系统总失效率 <10⁻⁹/飞行小时，满足 CCAR 25.1309 适航要求（10⁻⁹ 是灾难性失效概率上限）。

### 控制律

C919 FBW 控制律（Control Law）分为多个模式：

#### 1. 正常律（Normal Law）

正常飞行使用，提供全功能+包线保护：

- 完整操纵响应
- 包线保护激活
- 自动配平
- 偏航阻尼

#### 2. 备用律（Alternate Law）

部分失效时使用，保留主要功能但限制包线保护：

- 操纵响应略减弱
- 部分包线保护减弱
- 自动配平减弱

#### 3. 直接律（Direct Law）

严重失效时使用，飞行员直接控制舵面：

- 无包线保护
- 无自动配平
- 飞行员负责所有控制

#### 4. 备用机械操纵（Mechanical Backup）

电气失效时使用，通过机械连杆控制方向舵和俯仰配平：

- 仅控制方向舵和配平
- 用于紧急着陆

### 包线保护

C919 FBW 提供多种包线保护功能：

#### 1. 迎角保护（Alpha Protection）

- 当迎角接近临界值（约 14°）时激活
- 自动推杆低头，减小迎角
- 防止失速

#### 2. 速度保护（Speed Protection）

- **低速保护**：当速度接近失速时，自动低头增速
- **高速保护**：当速度接近 VMO/MMO 时，自动抬头减速

#### 3. 坡度保护（Bank Angle Protection）

- 手动飞行：最大坡度 67°
- 自动驾驶：最大坡度 30°
- 超过限制时自动减小坡度

#### 4. 高度保护（Altitude Protection）

- 在所选高度附近自动保持
- 防止偏离高度过大

#### 5. 俯仰姿态保护（Pitch Attitude Protection）

- 限制俯仰姿态 +30°/-15°
- 防止过度抬头或低头

### FBW 与液压系统的协同

C919 FBW 通过电信号控制液压作动器，实现飞行员指令到舵面动作的转换：

```
飞行员输入 → FCC 计算 → 电信号 → 伺服阀 → 液压作动器 → 舵面偏转
```

协同特点：

1. **Power Control Unit（PCU）**：作动器内置 PCU，双腔设计
2. **伺服阀**：电液伺服阀，将电信号转换为液压流量
3. **位置反馈**：作动器内置位置传感器，闭环控制
4. **故障检测**：FCC 监控作动器响应，异常时切换至备用

### 余度设计的适航要求

C919 FBW 余度设计满足以下适航要求：

- **CCAR 25.671**：操纵系统总则
- **CCAR 25.672**：增稳系统及自动飞行操纵系统
- **CCAR 25.674**：飞行员操纵力
- **CCAR 25.1309**：设备、系统及安装
- **CCAR 25.1439**：备份飞行操纵系统

关键要求：

- 任何单点失效不能导致灾难性后果
- 双失效后仍能保持安全飞行
- 必须有机械备份（方向舵+俯仰配平）

### 试飞验证

C919 FBW 在 4,200 小时试飞中进行了大量验证：

1. **正常律试飞**：全包线内验证操纵特性
2. **失效模式试飞**：模拟 FCC/液压/电源失效
3. **包线保护试飞**：接近包线边界验证保护功能
4. **大迎角试飞**：验证迎角保护
5. **颤振试飞**：验证颤振边界
6. **故障注入试飞**：在飞行中注入故障，验证系统响应

### FBW 的优势

C919 采用 FBW 系统带来的优势：

1. **重量减轻**：相比机械操纵减重约 200 kg
2. **维护便利**：减少机械连杆维护点
3. **飞行员负荷减轻**：自动配平、偏航阻尼等功能
4. **飞行安全提升**：包线保护防止误操作
5. **飞行品质一致**：控制律可编程，全包线内一致
6. **升级便利**：软件升级即可改进性能

### FBW 的挑战

C919 FBW 系统的挑战：

1. **电磁兼容性（EMC）**：电信号易受干扰
2. **软件复杂性**：控制律软件需严格验证
3. **电源依赖**：依赖电源可靠性
4. **飞行员接受度**：侧杆缺乏力反馈
5. **认证成本**：DO-178C 软件认证成本高

C919 通过严格的设计、验证和试飞，确保 FBW 系统的安全性和可靠性。
