# C919 马赫数效应：压缩性与阻力发散

## 来源

## 正文

### 马赫数定义

马赫数（Mach Number, Ma）是流体速度与当地声速之比：

```
Ma = V / a
```

其中：
- V：流体速度
- a：当地声速

声速公式：

```
a = sqrt(γ × R × T)
```

其中：
- γ：比热比（空气 1.4）
- R：气体常数（287 J/kg·K）
- T：绝对温度（K）

在标准大气下：

| 高度 | 温度 | 声速 |
| --- | --- | --- |
| 海平面 | 15℃ (288 K) | 340 m/s (1,224 km/h) |
| 5,000 m | -17.5℃ (255.5 K) | 320 m/s (1,153 km/h) |
| 11,000 m | -56.5℃ (216.5 K) | 295 m/s (1,062 km/h) |
| 12,200 m | -56.5℃ (216.5 K) | 295 m/s (1,062 km/h) |

### C919 巡航马赫数

C919 巡航马赫数为 0.785，对应巡航速度 835 km/h。在 12,200 m 高度：

```
V = Ma × a = 0.785 × 295 m/s = 231.6 m/s = 833.7 km/h
```

与 C919 公布的 835 km/h 基本一致。

### 马赫数范围分类

根据马赫数范围，飞行可分为：

| 范围 | Ma 范围 | 流动特征 | 典型应用 |
| --- | --- | --- | --- |
| 不可压缩 | < 0.3 | 密度变化可忽略 | 小型飞机 |
| 亚音速 | 0.3 - 0.7 | 局部加速但全流场亚音速 | 螺旋桨飞机 |
| 跨声速 | 0.7 - 1.2 | 局部超声速区+激波 | 民用喷气客机 |
| 超声速 | 1.2 - 5.0 | 全场超声速 | 战斗机 |
| 高超声速 | > 5.0 | 极高温度效应 | 导弹、航天器 |

C919 巡航马赫数 0.785 处于跨声速范围下端，是民用喷气客机的典型巡航马赫数。

### 压缩性效应

在跨声速范围，空气压缩性效应变得显著：

#### 1. 密度变化

亚音速时空气密度近似不变，跨声速时密度变化不可忽略：

| Ma | 密度变化（等熵） |
| --- | --- |
| 0.3 | -4.5% |
| 0.5 | -13% |
| 0.7 | -25% |
| 0.785 | -32% |
| 1.0 | -37% |

#### 2. 温度变化

空气温度随马赫数增加而升高：

```
T0 / T = 1 + (γ-1)/2 × Ma²
```

其中 T0 为驻点温度，T 为静温。

C919 巡航点：

- T（12,200 m）= 216.5 K
- T0 = 216.5 × (1 + 0.2 × 0.785²) = 216.5 × 1.123 = 243.2 K（-30℃）

驻点温度高于静温约 27℃，影响发动机和结构设计。

#### 3. 压力系数修正

Prandtl-Glauert 法则修正亚音速可压缩流的压力系数：

```
Cp = Cp_0 / sqrt(1 - Ma²)
```

其中 Cp_0 为不可压缩压力系数。

C919 巡航点修正系数：

```
Cp = Cp_0 / sqrt(1 - 0.785²) = Cp_0 / sqrt(0.384) = Cp_0 / 0.620
```

即可压缩压力系数比不可压缩值大约 61%。

### 阻力发散马赫数

阻力发散马赫数（Drag Divergence Mach Number, Mdd）是阻力系数开始急剧上升的马赫数。

#### Mdd 的定义

通常定义为：

```
dCD/dMa = 0.10
```

即阻力系数随马赫数变化率达到 0.10 时的马赫数。

#### C919 的 Mdd

C919 采用第四代超临界翼型，Mdd 约 0.84-0.86。C919 巡航马赫数 0.785 比 Mdd 低 0.06-0.07，留有充足阻力裕度。

#### 翼型类型对 Mdd 的影响

| 翼型类型 | Mdd | 巡航 Ma | 裕度 |
| --- | --- | --- | --- |
| 常规翼型（NACA 6 系列） | 0.72-0.75 | 0.78 | -0.05（已超过） |
| 第一代超临界 | 0.78-0.80 | 0.78 | 0 |
| 第二代超临界 | 0.80-0.82 | 0.80 | +0.01 |
| 第四代超临界（C919） | 0.84-0.86 | 0.785 | +0.06 |

### 阻力发散的物理机理

阻力发散主要由以下因素引起：

#### 1. 波阻产生

当翼型表面局部马赫数超过 1.0 时，形成超声速区和激波。激波本身消耗能量，产生波阻。

#### 2. 激波诱导边界层分离

激波后的逆压梯度可能引起边界层分离，分离区产生附加阻力。

#### 3. 诱导阻力变化

接近 Mdd 时，压力分布变化导致升力分布改变，可能引起诱导阻力变化。

### C919 巡航阻力组成

C919 巡航阻力组成：

| 阻力类型 | 占比 | 说明 |
| --- | --- | --- |
| 寄生阻力（parasite） | 50-60% | 摩擦阻力+压差阻力 |
| 诱导阻力 | 30-40% | 升力诱导 |
| 波阻 | 0-10% | 巡航点波阻较小 |
| 干扰阻力 | 5-10% | 部件间干扰 |

C919 巡航点波阻较低（<5%），得益于超临界翼型推迟了激波形成。

### 马赫数对升力的影响

马赫数对升力系数 CL 的影响：

#### 1. 亚临界马赫数（Ma < Mdd）

升力系数随马赫数增加：

```
CL = CL_0 / sqrt(1 - Ma²)
```

#### 2. 超临界马赫数（Ma > Mdd）

升力系数达到峰值后开始下降，因为激波诱导分离。

#### 3. C919 巡航点

C919 在巡航点 Ma 0.785：

- 升力系数相比不可压缩值增大约 60%
- 激波尚未引起严重分离
- 升阻比保持较高水平

### 马赫数对发动机性能的影响

#### 1. 进气冲压

马赫数越高，进气冲压越强，发动机推力越大。但油耗也相应增加。

#### 2. 巡航推力需求

C919 巡航所需推力等于巡航阻力：

```
T_cruise = D_cruise = 0.5 × ρ × V² × S × CD
```

#### 3. 最佳巡航马赫数

最佳巡航马赫数是燃油里程最大时的马赫数：

```
SR (Specific Range) = V / (SFC × T)
```

C919 最佳巡航马赫数约 0.78-0.79，0.785 处于最佳区间。

### 马赫数限制

C919 马赫数限制：

| 限制 | 数值 | 说明 |
| --- | --- | --- |
| 巡航马赫数 | 0.785 | 设计值 |
| 最大使用马赫数（MMO） | 0.85 | 适航限制 |
| 设计俯冲马赫数（MD） | 约 0.90 | 极限试验 |
| 颤振边界 | >1.2 × MD | 安全裕度 |

C919 巡航马赫数 0.785 比 MMO（0.85）低 0.065，留有安全裕度。

### 高速失速

在接近 MMO 时，可能出现"高速失速"或"马赫失速"：

- 翼型上表面激波增强
- 激波诱导分离
- 升力下降、阻力增加
- 飞行员感受到抖振

C919 通过超临界翼型设计，将高速失速边界推迟到 Ma 0.85 以上，保证巡航安全。

### 马赫数对操纵性的影响

马赫数对操纵性的影响：

#### 1. 升降舵效率

升降舵效率随马赫数增加而变化，跨声速范围可能出现效率下降（Mach tuck）。

#### 2. Mach Tuck

Mach Tuck 是跨声速范围机头自动下沉的现象，原因是激波位置后移导致压力中心后移，产生低头力矩。

C919 通过以下措施补偿 Mach Tuck：

- FBW 自动配平
- 安定面安装角自动调节
- 升降舵偏转补偿

#### 3. 方向稳定性

跨声速范围方向稳定性可能下降，C919 通过垂尾设计保证稳定性。

| C919 | 0.785 | 0.85 | 第四代超临界 |
| A320neo | 0.78 | 0.82 | 第二代超临界 |
| B737 MAX 8 | 0.79 | 0.82 | AT winglet |
| A321XLR | 0.78 | 0.82 | 第二代超临界 |

C919 巡航马赫数 0.785 处于 A320neo（0.78）和 B737 MAX 8（0.79）之间，经济性较好。

### 巡航效率优化

C919 在 Ma 0.785 巡航点的优化措施：

1. **超临界翼型**：Mdd 提高至 0.84-0.86
2. **翼尖小翼**：降低诱导阻力 3-5%
3. **面积律**：机身截面优化，减小跨声速阻力
4. **发动机短舱**：与机翼气动一体化设计
5. **机身整流罩**：减小干扰阻力

综合优化使 C919 巡航升阻比达到 18-20，与 A320neo、B737 MAX 8 相当。
