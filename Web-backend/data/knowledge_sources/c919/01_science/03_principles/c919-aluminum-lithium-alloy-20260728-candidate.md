## 正文

### 铝锂合金概述

铝锂合金（Aluminum-Lithium Alloy）是通过在铝合金中添加锂元素形成的新型航空材料。C919 机体结构中铝锂合金占比 8.8%，是仅次于复合材料（12%）的次要先进材料。铝锂合金相比传统铝合金具有密度更低、刚度更高、疲劳性能更好的优点。

锂是世界上最轻的金属元素，密度仅 0.534 g/cm³。将锂加入铝合金中，每增加 1% 锂含量，合金密度降低约 3%，弹性模量提高约 5%。

### 铝锂合金的发展历程

铝锂合金发展经历了三个主要阶段：

#### 第一代（1950-1970 年代）

- 代表牌号：2020（美国）
- 锂含量：1.0-1.3%
- 应用：少量用于军用飞机
- 问题：断裂韧性差，未大规模应用

#### 第二代（1980-1990 年代）

- 代表牌号：2090、8090、2091
- 锂含量：2.0-2.5%
- 应用：少量用于军用飞机和验证机
- 问题：各向异性严重，焊接性差

#### 第三代（2000 年至今）

- 代表牌号：2195、2196、2099、2198、2050
- 锂含量：1.0-1.5%（降低锂含量改善韧性）
- 应用：广泛用于新一代客机
- 优点：综合性能好，焊接性改善

C919 选用的铝锂合金主要是第三代产品，包括 2099、2196 等牌号。

### 铝锂合金的物理机理

#### 1. 密度降低

锂原子比铝原子轻得多，且锂原子半径（0.152 nm）比铝原子（0.143 nm）略大。锂原子替代铝原子在晶格中的位置，使合金整体密度降低。

密度降低的定量关系：

| 锂含量 | 密度降低 | 弹性模量提高 |
| --- | --- | --- |
| 1.0% | -3% | +5% |
| 2.0% | -6% | +10% |
| 3.0% | -9% | +15% |

#### 2. 弹性模量提升

锂原子加入后，影响晶格结合力，使弹性模量提高。这是铝锂合金独有的优势——同时实现减重和增强。

#### 3. 强化机理

铝锂合金的强化主要来自 δ' 相（Al3Li）析出：

- δ' 相与基体共格
- 阻碍位错运动
- 提高强度
- 但也可能引起变形局部化，影响韧性

### 铝锂合金的制造工艺

C919 铝锂合金部件的制造工艺：

#### 1. 板材制备

- 熔炼：真空熔炼，控制锂含量
- 铸造：半连续铸造，控制成分均匀性
- 轧制：热轧+冷轧，控制板材厚度
- 时效处理：固溶+人工时效，控制析出相

#### 2. 挤压型材

- 桁条等长条件采用挤压工艺
- 控制挤压温度和速度
- 后续时效处理

#### 3. 锻件

- 接头等受力复杂件采用锻造
- 控制金属流线方向
- 减少各向异性

#### 4. 机加

- 整体壁板数控加工
- 减少紧固件数量
- 提高结构效率

### 铝锂合金的挑战

#### 1. 各向异性

铝锂合金各向异性比传统铝合金严重，需要：

- 优化轧制方向
- 控制微观组织
- 进行多方向性能测试

#### 2. 焊接性

第二代铝锂合金焊接性差，第三代有所改善但仍有挑战：

- 摩擦搅拌焊（FSW）是首选
- 减少紧固件数量
- 提高结构效率

#### 3. 成本

铝锂合金成本高于传统铝合金：

| 材料 | 相对成本 |
| --- | --- |
| 2024 铝合金 | 1.0（基准） |
| 7075 铝合金 | 1.2 |
| 2099 铝锂合金 | 3.0-4.0 |
| 2196 铝锂合金 | 3.5-4.5 |
| 碳纤维复合材料 | 5.0-8.0 |

虽然成本较高，但减重收益大于成本增加。

#### 4. 加工工艺

- 加工时易产生裂纹
- 刀具磨损快
- 需要专用工艺参数

3. 全尺寸试验（机身段疲劳试验）
4. 在 4,200 小时试飞中验证
