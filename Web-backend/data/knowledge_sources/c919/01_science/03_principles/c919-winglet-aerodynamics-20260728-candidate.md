## 正文

### 翼尖小翼概述

C919 翼尖安装有翼尖小翼（winglet），用于降低诱导阻力。C919 基本翼展 33.6 米，安装小翼后总翼展达到 35.8 米，每侧小翼贡献约 1.1 米。翼尖小翼通过抑制翼尖涡流，可降低诱导阻力 3-5%，是窄体客机标配的气动优化措施。

### 翼尖涡流的形成

要理解翼尖小翼的作用原理，需要先理解翼尖涡流（wingtip vortex）的形成机理。

#### 升力产生与压力差

机翼产生升力的根本原因是上下表面存在压力差：上表面（吸力面）压力低，下表面（压力面）压力高。在翼尖处，下表面的高压空气会绕过翼尖流向上表面的低压区，形成绕翼尖的螺旋状流动。

#### 翼尖涡流特征

翼尖涡流主要特征：

| 特征 | 数值 | 说明 |
| --- | --- | --- |
| 涡核直径 | 0.5-1.0 m | 飞机后部 |
| 涡核切向速度 | 50-100 m/s | 强烈旋转 |
| 涡流持续距离 | 10-20 km | 后方 |
| 涡流持续时间 | 2-5 分钟 | 衰减 |
| 诱导下洗角 | 2-5° | 翼尖后方 |

#### 诱导阻力

翼尖涡流导致机翼后方气流产生下洗（downwash），使有效迎角减小，升力向量向后倾斜，产生"诱导阻力"（induced drag）。

诱导阻力公式：

```
CDi = CL² / (π × AR × e)
```

其中：
- CDi：诱导阻力系数
- CL：升力系数
- AR：展弦比（Aspect Ratio）
- e：奥斯瓦尔德效率因子（典型 0.75-0.85）

诱导阻力与展弦比成反比，因此增加展弦比可以降低诱导阻力。

### 翼尖小翼工作原理

翼尖小翼通过物理阻挡翼尖涡流的形成，减小下洗角，从而降低诱导阻力。

#### 小翼的气动作用

1. **阻挡翼尖绕流**：小翼垂直（或近似垂直）于机翼平面，阻挡下表面气流绕过翼尖
2. **产生侧向力**：小翼本身在涡流场中产生侧向气动力，其水平分量提供前向推力
3. **减小有效下洗**：抑制涡流强度，减小下洗角
4. **改变升力分布**：使机翼展向升力分布更接近椭圆分布

#### 小翼上的力分解

小翼在涡流场中产生的气动力可分解为：

- **垂直分量**：贡献小量升力
- **水平前向分量**：等效为减小阻力
- **水平后向分量**：小翼自身的寄生阻力

总效果：当小翼几何设计合理时，水平前向分量大于后向分量，净效果为阻力降低。

### C919 翼尖小翼几何

C919 翼尖小翼采用上下分叉的"鲨鱼鳍"构型，主要几何参数：

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| 小翼高度 | 约 0.9 m | 每侧 |
| 总翼展增加 | 2.2 m | 两侧合计 |
| 后掠角 | 约 40° | 上段 |
| 上反角 | 约 35° | 上段向上 |
| 下反角 | 约 20° | 下段向下 |
| 翼型 | 超临界 | 与主翼一致 |
| 安装角 | 约 -2° | 略向内倾 |
| 材料 | 复合材料 | 减重 |

### 鲨鱼鳍构型的优势

C919 选用的上下分叉鲨鱼鳍构型相比单一上翘小翼的优势：

1. **更高效**：上下双向抑制涡流
2. **重量更轻**：在相同效果下高度更低
3. **机动性好**：上下分叉对侧风不敏感
4. **空间占用小**：机场兼容性好

### 翼尖小翼的代价

虽然翼尖小翼带来显著气动收益，但也有代价：

#### 重量代价

- 小翼本身重量约 50-80 kg
- 翼根弯矩增加，需加强翼根结构
- 总重量增加约 100-150 kg

#### 阻力代价

- 小翼自身的寄生阻力
- 小翼与主翼连接处的干扰阻力
- 在非巡航阶段（如低速）小翼效果减弱

#### 气动弹性

- 小翼增加翼尖惯量
- 可能引起颤振（flutter）问题
- 需要进行颤振分析和试验

#### 维护

- 小翼容易在地面操作中受损
- 维护检查项目增加

### 小翼设计优化

C919 翼尖小翼经过大量 CFD 优化和风洞试验，主要优化目标：

1. **最大化诱导阻力降低**：在巡航 Ma 0.785 时最大化诱导阻力降低
2. **最小化寄生阻力**：小翼自身的寄生阻力最小化
3. **保证颤振安全**：颤振速度至少超过 VD（设计俯冲速度）15%
4. **减小结构重量**：通过复合材料和优化设计减小重量
5. **机场兼容性**：总翼展 35.8 m 满足 ICAO Class C 机场要求
