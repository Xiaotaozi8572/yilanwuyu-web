# C919 适航审定流程与方法：TC/PC/AC、符合性方法 M0-M9

## 来源
- 主要来源：Wikipedia "Comac C919"（en.wikipedia.org/wiki/Comac_C919）
- 访问日期：2026-07-29

## 正文

### 适航审定的三证体系

C919 的适航审定遵循中国民航局（CAAC）CCAR-25 部《运输类飞机适航标准》，涉及三个核心证书：

| 证书 | 全称 | 含义 | 颁发对象 |
| --- | --- | --- | --- |
| TC | 型号合格证（Type Certificate） | 型号设计满足适航标准 | 型号设计 |
| PC | 生产许可证（Production Certificate） | 生产体系能稳定生产符合 TC 的产品 | 制造体系 |
| AC | 适航证（Airworthiness Certificate） | 单架机符合 TC 并可安全运行 | 单架飞机 |

C919 的关键取证节点：

| 日期 | 事件 |
| --- | --- |
| 2010-10-28 | 申请型号合格证（TC） |
| 2020-11-27 | 获得 CAAC 型号检查授权（TIA） |
| 2022-09-29 | 获得 CAAC 型号合格证（TC） |

TC 是型号设计的批准，证明 C919 的设计满足 CCAR-25 部要求。TC 颁发后，COMAC 的生产体系需通过 PC 审定，证明其能够稳定地生产出符合 TC 设计的飞机。每架交付的飞机需通过单机适航检查取得 AC，方可投入商业运营。

### 适航审定的阶段

C919 的 TC 审定过程分为以下阶段：

| 阶段 | 内容 | C919 时点 |
| --- | --- | --- |
| 申请 | 申请人向 CAAC 提交 TC 申请 | 2010-10-28 |
| 联合定义（JDP） | 申请人与审定方共同确定审定基础、符合性方法 | 2011-11-24 完成 |
| 符合性验证 | 申请人按符合性方法开展分析、试验、试飞 | 2011-2022 |
| 型号检查授权（TIA） | 审定方确认符合性验证基本完成，开始局方试飞 | 2020-11-27 |
| 局方试飞 | CAAC 试飞员进行验证试飞 | 2020-2022 |
| TC 颁发 | 审定方确认全部符合性，颁发 TC | 2022-09-29 |

### 符合性方法 M0-M9

适航审定中，申请人需通过"符合性方法"（Means of Compliance, MOC）向审定方证明设计满足每条适航条款。中国民航局规定的符合性方法编号为 MC0-MC9（与 EASA AMC 20-6 / FAA Order 8110.4 类似）：

| 方法 | 名称 | 说明 |
| --- | --- | --- |
| MC0 | 符合性声明 | 申请人声明设计符合条款 |
| MC1 | 说明性文件 | 通过文字、图纸说明符合性 |
| MC2 | 分析/计算 | 通过工程分析、有限元计算等证明 |
| MC3 | 安全分析 | 通过 FMEA、FTA 等证明满足安全目标 |
| MC4 | 试验室试验 | 地面试验台测试 |
| MC5 | 飞机地面试验 | 在飞机上进行的地面试验 |
| MC6 | 飞行试验 | 在飞行中进行的验证试验 |
| MC7 | 航空器检查 | 审定方检查航空器实物 |
| MC8 | 模拟器试验 | 工程模拟器验证 |
| MC9 | 设备鉴定 | 设备级环境、软件鉴定 |

不同条款适用不同的符合性方法组合。例如，结构强度条款通常用 MC2（分析）+ MC4（试验室试验）；飞行品质条款通常用 MC6（飞行试验）+ MC8（模拟器）；系统安全性条款通常用 MC3（安全分析）。

### C919 的符合性验证规模

C919 的取证试飞计划总飞行小时数为 4,200 小时，动用 6 架原型机：

| 原型机 | 首飞日期 | 主要试飞科目 |
| --- | --- | --- |
| 第一架 | 2017-05-05 | 气动性能、基本飞行品质 |
| 第二架 | 2017-12-17 | 发动机、燃油系统 |
| 第三架 | 2018-12-28 | 航电、飞控 |
| 第四架 | 2019-08-01 | 结构载荷 |
| 第五架 | 2019-10-24 | 自然结冰、高温高原 |
| 第六架 | 2019-12-27 | 功能与可靠性 |

4,200 小时试飞规模对照：

| 机型 | 取证试飞小时数 |
| --- | --- |
| 空客 A320 | 约 3,000 小时 |
| 波音 737 | 约 3,000 小时 |
| C919 | 4,200 小时 |
| ARJ21 | 约 5,000 小时 |

### 专用条件（Special Conditions）

C919 采用多项新技术（电传飞控、IMA 航电、复合材料、超临界机翼等），CCAR-25 部现行条款可能未覆盖这些技术的特定安全要求。对此，CAAC 制定专用条件（Special Conditions），补充条款要求。例如：

- 电传飞控系统的控制律、余度、软件等级可能触发专用条件
- 锂电池（主电瓶、APU 电瓶）的安全要求
- 高强度辐射场（HIRF）防护要求

专用条件是审定基础的组成部分，申请人需同样证明符合性。

### EASA 验证

C919 的国际适航认可面向 EASA。中欧 BASA 于 2020 年生效，为 EASA 型号认可（Type Certificate Validation）提供法律框架。EASA 验证的关键节点：

| 日期 | 事件 |
| --- | --- |
| 2020 年 | 中欧 BASA 生效 |
| 2026-01 | EASA 飞行员参与验证试飞 |
| 2028-2031（预计） | EASA 型号认可证 |

EASA 验证模式下，EASA 不重复全部审定工作，而是基于 CAAC 的审定结论，对特定条款进行独立验证（重点关注 EASA 与 CCAR-25 的差异条款）。EASA 飞行员于 2026 年 1 月参与验证试飞，是 EASA 认可的关键步骤。

### 取证后的持续适航

TC 颁发后，C919 进入持续适航阶段：

- 服务通告（SB）/适航指令（AD）：发现服役问题后，CAAC 颁发 AD 强制要求纠正，COMAC 发出 SB 提供纠正方案
- 设计更改：超出 TC 范围的设计更改需补充审定
- 服役经验反馈：航空公司反馈运行数据，用于改进设计与维修方案

截至 2026 年 5 月，C919 已交付 37 架，累计服役经验用于持续适航改进。
