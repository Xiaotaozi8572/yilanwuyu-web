# 知识库接入目录说明

## 定位
本目录是航空科普知识库的资料治理目录，承载原始资料、审核清单、入库批次、派生索引说明和评测种子。它是科普证据源的集中管理入口，**不是运行产物目录**。

## 五分区职责
| 分区 | 职责 |
|------|------|
| `01_science` | 科普证据源，是科普事实链的主来源，支撑 C919 科普问答的事实基础 |
| `02_teaching` | 教学组织素材，服务讲解表达与教学组织，不补充航空事实 |
| `03_multimodal` | 多模态素材，包括图像、结构图、3D 场景对象和图文交叉验证 |
| `04_terms_graph` | 术语图谱素材，用于别名解析、实体绑定、关系检索和概念一致性 |
| `90_reference_only` | 参考资料，默认不进入科普回答证据链，V1 不启用 |

## 目录红线
1. `00_inbox/` 不得作为入库来源，不能被引用为科普证据源
2. `90_reference_only/` 不得直接作为科普证据源
3. 未登记 `manifest.yaml` 的文件不得入库
4. `review_status` 不得通过移动文件表达，必须由 manifest 字段承载
5. `allowed_use` 不得与分区语义冲突
6. 运行产物不得作为权威资料来源
7. 骨架对象（j20/y20/z20）下不得创建分区目录
