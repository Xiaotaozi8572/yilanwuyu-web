# 歼-20 技术特征

## 来源
- 数据来源：Wikipedia "Chengdu J-20"（en.wikipedia.org/wiki/Chengdu_J-20）
- 访问日期：2026-08-06

## 正文

### 隐身设计

歼-20 的隐身设计涵盖气动外形、材料与细节处理多个层面。外形上采用菱形机头、平直边条与折线轮廓，将强反射方向集中到少数几个方向；弹舱和起落架舱采用锯齿形舱门边缘，降低雷达散射截面（RCS）；进气道采用 DSI 无隔道设计，既降低了前向 RCS，又减轻了结构重量。发动机喷口在 WS-10C 之后采用锯齿形隐身喷口。

### 鸭式布局与机动性

歼-20 采用鸭翼-大三角翼布局。设计方宣称其升力系数是普通鸭式三角翼的 1.2 倍、纯三角翼的 1.8 倍。鸭翼与主翼的耦合产生额外涡升力，改善了低速大迎角机动和起降性能，同时为超声速巡航提供了良好的升阻特性。

### 超声速巡航

歼-20 在换装 WS-10C 发动机后具备超声速巡航能力（不加力持续超声速飞行）。DSI 进气道的低阻力设计与高推重比发动机共同支撑了这一能力，使歼-20 能快速到达战区并保持高能量状态。

### 航电架构

歼-20 采用综合航电架构，核心是 Type 1475 AESA 雷达（约 100 kW、1,856 个 T/R 模块），配合机头下方 EOTS 光电瞄准、EORD-31 红外搜索跟踪（IRST）以及机身多处的被动光电窗口，构成 360° 全向感知网络。J-20A/J-20S 批次进一步强化了 360° 态势感知。

### 座舱与显示

歼-20 座舱配备大尺寸触摸液晶屏（约 610 mm × 230 mm，对角线约 650 mm）作为主显示，外加 3 块辅助显示屏、全息平视显示器和头盔显示器。驾驶舱采用侧杆操纵。
