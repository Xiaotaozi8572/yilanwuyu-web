# 歼-20 常见误解与纠偏

## 误解 1：歼-20 的外形尺寸很大
**常见说法**：歼-20 是重型机，一定比 F-22 大很多。

**实际情况**：歼-20 的确属于双发重型战斗机，但机长、翼展等外形尺寸官方未公布，公开流传的数值均为估算且差异较大。在没有官方数据的情况下，不应断言其尺寸与 F-22 的对比（F-22 机长约 18.9 米、翼展约 13.6 米为公开数据）。

## 误解 2：歼-20 的发动机全是国产的
**常见说法**：歼-20 从头到尾都用中国自己造的发动机。

**实际情况**：歼-20 早期原型机使用俄制 AL-31FM2 发动机，2015 年起逐步换装国产 WS-10 系列，2022 年起测试终极动力 WS-15。动力系统经历了"进口起步 → 国产过渡 → 国产定型"的演进过程。

## 误解 3：歼-20 像 F-35 一样是多用途战斗机
**常见说法**：歼-20 和 F-35 都是能对地对空的全能战机。

**实际情况**：歼-20 定位为制空战斗机（以夺取制空权为核心任务），F-35 更侧重多用途对地打击。两者虽同为第五代战斗机，设计哲学不同：歼-20 追求超巡和机动能量，F-35 追求传感器融合和网络化作战。

## 误解 4：歼-20 装配了机炮
**常见说法**：所有战斗机都有机炮。

**实际情况**：歼-20 为隐身和弹舱空间考虑，未安装内埋机炮。近距格斗依赖 PL-10 红外格斗导弹和机动性，这与 F-22 保留 M61 机炮的设计不同。

## 误解 5：歼-20 已经满状态服役
**常见说法**：歼-20 服役即巅峰，性能已完全定型。

**实际情况**：歼-20 走的是"边服役边完善"路线。2017 年服役时仍使用过渡发动机，2019 年换装 WS-10C 后才具备超声速巡航，终极动力 WS-15 仍在推进。这是典型的渐进式成熟过程。
