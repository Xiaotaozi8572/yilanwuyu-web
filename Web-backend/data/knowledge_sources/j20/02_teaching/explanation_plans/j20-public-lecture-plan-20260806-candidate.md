# 歼-20 科普讲解计划：面向普通公众

## 讲解目标
15-20 分钟让普通公众了解歼-20 是什么、为什么重要、有哪些技术特点。

## 讲解骨架

### 开场（2 分钟）
- 歼-20 是中国第一款第五代隐身战斗机，代号"威龙"
- 2017 年正式服役，2026 年年中已累计建造约 500 架
- 与美国的 F-22、F-35 同属世界隐身战斗机第一梯队

### 为什么隐身重要（4 分钟）
- 雷达靠"回声"探测飞机，隐身 = 让回声变弱
- 比喻：隐身机像"安静的幽灵"，敌人雷达难以发现
- 歼-20 通过外形、材料、内埋武器三招降低雷达回波

### 歼-20 的气动设计（4 分钟）
- 鸭式布局：机头前一对小翅膀（鸭翼）+ 大三角主翼
- 无隔道进气道（DSI）：进气口没有隔板，减重又隐身
- 双外倾垂尾、全动鸭翼

### 速度与动力（3 分钟）
- 最大速度 Mach 2.0（约 2 倍音速）
- 超声速巡航：不开加力也能飞超声速
- 发动机演进：AL-31 → WS-10C → WS-15（终极动力）

### 武器与航电（3 分钟）
- 弹舱全内埋：4-6 枚 PL-15 中远程导弹 + 2 枚 PL-10 格斗弹
- AESA 相控阵雷达 + 红外搜索跟踪（IRST）
- 360° 光电感知，可"静默"发现目标

### 结尾（2 分钟）
- 歼-20 代表中国航空工业的跨越式进步
- 互动问答
