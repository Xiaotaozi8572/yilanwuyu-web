# 密钥扫描使用说明（T03）

> 目的：在密钥再次进入 git 之前拦截。本脚本只使用 Python 标准库，无新增依赖。
> 文件：`scripts/check_secrets.py`

## 手动执行

```bash
# 默认扫描 git 暂存区（git add 之后、git commit 之前）
python scripts/check_secrets.py

# 扫描全仓文本文件（适合定期巡检）
python scripts/check_secrets.py --all
```

- 退出码 `0`：未检出疑似密钥。
- 退出码 `1`：检出命中，输出格式为 `文件:行号: [规则名] 行内容`。
- 退出码 `2`：当前目录不是 git 仓库，无法读取暂存区。

匹配规则（命中即报）：

| 规则 | 模式 | 说明 |
|---|---|---|
| sk-key | `sk-[A-Za-z0-9._-]{20,}` | DeepSeek / DashScope 等 OpenAI 兼容平台密钥 |
| nvapi-key | `nvapi-[A-Za-z0-9._-]{20,}` | NVIDIA NIM 密钥 |
| bearer-token | `Bearer [A-Za-z0-9._-]{20,}` | 内联 Authorization 头明文 token |

白名单（文档占位符，不报）：`sk-your-key-here`、`sk-xxx`、`sk-xxxx`、`sk-placeholder`、`sk-example`、`sk-<your-key>`。

## 安装为 pre-commit 本地钩子（不入库）

**本仓库已于 2026-08-15（T37）安装并验证通过**（阳性阻断 exit 1、阴性放行 exit 0）。新克隆环境按下述步骤重装。

当前已安装的钩子内容（`.git/hooks/pre-commit`，优先用主开发 venv `.venv`，回退 `.venv-review`，再回退系统 `python`）：

```bash
#!/bin/sh
# pre-commit 密钥扫描钩子（T37 安装，对应最终修复计划任务 0.2）
# 脚本：scripts/check_secrets.py（扫描 git 暂存区，命中疑似密钥即退出码 1 阻断提交）。
# Git for Windows 自带 sh.exe 执行本文件；钩子运行时工作目录为仓库根。
# 注意：.git/hooks 不入版本控制，新克隆需按本节重装。
PY=python
if [ -x ".venv/Scripts/python.exe" ]; then
  PY=".venv/Scripts/python.exe"
elif [ -x ".venv-review/Scripts/python.exe" ]; then
  PY=".venv-review/Scripts/python.exe"
fi
exec "$PY" scripts/check_secrets.py
```

新克隆安装步骤（项目根执行一次；`hooks` 目录不在 git 版本控制内）：

```bash
mkdir -p .git/hooks
cat > .git/hooks/pre-commit << 'EOF'
#!/bin/sh
PY=python
if [ -x ".venv/Scripts/python.exe" ]; then
  PY=".venv/Scripts/python.exe"
elif [ -x ".venv-review/Scripts/python.exe" ]; then
  PY=".venv-review/Scripts/python.exe"
fi
exec "$PY" scripts/check_secrets.py
EOF
chmod +x .git/hooks/pre-commit
```

Windows 下 git commit 会自动用自带的 `sh.exe` 执行该钩子；若需手工验证，可用
`& "C:\Program Files\Git\bin\sh.exe" .git/hooks/pre-commit`（PowerShell），退出码语义与下文一致。

## 验证示例

```bash
# 阳性：应退出码 1 并输出文件名
# 注意：伪密钥需为「sk- 前缀 + ≥20 位随机字符」；本文档不落字面值（否则本文件自身会触发门禁），
# 请自行生成，例如 PowerShell：'sk-' + -join((48..57+97..122) | Get-Random -Count 24 | % {[char]$_})
echo '<自行生成的 sk- 伪密钥>' > tmp/_secret_probe.txt
git add tmp/_secret_probe.txt
python scripts/check_secrets.py
echo $?   # 期望 1

# 清理
git reset tmp/_secret_probe.txt
rm tmp/_secret_probe.txt

# 阴性：当前工作区应退出码 0
python scripts/check_secrets.py
echo $?   # 期望 0
```
