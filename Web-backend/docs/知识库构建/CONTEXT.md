# 挑战杯项目目录治理

本上下文定义当前项目在目录结构设计中的核心语言。它只记录领域术语，不记录实现计划。

## Language

**全局目录蓝图**:
描述项目根目录下代码、配置、资料、产物、测试和文档之间的职责边界。它可以指导长期整理，但不等于一次性重排整个工程。
_Avoid_: 全量重构、整体搬家

**知识库接入目录**:
承载原始资料、审核清单、入库批次、派生索引和评测样例的资料治理目录，是本轮目录设计的实际落地重点。其根路径为 `data/knowledge_sources/`，根下维护 `00_inbox/`、`README.md`、`MANIFEST.yaml` 和 `SCHEMA.md`。
_Avoid_: 原始知识库、资料堆、RAG 文件夹

**导入暂存区**:
`data/knowledge_sources/00_inbox/`，用于临时保存刚收集、尚未完成对象归属和 manifest 登记的资料。导入暂存区不作为入库来源，也不能被引用为科普证据源。
_Avoid_: 已审核资料目录、长期资料库

**知识对象**:
知识库接入目录第一层的组织对象，表示可独立成库、独立评测和独立扩展的航空平台。本轮目录设计固定为 `c919`、`j20`、`y20`、`z20` 四个机器友好对象目录，中文展示名和别名由对象目录内的 `object.yaml` 承载。
_Avoid_: 部件文件夹、资料类型文件夹、使用场景文件夹

**科普证据源**:
面向普通用户讲解航空知识时允许进入回答链的已审核资料。它可以解释原理、结构、背景和应用价值，但不能变成维修、改装或运行操作指南。
_Avoid_: 培训资料、维修资料、操作手册

**资料清单**:
记录资料路径、`source_id`、标题、审核状态、权威等级和允许用途的结构化 manifest。审核状态由资料清单承载，不通过移动文件到 `reviewed`、`candidate` 或 `rejected` 目录表达；每个最小资料分区维护一个 `manifest.yaml`。
_Avoid_: 审核状态目录、只靠文件名记录来源

**资料文件名**:
资料文件名优先人读友好，建议包含短标题、日期和版本；机器唯一性由资料清单中的 `source_id` 承载，不强制把完整 `source_id` 塞进文件名。
_Avoid_: 完全依赖原始下载名、超长机器编码文件名

**资料用途**:
资料清单中的 `allowed_use` 字段，固定表达资料能否作为科普事实证据、教学组织素材、视觉辅助、术语图谱素材、参考资料或评测种子。
_Avoid_: 只用审核状态推断用途、自由文本用途

**审核状态**:
资料清单中的 `review_status` 字段，固定表达资料处于待审核、已审核、已拒绝、需修订、已替代或仅参考状态。`review_status=reviewed` 必须结合资料用途才可判断是否能进入科普事实链。
_Avoid_: 目录搬移式审核、审核即入库

**权威等级**:
资料清单中的 `authority_level` 字段，固定表达资料来源权威性。来源不明资料不能作为科普事实证据。
_Avoid_: 无来源资料、只凭文件标题判断权威性

**科普内容任务**:
`01_science` 内部按回答意图组织的资料类别，包括 `01_overview`、`02_structure_systems`、`03_principles`、`04_history_milestones`、`05_applications_value`、`06_comparison`。
_Avoid_: 按文件格式分类、无意图区分的大杂烩

**教学组织素材**:
`02_teaching` 内部维护的科普讲解组织材料，包括讲解计划、难度分层版本、类比素材、常见误解和问答种子。它服务表达与教学组织，不默认补充航空事实。
_Avoid_: Prompt 资产、维修培训教材、事实权威来源

**多模态素材**:
`03_multimodal` 内部维护的图像、结构图、视觉标注、场景对象和图文交叉验证说明。原始图像本身不等于科普证据源，必须通过标注、来源和交叉验证形成可用视觉证据。
_Avoid_: 无来源图片、未标注视觉事实、直接图像事实源

**术语图谱素材**:
`04_terms_graph` 内部维护的术语、别名、实体、关系和图谱种子材料。它用于别名解析、实体绑定、关系检索和科普问答中的概念一致性。
_Avoid_: 单一混合术语表、无对象归属的全局杂表

**参考资料**:
有价值但默认不直接进入科普回答证据链的材料，例如培训教材、维修手册、标准规程和故障案例。它在每个知识对象内以 `90_reference_only` 隔离，并按培训材料、维修手册、标准规程、案例研究和转化说明组织；经过人工转化或审核后，才能派生为科普证据源。
_Avoid_: 已审核证据、直接入库资料

**科普导师结构**:
每个知识对象内部统一采用的五个资料分区：`01_science`、`02_teaching`、`03_multimodal`、`04_terms_graph`、`90_reference_only`。
_Avoid_: 临时按文件类型堆放、每个对象自由命名

**工程模块目录**:
承载 `src/` 下已经形成的运行时代码边界，例如输入理解、知识检索、回答生成、自检、反馈、语音和评测。
_Avoid_: 业务资料目录、知识库目录

**运行产物目录**:
承载可重建的数据库、checkpoint、索引或报告等派生产物，不能作为人工维护的权威资料来源。
_Avoid_: 原始资料目录、知识源目录

**入库批次**:
记录一次知识库接入动作的过程证据，包括参与的 manifest、入库命令、配置摘要和验证报告。入库批次集中放在 `data/knowledge_sources/_ingestion_batches/`，不放入单个知识对象资料区。
_Avoid_: 对象资料目录、运行产物目录

**评测种子**:
资料侧维护的对象级或主题级问题种子，用于说明知识库应支撑哪些科普问答和证据引用。评测种子放在 `data/knowledge_sources/_eval_seeds/`，正式可运行评测仍由现有配置、脚本和测试系统执行。
_Avoid_: 正式测试入口、运行报告目录

**分区启用状态**:
知识对象内部各资料分区的启用开关，用于允许 `01_science` 等成熟分区先参与扫描或入库，而不要求对象下所有分区同时成熟。
_Avoid_: 目录存在即启用、一开全开

**目录红线**:
知识库接入目录必须遵守的禁止事项，例如导入暂存区不得入库、参考资料不得直接作为科普证据源、未登记资料清单的文件不得入库、运行产物不得作为权威资料。
_Avoid_: 注意事项、建议项

**目录设计文档**:
本轮工作的唯一交付物，用于记录知识库接入目录的目标结构、完整目录树、每层说明、manifest 示例、命名规范、边界规则和后续落地建议。它放在 `docs/知识库构建/` 下，不创建目录、不迁移资料、不修改入库脚本。
_Avoid_: 目录骨架、迁移脚本、实现计划
