## 执行说明（PPT 附录素材）

1. **统一环境**：Windows + 项目 `.venv`；知识库 `data/processed/knowledge.sqlite3`（3189 块，bge-m3 真实向量 is_mock=0）；生成类测试需 `DEEPSEEK_API_KEY`，检索类测试完全离线可跑。
2. **一键回归**：`pytest tests/ -q`（150+ 测试文件）+ `run_eval.py` 三套件（text_smoke / rag_refactor / voice_smoke），可先跑全量确认绿色基线。
3. **口径纪律**（答辩防追问）：召回指标一律用 90 题 gold 口径并标注分母；Recall@k 是保守下界；faithfulness 为 LLM-as-judge 单次调用结果——主动说明评测方法的边界比被动被质疑好。
4. **推荐答辩呈现顺序**：先总览表（七大维度一页）→ 挑 T1.1/T1.3（召回+消融互补）、T2.1（忠实度 4.94 零错误）、T5.3（打断时延）、T6.1（安全拒答）四张深入，其余作为附录取证。
