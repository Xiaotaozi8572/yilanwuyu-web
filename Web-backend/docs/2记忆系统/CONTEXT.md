# 记忆与个性化上下文

本上下文定义智能导师如何保存用户相关信息，并在不影响航空事实正确性的前提下形成个性化回答上下文。

## Language

**学习者标识**:
用于区分长期记忆归属的稳定匿名化标识，不包含可直接识别自然人的信息。
_Avoid_: 真实姓名、设备指纹、账号画像

**会话标识**:
用于界定一次连续交互范围的临时标识，只关联会话热状态，不单独赋予长期记忆资格。
_Avoid_: 学习者标识、长期用户编号

**匿名学习者**:
没有学习者标识的使用者，只能获得会话内连续性，不读取或写入跨会话长期记忆。
_Avoid_: 默认用户、共享用户、访客画像

**长期记忆授权**:
学习者对跨会话保存和使用个性化信息作出的显式选择；具有学习者标识不等于已经授权。
_Avoid_: 默认同意、登录即授权、一次授权永久有效

**记忆遗忘**:
学习者撤回指定或全部长期记忆的过程，要求后续读取立即停止，并按隐私策略完成可审计的删除或匿名化。
_Avoid_: 隐藏记忆、仅从界面移除、无审计硬删

**记忆控制中心**:
学习者查看长期记忆来源、状态和使用情况，并执行授权、确认、纠正、停用及遗忘的统一治理入口。
_Avoid_: 后台数据库管理器、开发调试页、用户画像看板

**长期记忆**:
经过来源追踪、隐私治理、冲突处理和时间有效性检查，能够跨会话保留的用户相关信息。长期记忆只能影响表达、指代和教学路径，不能作为航空事实依据。
_Avoid_: 用户知识库、事实记忆、完整聊天记录

**会话热状态**:
仅服务当前会话连续性的短期上下文，包括当前对象、对话进度和未完成指代；它不等同于可跨会话复用的长期记忆。
_Avoid_: 长期记忆、用户画像

**会话即时偏好**:
用户在当前会话明确表达、无需等待长期治理即可用于后续轮次的表达偏好。它在会话内生效不代表已获准跨会话保存。
_Avoid_: 长期偏好、已持久化画像

**待治理记忆事件**:
由交互产生、等待长期记忆边界验证和处理的最小化事件。它不是已接受的长期记忆，也不能被回答主链直接当作记忆读取。
_Avoid_: 长期记忆、记忆副本、聊天记录备份

**记忆候选**:
由确定性规则或记忆智能处理提出、尚未通过长期治理的结构化主张，必须携带来源、置信度和提议者信息。
_Avoid_: 长期记忆、模型事实、自动落库结果

**治理裁决**:
长期记忆边界依据授权、隐私、来源、冲突和时间规则，对记忆候选作出的接受、拒绝或待确认决定。
_Avoid_: 模型自评、生成质量判断、自动同意

**记忆晋级**:
记忆候选依据其类型对应的证据与治理条件转为可用长期记忆的过程；不同类型不得共用单一自动阈值。
_Avoid_: 自动保存、统一置信度门槛、模型直接写入

**交互事件**:
对一次用户交互或系统反馈的可追溯记录，是后续记忆派生的来源。其保留期限和可见范围由隐私等级决定。
_Avoid_: 长期记忆、完整永久聊天记录

**情景记忆**:
经过治理后保留的具体学习经历，例如一次问答、测验或纠偏结果，并能追溯到交互事件。
_Avoid_: 会话热状态、事实知识、原始事件

**语义学习者模型**:
从多次交互中形成的结构化学习者状态，包括偏好、目标、概念掌握度、薄弱点和误解。
_Avoid_: 用户知识库、航空事实画像、完整聊天摘要

**时间关系图**:
表达记忆实体之间关系及其有效区间、冲突、替代和来源链的受治理结构。
_Avoid_: 航空知识图谱、静态用户画像、无来源关系图

**有效时间**:
某条记忆所描述的学习者状态在现实交互中成立的时间区间。
_Avoid_: 数据写入时间、最后更新时间

**记录时间**:
系统接收、修订或撤销某个记忆版本的时间，用于审计系统当时掌握了什么。
_Avoid_: 有效时间、用户行为发生时间

**记忆版本**:
同一记忆主张在一次治理变化后的不可覆盖状态；新版本通过替代关系连接旧版本。
_Avoid_: 原地更新、无历史覆盖、重复记忆

**过时记忆**:
因长期缺少新证据、超过复核周期或上下文已变化而不能默认使用的记忆版本；它可以等待确认、被替代或按期限清理。
_Avoid_: 已删除记忆、当前有效记忆、永久用户标签

**反思记忆**:
从多个可追溯经历中归纳的高层学习模式，必须携带派生依据、置信度和可撤销状态。
_Avoid_: 模型事实、最终质量裁决、自我臆测

**记忆演化**:
记忆随新事件发生整合、关联、反思、降级、过期或替代的受治理过程，每次变化必须保持来源闭包。
_Avoid_: 自动改写历史、反思自循环、无来源自我更新

**策略与授权记忆**:
约束个性化信息如何保存和使用的授权、隐私及教学边界，其优先级高于其他记忆。
_Avoid_: 普通偏好、系统 Prompt、航空安全规则替代品

**优化候选记忆**:
从运行经验中形成、等待离线评测和人工审核的 Prompt 或教学策略候选，不能直接进入正式回答。
_Avoid_: 在线 Prompt、自动生效策略、学习者画像

**记忆上下文**:
从当前请求可用且获准使用的记忆中构造的受治理投影，是回答主链唯一可消费的个性化上下文。
_Avoid_: 记忆数据库、原始记忆、聊天记录

**记忆上下文预算**:
当前轮允许注入的各类记忆条目和 token 上限，用于保持相关性并防止某一记忆类型挤占回答上下文。
_Avoid_: 数据库存储上限、模型上下文总长度、固定 top-k

**空记忆上下文**:
不包含可用长期记忆的合法记忆上下文。它表示当前回答不使用跨会话个性化，但不影响基于已审核证据完成事实回答。
_Avoid_: 记忆故障、空回答、无证据回答

**记忆应用状态**:
当前轮长期记忆的使用结果，固定为已应用、合法为空或技术降级；状态用于审计和监控，不改变航空事实回答契约。
_Avoid_: 回答质量等级、RAG 状态、记忆命中数

**无长期记忆回答**:
在空记忆上下文下生成的有证据回答；其事实正确性和安全门控保持不变，只缺少跨会话个性化。
_Avoid_: 降质回答、离线回答、无记忆模式

**长期记忆唯一归属**:
长期记忆只有一个权威写入与治理边界，其他上下文只能通过稳定契约读取记忆上下文或提交待治理事件。
_Avoid_: 双写、共享数据库、双重真相源

**权威记忆存储**:
长期记忆状态、来源和治理结果的唯一可信记录；缓存、事件流和图投影均不能替代它。
_Avoid_: Redis 缓存、事件队列、图投影

**记忆图投影**:
从权威记忆存储派生、可重新构建的时间关系视图，用于关系检索和可视化，但不独立决定长期记忆状态。
_Avoid_: 权威记忆存储、航空知识图谱、第二真相源
