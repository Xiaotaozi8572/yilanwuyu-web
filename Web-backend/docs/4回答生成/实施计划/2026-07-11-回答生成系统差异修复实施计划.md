# 回答生成系统差异修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Before editing code, use `using-git-worktrees`; for every failure use `systematic-debugging`; before each completion claim use `verification-before-completion`.

**Goal:** 在保持 `TextQueryRequest`、`TextQueryResponse` 和 CLI 对外兼容的前提下，将回答生成重构为强类型、证据优先、模型可接线、可语义核验、可安全回退并可彻底清理旧路径的完整流水线。

**Architecture:** 保留 AppPipeline/CLI 作为稳定边缘，在内部依次建立 canonical answer contracts、配置化路由、完整 EvidenceSketch、AnswerPlan/AnswerOutline、ModelRuntime、AnswerGenerationPipeline、SelfCheckPipeline 和 typed answer loop。迁移期间旧 facade 只作为临时桥接；所有调用方切换并通过兼容测试后，在 G7 工作包一次性删除旧实现和伪配置。

**Tech Stack:** Python 3.11+、标准库 `dataclasses`/`enum`/`typing.Protocol`/`json`/`re`、现有 SQLite memory repository、现有 Prompt asset repository、pytest、现有 MockModelClient 与 DeepSeek adapter；不新增大型框架或生产外部服务依赖。

## 需要调用的 skill

按顺序使用：

1. `using-git-worktrees`：创建隔离分支/worktree，保护用户现有改动。
2. `subagent-driven-development`：按 Task 1→18 小步执行、逐任务复核。
3. `systematic-debugging`：任何红测、回归或异常先复现并定位根因。
4. `requesting-code-review`：每个 G 工作包完成后审查契约、边界与遗漏。
5. `verification-before-completion`：每个 Task/G 和最终交付前运行对应验证门并记录证据。

## Global Constraints

- 本计划的规格来源是 `docs/4回答生成/设计文档/2026-07-11-回答生成系统差异修复任务.md`。
- 正式执行必须在 `codex/answer-generation-refactor` 隔离 worktree/分支中进行，不得覆盖共享工作区里的用户变更。
- `TextQueryRequest` 字段、`TextQueryResponse.to_dict()` 顶层键、CLI 参数、CLI JSON 和退出码保持兼容。
- 现有 answer JSON 字段和六类 answer type 字符串值不得删除或改义；新增字段只能向后兼容地附加。
- 现有 trace 字段不得删除或改义；新增 trace 不得记录完整 Prompt、密钥、原始私人记忆或原始音频。
- 航空事实只能来自 reviewed 且 `usable_as_core_evidence=true` 的 `EvidencePackage` 条目。
- 记忆、Prompt、用户反馈和模型常识不得作为航空事实来源。
- 参数和安全 claim 必须通过确定性硬门控；模型 judge 不能覆盖硬失败。
- P4 只产生候选绑定；P5 独占 `supported/partially_supported/unsupported/contradicted` 最终判断。
- DisplayBlock 和 SpokenAnswer 只能投影已验证 AnswerEnvelope，不得新增事实。
- 不连接真实密钥、真实生产数据库或真实外部服务；真实 Provider 验收需要单独授权。
- 不引入 LangGraph、LangChain、Guardrails、向量数据库或其他大型依赖；现有显式状态机和 Protocol 足以完成本专项。
- 每个 Task 必须红测先行、目标测试通过、前序回归通过、独立提交；不得带失败进入下一 Task。
- 同一失败连续三次且无法定位、文档边界冲突、需要大型依赖或会破坏外部契约时立即停止并更新 `STATUS.md`。

### 1.1 固定命令

除非命令明确要求 CLI subprocess，所有测试使用项目既有虚拟环境：

```powershell
$PY = "D:\APP\Python 3.13\Internet\.venv\Scripts\python.exe"
$env:PYTHONDONTWRITEBYTECODE = "1"

function Invoke-NativeChecked {
    param([string]$Label, [scriptblock]$Command)
    & $Command
    $code = $LASTEXITCODE
    if ($code -ne 0) {
        throw "$Label failed with exit code $code"
    }
}

function Assert-NoRgMatch {
    param([string]$Label, [scriptblock]$Search)
    & $Search
    $code = $LASTEXITCODE
    if ($code -eq 0) {
        throw "$Label found forbidden matches"
    }
    if ($code -ne 1) {
        throw "$Label rg failed with exit code $code"
    }
}
```

所有多命令 gate 都在同一个 PowerShell 进程内执行；每条要求 exit 0 的 native command 必须用 `Invoke-NativeChecked`，期望 `rg` 零命中的命令必须用 `Assert-NoRgMatch`。禁止依赖“代码块最后一条命令”的退出码，否则前序失败会被后续成功掩盖。单条演示命令可直接运行，但仍须检查其退出码后再勾选 Step。

### 1.4 提交、失败与回滚规则

- 每个 Task 先红测取证，再实现、跑目标测试、前序回归、更新 STATUS，最后提交；工作区存在失败时不得提交或进入下一 Task。
- 同一失败连续三次无法定位时，按项目停止条件记录三次命令/错误/已排除原因并暂停。
- 提交前需要撤销本 Task 时只用反向 `apply_patch`；提交后按 STATUS 记录的实际 SHA 逆序 `git revert`，禁止 `git reset --hard`、`git checkout --` 覆盖文件或带回用户无关变更。
- Prompt 回滚通过 asset governance 的 parent version/status，不删除历史版本或 evaluation snapshot。
- 每次 stage 前执行 `git status --short`，只加入当前 Task Files；发现用户原有改动立即排除，不使用宽泛 `git add -A`。

~~~python
class RecordingRetrievalController(RetrievalController):

class RetrieveThenStop:

        self.calls += 1

        return CheckReport(action_decision=action)
~~~

```python
class BaseContract:

    def __post_init__(self) -> None:
        self.validate()

    def validate(self) -> None:
        for name in self.required_fields:
            value = getattr(self, name, None)
            if value is None or value == "" or value == [] or value == {}:
                raise ContractValidationError(name, "required field is empty")

    def to_dict(self) -> dict[str, Any]:
        return asdict(self)

    @classmethod
    def from_dict(cls, payload: dict[str, Any]) -> "BaseContract":
        allowed = {item.name for item in fields(cls)}
        return cls(**{key: value for key, value in payload.items() if key in allowed})
```

```python
def parse_claim(item: Any, index: int) -> ClaimCandidate:
    path = f"claim_candidates[{index}]"
    required = {
        "claim_id", "text", "claim_type", "risk_level",
        "required_evidence_type", "minimum_authority", "source_origin", "evidence_ids",
        "numeric_assertions",
    }
    if not isinstance(item, dict):
        raise StructuredOutputError("INVALID_CLAIM", path)
    missing = sorted(required - set(item))
    if missing:
        raise StructuredOutputError(
            "MISSING_CLAIM_FIELD", f"{path}.{missing[0]}"
        )
    if not isinstance(item["evidence_ids"], list):
        raise StructuredOutputError("INVALID_EVIDENCE_IDS", f"{path}.evidence_ids")
    if not isinstance(item["numeric_assertions"], list):
        raise StructuredOutputError(
            "INVALID_NUMERIC_ASSERTIONS", f"{path}.numeric_assertions"
        )
    try:
        assertions = tuple(
            NumericAssertion(
                parameter_name=str(value["parameter_name"]),
                value=str(value["value"]),
                unit=str(value["unit"]) if value.get("unit") else None,
            )
            for value in item["numeric_assertions"]
        )
    except (KeyError, TypeError, ValueError) as exc:
        raise StructuredOutputError(
            "INVALID_NUMERIC_ASSERTION", f"{path}.numeric_assertions"
        ) from exc
    try:
        claim_type = ClaimType(str(item["claim_type"]))
    except ValueError as exc:
        raise StructuredOutputError("INVALID_CLAIM_TYPE", f"{path}.claim_type") from exc
    try:
        risk_level = RiskLevel(str(item["risk_level"]))
    except ValueError as exc:
        raise StructuredOutputError("INVALID_RISK_LEVEL", f"{path}.risk_level") from exc
    try:
        evidence_type = EvidenceType(str(item["required_evidence_type"]))
    except ValueError as exc:
        raise StructuredOutputError(
            "INVALID_EVIDENCE_TYPE", f"{path}.required_evidence_type"
        ) from exc
    raw_minimum_authority = item["minimum_authority"]
    try:
        minimum_authority = (
            None
            if raw_minimum_authority is None
            else AuthorityLevel(str(raw_minimum_authority))
        )
    except ValueError as exc:
        raise StructuredOutputError(
            "INVALID_MINIMUM_AUTHORITY", f"{path}.minimum_authority"
        ) from exc
    if claim_type is ClaimType.PARAMETER_FACT and minimum_authority is None:
        raise StructuredOutputError(
            "PARAMETER_MINIMUM_AUTHORITY_REQUIRED", f"{path}.minimum_authority"
        )
    try:
        source_origin = SourceOrigin(str(item["source_origin"]))
    except ValueError as exc:
        raise StructuredOutputError(
            "INVALID_SOURCE_ORIGIN", f"{path}.source_origin"
        ) from exc
    return ClaimCandidate(
        claim_id=str(item["claim_id"]),
        text=str(item["text"]),
        claim_type=claim_type,
        risk_level=risk_level,
        required_evidence_type=evidence_type,
        minimum_authority=minimum_authority,
        asserted_evidence_ids=tuple(str(value) for value in item["evidence_ids"]),
        source_origin=source_origin,
        subject_refs=tuple(item.get("subject_refs", ())),
        qualifiers=tuple(item.get("qualifiers", ())),
        numeric_assertions=assertions,
    )


class AnswerDraftParser:
    def parse(self, payload: str | dict[str, Any]) -> ParsedAnswerDraft:
        parsed = StructuredOutputValidator(
            StructuredOutputSchema(
                name="answer_draft",
                required_fields=(
                    "answer_type", "response_mode", "short_answer", "main_answer",
                    "claim_candidates", "visual_refs", "uncertainty_notes",
                    "safety_notes", "follow_up_questions"
                ),
            )
        ).parse_and_validate(payload)
        try:
            answer_type = AnswerType(str(parsed["answer_type"]))
        except ValueError as exc:
            raise StructuredOutputError("INVALID_ANSWER_TYPE", "answer_type") from exc
        try:
            response_mode = ResponseMode(str(parsed["response_mode"]))
        except ValueError as exc:
            raise StructuredOutputError("INVALID_RESPONSE_MODE", "response_mode") from exc
        valid_mode = {
            ResponseMode.CLARIFICATION_ONLY: answer_type is AnswerType.CLARIFICATION,
            ResponseMode.PURE_SAFETY_REFUSAL: answer_type is AnswerType.OPERATION_SAFETY,
            ResponseMode.GROUNDED_ANSWER: answer_type is not AnswerType.CLARIFICATION,
        }[response_mode]
        if not valid_mode:
            raise StructuredOutputError("ANSWER_TYPE_RESPONSE_MODE_MISMATCH")
        raw_claims = parsed["claim_candidates"]
        if not isinstance(raw_claims, list):
            raise StructuredOutputError("INVALID_CLAIM_LIST")
        if not isinstance(parsed["visual_refs"], list):
            raise StructuredOutputError("INVALID_VISUAL_REFS", "visual_refs")
        empty_claims_allowed = response_mode in {
            ResponseMode.CLARIFICATION_ONLY,
            ResponseMode.PURE_SAFETY_REFUSAL,
        }
        if not empty_claims_allowed and not raw_claims:
            raise StructuredOutputError("CLAIMS_REQUIRED")
        claims = tuple(parse_claim(item, index) for index, item in enumerate(raw_claims))
        return ParsedAnswerDraft(
            answer_type=answer_type,
            response_mode=response_mode,
            short_answer=str(parsed["short_answer"]),
            main_answer=str(parsed["main_answer"]),
            claim_candidates=claims,
            visual_refs=tuple(
                parse_visual_ref(item, index)
                for index, item in enumerate(parsed["visual_refs"])
            ),
            uncertainty_notes=tuple(parsed.get("uncertainty_notes", ())),
            safety_notes=tuple(parsed.get("safety_notes", ())),
            follow_up_questions=tuple(parsed.get("follow_up_questions", ())),
        )
```

```python
from core.answer_contracts import (
    AnswerType,
    AuthorityLevel,
```

```python
from core.runtime_settings import RuntimeSettings


@dataclass(frozen=True)
class AnswerRoutePolicy:
    answer_type: AnswerType
    priority: int
    template_id: str
    required_evidence_types: tuple[EvidenceType, ...]
    minimum_authority: AuthorityLevel | None
    allow_definitive_without_evidence: bool
    missing_evidence_action: str
    require_visual_context: bool = False
    safety_mode: bool = False


class RoutePolicyRegistry:
    def __init__(self, version: str, policies: tuple[AnswerRoutePolicy, ...]) -> None:
        self.version = version
        self._by_type = {policy.answer_type: policy for policy in policies}
        if set(self._by_type) != set(AnswerType):
            raise ConfigError("route policy must define all six answer types")
        safety_priority = self._by_type[AnswerType.OPERATION_SAFETY].priority
        if any(
            policy.priority >= safety_priority
            for answer_type, policy in self._by_type.items()
            if answer_type not in {AnswerType.CLARIFICATION, AnswerType.OPERATION_SAFETY}
        ):
            raise ConfigError("operation_safety must outrank factual routes")

    @classmethod
    def from_settings(
        cls, runtime: RuntimeSettings, prompts_config: Mapping[str, Any]
    ) -> "RoutePolicyRegistry": ...

    @classmethod
    def for_test(cls) -> "RoutePolicyRegistry": ...

    def get(self, answer_type: AnswerType) -> AnswerRoutePolicy:
        return self._by_type[answer_type]

    def replace_policy(
        self, answer_type: AnswerType, **changes: Any
    ) -> "RoutePolicyRegistry":
        policies = tuple(
            replace(policy, **changes)
            if policy.answer_type is answer_type else policy
            for policy in self._by_type.values()
        )
        return RoutePolicyRegistry(self.version, policies)
```

```python
from core.answer_contracts import AnswerType
from core.contracts import EvidencePackage, SceneState
from generation.policies import AnswerRoutePolicy, RoutePolicyRegistry
from input.query_object import QueryObject


@dataclass(frozen=True)
class AnswerRoute:
    answer_type: AnswerType
    policy: AnswerRoutePolicy
    allow_definitive_answer: bool
    reason_codes: tuple[str, ...]
    policy_version: str


class AnswerTypeRouter:
    def __init__(self, policies: RoutePolicyRegistry) -> None:
        self._policies = policies

    def route(
        self,
        query: QueryObject,
        evidence: EvidencePackage,
        scene: SceneState | None,
    ) -> AnswerRoute:
        signals = query.intent_signals
        ambiguous_scene = bool(
            scene
            and not scene.selected_object_id
            and len(scene.candidate_object_ids) > 1
            and (
                signals.references_scene_pronoun
                or query.intent_type == AnswerType.COMPONENT_SCENE.value
            )
        )
        if query.needs_clarification or ambiguous_scene:
            policy = self._policies.get(AnswerType.CLARIFICATION)
            return AnswerRoute(
                AnswerType.CLARIFICATION,
                policy,
                False,
                ("scene_or_reference_ambiguous",),
                self._policies.version,
            )

        candidates: list[tuple[AnswerType, str]] = []
        if signals.is_safety_sensitive:
            candidates.append((AnswerType.OPERATION_SAFETY, "safety_signal"))
        if signals.is_comparison:
            candidates.append((AnswerType.COMPARISON, "comparison_signal"))
        if signals.is_parameter_fact:
            candidates.append((AnswerType.PARAMETER_FACT, "parameter_signal"))
        if signals.references_component or query.scene_object_id or (scene and scene.component_id):
            candidates.append((AnswerType.COMPONENT_SCENE, "component_or_scene_signal"))
        if candidates:
            selected, selected_reason = max(
                candidates,
                key=lambda item: self._policies.get(item[0]).priority,
            )
            reasons = (selected_reason,)
        else:
            selected = AnswerType.CONCEPT_EXPLANATION
            reasons = ("default_concept_route",)

        policy = self._policies.get(selected)
        allow = policy.allow_definitive_without_evidence
        if not allow and selected not in {AnswerType.CLARIFICATION, AnswerType.OPERATION_SAFETY}:
            allow = evidence.gate_status == "confident" and not evidence.missing_evidence
        return AnswerRoute(
            selected, policy, allow, reasons, self._policies.version
        )
```

```python
    conflict_id: str

    right_value: str

    qualifiers: tuple[str, ...]
    reason: str

class EvidenceSketch:
    route: AnswerRoute
    facts: tuple[EvidenceFact, ...]
    relations: tuple[EvidenceRelation, ...]
    visual_clues: tuple[VisualClue, ...]
    missing_points: tuple[str, ...]
    conflicts: tuple[EvidenceConflict, ...]
    generation_boundary: tuple[str, ...]
    gate_status: str


@dataclass(frozen=True)
class EvidenceSketchLimits:
    max_facts: int
    max_chars_per_fact: int


def stable_conflict_id(value: dict[str, Any]) -> str:
    canonical = json.dumps(
        {
            "subject": value["subject"],
            "predicate": value["predicate"],
            "values": sorted((str(value["left_value"]), str(value["right_value"]))),
            "evidence_ids": sorted(str(item) for item in value["evidence_ids"]),
            "qualifiers": sorted(str(item) for item in value.get("qualifiers", ())),
        },
        ensure_ascii=False,
        sort_keys=True,
        separators=(",", ":"),
    )
    return "conflict_" + hashlib.sha256(canonical.encode("utf-8")).hexdigest()[:16]
```

```python
class EvidenceSketchBuilder:
    def __init__(self, limits: EvidenceSketchLimits) -> None:
        self._limits = limits

    def _stable_rank_key(self, item: EvidenceItem) -> tuple[int, float, str]:
        raw_score = item.metadata.get("retrieval_score", 0.0)
        try:
            retrieval_score = float(raw_score)
        except (TypeError, ValueError):
            retrieval_score = 0.0
        return (
            -AUTHORITY_ORDER[AuthorityLevel(item.authority_level)],
            -retrieval_score,
            item.evidence_id,
        )

    def build(self, package: EvidencePackage, route: AnswerRoute) -> EvidenceSketch:
        valid_evidence_types = {item.value for item in EvidenceType}
        invalid_type_items = tuple(
            item for item in package.evidence_items
            if item.review_status == "reviewed"
            and item.usable_as_core_evidence
            and item.metadata.get("evidence_type") not in valid_evidence_types
        )
        usable = tuple(sorted(
            (
                item for item in package.evidence_items
                if item.review_status == "reviewed" and item.usable_as_core_evidence
                and item.metadata.get("evidence_type") in valid_evidence_types
            ),
            key=self._stable_rank_key,
        ))[: self._limits.max_facts]
        facts = tuple(
            EvidenceFact(
                evidence_id=item.evidence_id,
                source_id=item.source_id,
                text=self._compress_preserving_assertions(item.content),
                evidence_type=EvidenceType(str(item.metadata["evidence_type"])),
                authority_level=AuthorityLevel(item.authority_level),
                review_status=item.review_status,
                applicability_scope=tuple(item.metadata.get("applicability_scope", ())),
                subject_refs=tuple(filter(None, (
                    item.metadata.get("aircraft"),
                    item.metadata.get("component"),
                    item.metadata.get("concept"),
                ))),
                qualifiers=tuple(item.metadata.get("qualifiers", ())),
                metadata=dict(item.metadata),
            )
            for item in usable
        )
        relations = tuple(
            EvidenceRelation(
                item.evidence_id,
                str(item.metadata["relation"]["subject"]),
                str(item.metadata["relation"]["predicate"]),
                str(item.metadata["relation"]["object"]),
            )
            for item in usable if isinstance(item.metadata.get("relation"), dict)
        )
        visuals = tuple(
            VisualClue(
                item.evidence_id,
                item.source_id,
                item.metadata.get("page_id"),
                dict(item.metadata["bbox"]),
                str(item.metadata["layout_trace"]["trace_id"]),
                str(item.metadata["text_cross_check"]),
            )
            for item in usable
            if item.metadata.get("visual")
            and item.metadata.get("bbox")
            and item.metadata.get("layout_trace")
            and item.metadata.get("text_cross_check")
        )
        conflicts = tuple(
            EvidenceConflict(
                conflict_id=stable_conflict_id(value),
                subject=str(value["subject"]),
                predicate=str(value["predicate"]),
                left_value=str(value["left_value"]),
                right_value=str(value["right_value"]),
                evidence_ids=tuple(value["evidence_ids"]),
                qualifiers=tuple(value.get("qualifiers", ())),
                reason="evidence_values_conflict",
            )
            for event in package.audit_trace
            for value in event.get("conflicts", ())
        )
        return EvidenceSketch(
            route=route,
            facts=facts,
            relations=relations,
            visual_clues=visuals,
            missing_points=(
                tuple(package.missing_evidence)
                + tuple(
                    f"invalid_evidence_type:{item.evidence_id}"
                    for item in invalid_type_items
                )
            ),
            conflicts=conflicts,
            generation_boundary=tuple(package.generation_boundary),
            gate_status=package.gate_status,
        )
```

```python
from dataclasses import dataclass

from core.answer_contracts import (
    AUTHORITY_ORDER,
    AnswerType,
    AuthorityLevel,
    EvidenceType,
    authority_at_least,
)
from core.base_contracts import new_id
from core.contracts import MemoryContext, SceneState
from core.runtime_settings import GenerationSettings, SelfCheckSettings
from generation.evidence_sketch import EvidenceSketch
from input.query_object import QueryObject


@dataclass(frozen=True)
class PlannedClaim:
    claim_key: str
    objective: str
    required_evidence_type: EvidenceType
    minimum_authority: AuthorityLevel | None
    candidate_evidence_ids: tuple[str, ...]
    subject_refs: tuple[str, ...]
    comparison_dimension: str | None = None


@dataclass(frozen=True)
class PlanningContext:
    query_object: QueryObject
    scene_state: SceneState | None
    memory_context: MemoryContext
    generation_settings: GenerationSettings
    self_check_settings: SelfCheckSettings


@dataclass(frozen=True)
class AnswerPlan:
    plan_id: str
    answer_type: AnswerType
    objective: str
    required_points: tuple[str, ...]
    forbidden_content: tuple[str, ...]
    evidence_order: tuple[str, ...]
    target_claims: tuple[PlannedClaim, ...]
    require_visual_guidance: bool
    require_safety_template: bool
    missing_evidence_action: str
    allow_definitive_answer: bool
    expression_hints: tuple[str, ...]
    missing_points: tuple[str, ...]


class GenerationPlanner:
    def create_plan(
        self, context: PlanningContext, sketch: EvidenceSketch
    ) -> AnswerPlan:
        route = sketch.route
        forbidden = [*sketch.generation_boundary]
        if route.answer_type == AnswerType.PARAMETER_FACT:
            forbidden.append("不得从型号编号推断参数")
        if sketch.conflicts:
            forbidden.append("不得裁决冲突来源")
        claim_type = (
            EvidenceType.STRUCTURED_PARAMETER
            if route.answer_type == AnswerType.PARAMETER_FACT
            else EvidenceType.REVIEWED_TEXT
        )
        authority = route.policy.minimum_authority
        if route.answer_type == AnswerType.PARAMETER_FACT:
            candidates = tuple(filter(None, (
                authority,
                context.self_check_settings.high_risk_minimum_authority,
            )))
            authority = max(candidates, key=AUTHORITY_ORDER.__getitem__)
        eligible_facts = tuple(
            fact for fact in sketch.facts
            if fact.evidence_type is claim_type
            and authority_at_least(fact.authority_level, authority)
        )
        evidence_ids = tuple(fact.evidence_id for fact in eligible_facts)
        target_claims = self._build_target_claims(
            context, sketch, claim_type, authority, eligible_facts
        )
        missing_points = self._missing_points(
            context, sketch, eligible_facts, target_claims
        )
        return AnswerPlan(
            plan_id=new_id("answer_plan"),
            answer_type=route.answer_type,
            objective=f"生成{route.answer_type.value}回答",
            required_points=("direct_conclusion", "grounded_explanation"),
            forbidden_content=tuple(dict.fromkeys(forbidden)),
            evidence_order=evidence_ids,
            target_claims=target_claims,
            require_visual_guidance=route.policy.require_visual_context,
            require_safety_template=route.policy.safety_mode,
            missing_evidence_action=(
                "uncertainty" if sketch.conflicts else route.policy.missing_evidence_action
            ),
            allow_definitive_answer=(
                route.allow_definitive_answer
                and bool(target_claims)
                and not missing_points
                and not sketch.conflicts
                and route.answer_type is not AnswerType.CLARIFICATION
            ),
            expression_hints=self._expression_hints(context.memory_context),
            missing_points=missing_points,
        )
```

```python
    evidence_ids: tuple[str, ...]
    subject_refs: tuple[str, ...]
    max_chars: int
    display_intent: str | None = None


@dataclass(frozen=True)
class AnswerOutline:
    outline_id: str
    sections: tuple[OutlineSection, ...]


class AnswerOutlineBuilder:
    def build(
        self,
        plan: AnswerPlan,
        sketch: EvidenceSketch,
        settings: GenerationSettings,
    ) -> AnswerOutline:
        evidence_ids = plan.evidence_order
        if plan.answer_type is AnswerType.CLARIFICATION:
            return AnswerOutline(
                new_id("answer_outline"),
                (OutlineSection(
                    section_id="clarification",
                    section_type="clarification",
                    objective="请求用户消除对象或问题歧义",
                    claim_keys=(),
                    evidence_ids=(),
                    subject_refs=(),
                    max_chars=min(160, settings.max_main_answer_chars),
                ),),
            )
        conclusion_claim_keys = tuple(
            claim.claim_key for claim in plan.target_claims
        )
        sections = [OutlineSection(
            section_id="conclusion",
            section_type="conclusion",
            objective="直接回答核心问题",
            claim_keys=conclusion_claim_keys,
            evidence_ids=evidence_ids[:1],
            subject_refs=(),
            max_chars=min(120, settings.max_main_answer_chars),
        )]
        if plan.answer_type is AnswerType.COMPARISON:
            dimensions = tuple(dict.fromkeys(
                claim.comparison_dimension
                for claim in plan.target_claims
                if claim.comparison_dimension
            ))
            for dimension in dimensions:
                claims = tuple(
                    claim for claim in plan.target_claims
                    if claim.comparison_dimension == dimension
                )
                sections.append(OutlineSection(
                    section_id=f"comparison_{dimension}",
                    section_type="comparison_dimension",
                    objective=f"按同一维度比较：{dimension}",
                    claim_keys=tuple(claim.claim_key for claim in claims),
                    evidence_ids=tuple(dict.fromkeys(
                        evidence_id
                        for claim in claims
                        for evidence_id in claim.candidate_evidence_ids
                    )),
                    subject_refs=tuple(dict.fromkeys(
                        ref for claim in claims for ref in claim.subject_refs
                    )),
                    max_chars=self._dimension_budget(settings.max_main_answer_chars, len(dimensions)),
                    display_intent="comparison_table",
                ))
        else:
            sections.append(OutlineSection(
                section_id="body",
                section_type="explanation",
                objective="按证据解释结论",
                claim_keys=tuple(claim.claim_key for claim in plan.target_claims),
                evidence_ids=evidence_ids,
                subject_refs=tuple(dict.fromkeys(
                    ref for claim in plan.target_claims for ref in claim.subject_refs
                )),
                max_chars=self._body_budget(settings.max_main_answer_chars),
            ))
        if plan.missing_points or sketch.conflicts:
            sections.append(OutlineSection(
                section_id="uncertainty",
                section_type="uncertainty",
                objective="表达缺失或冲突边界",
                claim_keys=(),
                evidence_ids=(),
                subject_refs=(),
                max_chars=80,
            ))
        sections.append(OutlineSection(
            section_id="follow_up",
            section_type="follow_up",
            objective="提供一个可选追问",
            claim_keys=(),
            evidence_ids=(),
            subject_refs=(),
            max_chars=40,
        ))
        return AnswerOutline(new_id("answer_outline"), tuple(sections))
```

```python
from dataclasses import dataclass
from typing import Generic, TypeVar

from core.runtime_settings import ModelSettings
from services.model_client import ModelClient, ModelMessage, ModelOptions
from services.structured_output import StructuredOutputError, StructuredParser

T = TypeVar("T")


@dataclass(frozen=True)
class ModelCallResult(Generic[T]):
    ok: bool
    value: T | None
    provider: str
    model_alias: str
    request_id: str
    latency_ms: int
    retry_count: int
    error_code: str | None


class ModelRuntime:
    def __init__(self, client: ModelClient, settings: ModelSettings) -> None:
        self.client = client
        self.settings = settings

    def complete_structured(
        self,
        messages: tuple[ModelMessage, ...],
        parser: StructuredParser[T],
        options: ModelOptions,
    ) -> ModelCallResult[T]:
        raw = self.client.complete(tuple(messages), options)
        value = None
        error_code = raw.error_code.value if raw.error_code else None
        if error_code is None:
            try:
                value = parser.parse(
                    raw.parsed_payload
                    if raw.parsed_payload is not None
                    else raw.raw_text
                )
            except StructuredOutputError:
                error_code = "structured_output_invalid"
        ok = error_code is None and value is not None
        return ModelCallResult(
            ok=ok,
            value=value,
            provider=raw.provider,
            model_alias=raw.model_alias,
            request_id=raw.request_id,
            latency_ms=raw.latency_ms,
            retry_count=raw.retry_count,
            error_code=error_code,
        )
```

将 `ModelClient` Protocol 改为只负责 Provider 调用：

```python
class ModelClient(Protocol):
    def complete(
        self,
        messages: tuple[ModelMessage, ...],
        options: ModelOptions,
    ) -> ModelResult: ...
```

`ModelResult` 只保存 provider transport 结果：`raw_text`、可选 `parsed_payload`（Mock 可直接提供 dict）、provider/model/request/latency/retry/error；删除 `fallback_used`。Mock 对 dict 同时设置 `parsed_payload=dict(response)` 和 `raw_text=json.dumps(response, ensure_ascii=False)`；ModelRuntime 必须优先 `parsed_payload`，避免 `str(dict)` 单引号导致解析失败。DeepSeek `complete()` 只解析 HTTP JSON 外壳并返回模型 content，不执行 answer schema parser。

```python
from generation.outline import AnswerOutline

from services.model_runtime import ModelCallResult, ModelRuntime
from services.model_client import ModelOptions
from services.structured_output import AnswerDraftParser, ParsedAnswerDraft


@dataclass(frozen=True)
class DraftResult:
    draft: ParsedAnswerDraft
    model_result: ModelCallResult[ParsedAnswerDraft] | None
    fallback_used: bool
    fallback_reason: str | None


class ModelDraftGenerator:
    def __init__(self, runtime: ModelRuntime, options: ModelOptions) -> None:
        self.runtime = runtime
        self.options = options

    def generate(self, messages) -> ModelCallResult[ParsedAnswerDraft]:
        return self.runtime.complete_structured(
            tuple(messages), AnswerDraftParser(), self.options
        )


class DeterministicFallbackGenerator:
    def generate(
        self,
        plan: AnswerPlan,
        outline: AnswerOutline,
        sketch: EvidenceSketch,
    ) -> ParsedAnswerDraft:
        if not plan.allow_definitive_answer or not plan.target_claims or not sketch.facts:
            return ParsedAnswerDraft(
                answer_type=AnswerType.CLARIFICATION,
                response_mode=ResponseMode.CLARIFICATION_ONLY,
                short_answer="当前资料不足，不能给出确定事实回答。",
                main_answer="当前已审核资料不足，请补充资料或缩小问题范围。",
                claim_candidates=(),
                visual_refs=(),
                uncertainty_notes=("reviewed_evidence_missing",),
                follow_up_questions=("是否可以提供更明确的问题或已审核资料？",),
            )
        selected_facts = self._select_facts_for_outline(plan, outline, sketch)
        main_answer, included_evidence_ids = self._render_sections(
            outline, selected_facts
        )
        claims = tuple(
            self._claim_from_fact(index, plan, fact)
            for index, fact in enumerate(selected_facts, start=1)
            if fact.evidence_id in included_evidence_ids
        )
        return ParsedAnswerDraft(
            answer_type=plan.answer_type,
            response_mode=ResponseMode.GROUNDED_ANSWER,
            short_answer=self._first_complete_sentence(main_answer),
            main_answer=main_answer,
            claim_candidates=claims,
            visual_refs=tuple(self._visual_refs(outline, sketch)),
        )
```

```python
@dataclass(frozen=True)
class GenerationRequest:
    run_id: str
    query_object: QueryObject
    scene_state: SceneState | None
    memory_context: MemoryContext
    evidence_package: EvidencePackage
    prompt_bundle: PromptMessageBundle | None
    generation_settings: GenerationSettings
    self_check_settings: SelfCheckSettings
    model_settings: ModelSettings
    config_version: str
    retrieve_round: int = 0
    rewrite_round: int = 0


@dataclass(frozen=True)
class GenerationOutcome:
    envelope: AnswerEnvelope
    route: AnswerRoute
    sketch: EvidenceSketch
    plan: AnswerPlan
    outline: AnswerOutline
    prompt_context: PromptContext


class AnswerGenerationPipeline:
    def generate_outcome(self, request: GenerationRequest) -> GenerationOutcome:
        route = self.router.route(
            request.query_object, request.evidence_package, request.scene_state
        )
        sketch = self.sketch_builder.build(request.evidence_package, route)
        context = PlanningContext(
            request.query_object,
            request.scene_state,
            request.memory_context,
            request.generation_settings,
            request.self_check_settings,
        )
        plan = self.planner.create_plan(context, sketch)
        outline = self.outline_builder.build(
            plan, sketch, request.generation_settings
        )
        assembled = self.prompt_runtime.assemble_generation_bundle(
            route,
            request.query_object,
            request.scene_state,
            request.memory_context,
            request.evidence_package,
            plan,
            outline,
            output_contract=AnswerDraftParser.prompt_contract(),
        )
        bundle = self.prompt_replay_validator.select(
            supplied=request.prompt_bundle,
            assembled=assembled,
            route=route,
        )
        draft_result = self.drafting_coordinator.generate(
            model_settings=request.model_settings,
            messages=bundle.messages,
            plan=plan,
            outline=outline,
            sketch=sketch,
        )
        draft = self.claim_normalizer.normalize(
            draft_result.draft, plan, outline, sketch
        )
        bindings = self.citation_binder.bind_candidates(
            draft.claim_candidates,
            request.evidence_package,
            require_all=request.generation_settings.require_source_binding_for_claims,
        )
        trace = self.trace_builder.build(
            route, plan, outline, sketch, draft_result, bundle, request
        )
        envelope = AnswerEnvelope.from_draft(draft, bindings, trace)
        return GenerationOutcome(
            envelope=envelope,
            route=route,
            sketch=sketch,
            plan=plan,
            outline=outline,
            prompt_context=bundle.prompt_context,
        )

    def generate(self, request: GenerationRequest) -> AnswerEnvelope:
        return self.generate_outcome(request).envelope
```

~~~python
def route_decision(
    self, draft: CheckReportDraft, context: DecisionContext
) -> CheckReport:
    if draft.has_hard_safety_issue:
        return draft.finalize(ActionDecision.SAFE_RESPONSE)
    if not draft.has_all(self.policy.required_checks):
        return draft.finalize(ActionDecision.HUMAN_REVIEW, "CHECK_REPORT_INCOMPLETE")
    if draft.needs_scene_clarification:
        return draft.finalize(ActionDecision.ASK_CLARIFICATION)
    if draft.has_contradiction:
        return draft.finalize(ActionDecision.HUMAN_REVIEW)
    if draft.has_missing_evidence and context.retrieve_round < self.policy.max_retrieve_rounds:
        return draft.finalize(ActionDecision.RETRIEVE_MORE)
    if draft.has_unsupported_generated_claim and context.rewrite_round < self.policy.max_rewrite_rounds:
        return draft.finalize(ActionDecision.REWRITE_ONLY)
    if draft.all_required_checks_passed(self.policy):
        return draft.finalize(ActionDecision.PASS)
    return draft.finalize(ActionDecision.HUMAN_REVIEW)
~~~
