## 统一准备与终止规则

PICO-01 前执行：`py -3.13 -m venv .venv-pico4`，随后仅使用 `\.venv-pico4\Scripts\python.exe` 运行测试。不得用全局 Python、不得修改 `pyproject.toml`、`uv.lock` 或 Unity Packages。每任务开始先运行 `git status --short` 与 `git diff --check`；同一白名单文件已有用户改动即停止。PICO-13 验收记录落盘后，验证绝对路径为 `D:\APP\Python 3.13\挑战杯\.venv-pico4`，再执行 `Remove-Item -LiteralPath 'D:\APP\Python 3.13\挑战杯\.venv-pico4' -Recurse -Force`。
